## 一、调研结论（三路子智能体 + 网络检索交叉）

**换弹链（决定①只需改一处）**：换弹时长唯一生产点 = `19-input.js tryReload` 的 `VM.stateDur`；VM 第一人称换弹动画（10-viewmodel `nt=stateT/stateDur` 相位驱动、无固定时间线）、换弹读条（22-hud 同两字段）、第三人称换弹姿态镜像（20-player `p.reloadT` 只读镜像）、换弹中重按 R 加速（推进 stateT 的 2.5%）**全部按比例自动跟随**。Bot 与玩家共用 `WPN_DEFS`（def.reload/mag/reserve）但各有一套计时账：14-bots 六处 `reloadT` 起点。车载/固定武器是纯 CD 制无弹匣概念，不在本设置范围。

**死亡/相机链（决定②的插点）**：`18-game die(attacker)` —— 击杀者参数名即 `attacker`；自杀（自雷 thrower=自己）不进 killfeed、环境死（fallDamage/淹水/激流）传 `null`；玩家死后时序 = 0~2.2s 尸体环绕镜头 → 2.1s `#blackOv` 渐入(0.8s) → 2.8s `showDeploy(true)`（die() 尾部两个 addMatchTimeout，**本批原样保留**）；`updateCamera`（20-player）死亡分支顺序 = specView 让位 → 死亡环绕 → 航拍。画布 CSS 滤镜有历史先例（2026-11-11 性能批把常挂的电影感滤镜摘除并钉 `filter='none'`——本批只在 killcam 窗口临时挂、killcamEnd 单源还原，不破坏该口径）。

**网络检索（killcam 设计惯例）**：killcam 三目的=公平验证/位置教育/重生等待填充；时长宜短（CS:GO ~6s、围攻 ~10s 被诟病拖节奏）；**部分去饱和优于全灰**（MW2019 全灰被评为"too much"，Buckshot Roulette 灰度死亡镜头后补了开关）；重入 UI 前先压黑过渡避免镜头硬跳。本批落地：窗口≈0.5s 保留 + ~2.3s killcam（受既有 2.8s 部署页时序约束，用户令"重部署页面不变"优先）、grayscale 0.62 部分去饱和、`#blackOv` 天然充当收尾过渡。

## 二、实现

### ① 动态换弹速度（sf_dynreload，默认关）
- `00-config`：`let DYN_RELOAD=localStorage.getItem('sf_dynreload')==='1'` + **系数单源** `dynReloadFac(mag,cap)`（`clamp((cap-mag)/cap,0,1)`；已耗≤0〔满匣，正常被换弹门拦〕或容量非法回退 1 防零时长瞬换）。
- 玩家：`19-input tryReload` stateDur 行尾乘 `dynReloadFac(w.mag,w.def.mag)`（连杀增益 reloadMul 照旧并联，乘法交换序无歧义）。
- Bot 同规（用户公式为世界规则口径，未限定玩家）：14-bots 六处 reloadT 起点（1078 压弹尽 / 1940 火箭筒 / **1985 主动补弹 <40% 档=唯二真实变档点** / 2268 副武器 / 2319 弹尽带 rand(1,1.25) / 4236 坦克乘员）全部乘系数——弹尽档 mag≤0 系数恒 1（行为不变），照挂是为单源语义完备。
- 附身镜像（宿主 Bot 换弹投玩家 VM）自动继承（镜像读宿主剩余时间）。

### ② 死亡时视角=击杀者（sf_deathcam self/killer，默认自己）
- `18-game die()` 尾部（deathPos 之后、setRespawnCd 之前）目标解析：`attacker` 有 `slots`（持枪 Bot 士兵）直接用；是载具则取 `crewBot`；**自杀（attacker===this）/环境死（null）/丧尸等无 slots 对象一律 `killcam=null` 回退原镜头**。`player.killcam={src,t:0}`。
- `20-player updateCamera` 死亡分支：specView 让位之后、死亡环绕之前插 killcam 档——`t+=dt`；**t<0.5 落回原死亡环绕（=「一瞬间和现在相同的视角」）**；t≥0.5 **剪切**（首帧直摆=CoD 式硬切，之后 dampF(7) 跟随）到击杀者背后追尾机位：注视点=活体眼位（prone/crouch 口径同 14-bots eyePos）/阵亡 ragdoll 骨盆/兜底原地；机位=反向 (−sin yaw, 0.5, −cos yaw)×6m（Bot 前向=(sin,cos) 系差 π 同 752 行注）、`raycastWorld` 背后遮挡收近（同死亡环绕 2205 口径）、地形+水面下限（同海战审计 2210 口径）、fov 钳 60。纯观察：不写 player 姿态、不附身（与 U 键第三人称/specView/specRide 三种皆不同）。
- 滤镜与角标：killcam 期挂 `renderer.domElement.style.filter='grayscale(0.62) contrast(1.05) brightness(0.92)'`（部分去饱和）+ `#kcInd`「☠ 击杀者视角」角标（#ui 内 blackOv 之前，黑屏渐入连带压暗）。
- **收账单源 `killcamEnd()`**（20-player）：清账+滤镜还原 'none'+角标藏回；三点接线：`showDeploy`（23-deploy，死亡进部署页）/`endMatch`（21-match，结算屏覆盖前还原）/`enterSpecView`（自由观战，specView 相机分支优先不能残灰）；killcam 分支内目标失效/结算自愈同调。
- **重部署页面零改动**：die() 两个 addMatchTimeout（blackOv 2.1s / showDeploy 2.8s）原样，部署页内容/按钮冷却(8s)/票尽门全部不动。

### ③ 设置 UI + i18n
- index.html `#mGameplaySet` 两张 setCard（dynReloadBtn ⏱ / deathCamBtn ☠，单钮循环+sel 高亮，说明含公式与 killcam 口径）；`#kcInd` 角标 div；style.css `#kcInd` 样式；00b-i18n 词条八条（标签/档位'自己''击杀者'/角标/两段说明，'开''关'复用既有键）。

## 四、探针坑三新（本批实录）

1. **沙箱同步 setTimeout 会吃掉 killcam**：成批沿用的 `ctx.setTimeout=同步执行` 桩，令 die() 里 `addMatchTimeout(showDeploy)` 当帧执行 → killcamEnd 把刚建的账当帧收掉 = ③-2 假红（实机异步无此问题）。修=本探针 boot 改**队列不执行**（贴近 bootstub 原生 no-op 语义；行为链全直调不依赖定时器）。
2. **探针前置缺 `rearmPlayerClass`**：startBtn 开局后 `player.curW=null`（槽位在部署时才建）——须 `rearmPlayerClass(0)` 建槽（20-player 单源）再测 tryReload。
3. **bootstub classList 是 no-op（contains 恒 false）**：killcam 显隐 #kcInd 走 classList ⇒ 断言不可见——探针 boot 的 getElementById 自动建元素补 Set 版可观测 classList（`_cls`），其余行为走原生桩。

## 六、实机关注清单

1. 游戏内容设置两张新卡：动态换弹速度开关（默认关）、死亡时视角 自己/击杀者（默认自己）。
2. 开动态换弹：打 1~2 发立刻换弹应明显变快（加兰德 0.3s 级）、打空换弹与从前一样；读条/第一人称动画/换弹音效按比例同步，不应有动画错拍。
3. 死亡视角=击杀者：被 Bot 击杀 → 约 0.5s 原死亡镜头 → 硬切到击杀者背后追尾（偏灰绿滤镜+顶部「☠ 击杀者视角」角标）→ 黑屏 → 2.8s 照常进重部署页面（按钮照旧 8s 冷却）；自杀/坠地/淹水/丧尸杀不切；被坦克打死应切到**乘员**（crewBot）视角。
4. 击杀者被击杀瞬间（换杀）：killcam 应跟随其布娃娃至部署页，不崩、不黑屏残留。
5. 死亡视角=自己：一切照旧。
6. killcam 期间画面帧率若可感知下降属预期（画布滤镜合成 pass，仅死亡窗口 2~3 秒；平时零开销，2026-11-11 性能批口径未破坏）。
7. EN 语言下两设置与角标显示英文（KILLCAM 词条）。

## 七、范围裁定与后续项

- 「换弹速度」按**耗时**口径实现（公式字面为速度、按速度实现会出现"几乎满匣换弹极慢/空匣无限慢"的反直觉病——已按"越接近满匣越快、打空=原时长"的战术换弹惯例落地说，与用户示例语义一致）。
- 动态换弹**玩家与 Bot 同规**（世界规则口径）；若实机后想改"仅玩家"，把 14-bots 六处系数摘掉即可（单源不动）。
- 车载/固定武器（纯 CD 制）不在本设置范围；丧尸击杀暂走原视角（无 slots 目标，回退口径）。
