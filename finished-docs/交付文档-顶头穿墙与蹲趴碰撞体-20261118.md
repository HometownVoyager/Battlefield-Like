# 交付文档 — 顶头穿墙通用修复 + 蹲/趴真实碰撞体（2026-11-18）

## 一、问题与归因

**用户实报（两轮）**

1. 走/跳上有判定的砖时，脚下瞬间升高、没有过程；头顶随之探进上方楼板/屋顶，人被横向弹射穿墙。
2. 首轮修复（自动蹲 + 横推豁免）上线后仍有残留：自动蹲状态下跳跃仍穿墙；自动蹲不及时，且触发了也未必能避免；高砖与屋顶之间空间小时，一上去就**完全无法移动**（自动蹲着、钉在原地）。

**根因（代码级）**

| 根因 | 位置 | 说明 |
| --- | --- | --- |
| 横推"最近边"分支把初始重叠的人整只弹射 | `04-collision.js` `_cmBoxCb` 的 `d≈0` 分支 | 人中心落进盒 footprint 时走"就近推出"，一步推出数米，直接穿相邻薄墙。 |
| 屋顶内侧**有**判定 | `05-world.js` `pitchedRoof()` 阶梯碰撞带（每坡 3 条，底面 `y0-0.35` 一直到坡面） | 屋顶不是薄壳，而是填满室内上部的实心盒带；站在屋顶 footprint 下方即"人在盒里"。 |
| 起跳强制站起 | `20-player.js` 起跳行原 `p.crouch=false` | 自动蹲着按空格，当帧站起来，头顶瞬间顶进屋顶。 |
| 解嵌晚于横推 | `20-player.js` / `14-bots.js`：`collideMove` 在前、`standHeightSafe` 在后 | 想救已经来不及，人已被弹出墙外。 |
| **碰撞体恒 1.7m** | `collideMove` 纵带写死 `pos.y+1.5` / `+1.7` | 蹲/趴只改视觉、眼位、命中体，碰撞身体不变矮——低顶下的横梁/阶梯带仍按"站立的人"横推，形成夹击楔死。**这是"上去无法移动"的直接原因。** |
| 从高砖横移出的那几帧误站起 | `standHeightSafe` 只看 `newY` | `standHeight` 在高砖边缘已掉回地面（newY 低），判定"站姿放得下"→ 立刻站起，但身体 `y` 还在高处顶着屋顶，以 1.7m 站姿卡死。 |

## 二、用户裁定（讨论确认）

- 范围：**玩家 + Bot + 僵尸**（共用 `standHeightSafe` / `collideMove`）。
- 顶头策略：**原地压回**，不改 x/z；沿用 C 键蹲 / Z 键趴的现成动画与 `dampF` 过渡。
- 蹲/趴时**碰撞体真的变矮**（头顶 1.7 → 1.25 / 0.6），同步趴姿。
- 起跳：自动压低姿态下，头顶净空不足则**禁止跳跃**；净空够则保持当前姿态跳，不强制站起。站姿沿用旧 `headGrazeBlocked` + `headCeilClamp` 穿越窗（护栏顶起跳行为不变）。
- 恢复：离开低矮处自动恢复站姿；手动 C/Z 夺回姿态控制权（清自动旗），在顶下仍会被下一帧压回。

## 三、实现

### `js/04-collision.js`
- `collideMove(pos, radius, headH)`：第三参为**当前姿态头顶高**（站 1.7 / 蹲 1.25 / 趴 0.6，缺省 1.7 兼容旧调用）。`_cmBoxCb`/`_cmCylCb` 的纵带上界由写死 `pos.y+1.5` 改为 `pos.y+hh-0.2`（站姿 = 1.5，完全不变）。
- `_cmEmbeddedBody(b,pos,headH)`：`d≈0` 的"最近边"分支对**初始重叠件一律不横推**（泛化了首版只豁免 ceiling-like 的限制），屋顶带内部/蹲姿/趴姿全覆盖；竖直解嵌单源化。
- `headCeilClamp(pos,rise,stanceH)`：上升钳制按当前姿态头顶高，蹲/趴跳不再被 1.7m 幽灵头顶错误钉住。
- `headJumpBlocked(pos,curHeadH,rise)`：蹲/趴起跳前预检整段上升净空，净空不足禁跳。
- `standHeightSafe` 升为**四级**：①站够 → 站；②蹲够 → 蹲；③趴够 → 趴；④连趴都不够 → 不抬脚（留 oldY）。并同时探测 `newY`（抬脚目标）与 `oldY`（身体实际所在），取更严格姿态——修掉"高砖边缘误站起卡死"。输出 `.crouch`/`.prone` 互斥。

### `js/20-player.js`
- `playerHeadH(p)` 单源给三档高度；两条积分路径（步行 + TV 制导本体）解嵌提前到横推**之前**，并把 `headH` 传给 `collideMove` / `headCeilClamp`。
- `playerSafeStand` 管理 `_autoCrouch`/`_autoProne`：顶头逐级压下；腾空不自动站起；离场才恢复；输出 `.prone`。
- 起跳门：站姿 = `!headGrazeBlocked`；蹲/趴 = `!headJumpBlocked(_jumpHH, jumpRise)`；不再无条件 `p.crouch=false`。

### `js/14-bots.js`
- Bot / 僵尸（Zombie extends Bot）：`botSafeStand` 同源四级 + `botHeadH()` 传给 `collideMove`；解嵌同样提前到横推前。

### `js/19-input.js`
- 手动 C / Z 同时清 `_autoCrouch` / `_autoProne`，夺回姿态控制权。

## 五、实机验收要点

1. 走到/跳上有判定的砖，头顶贴楼板/屋顶：应**平滑蹲下**（不再瞬间抬脚穿模），不穿相邻墙。
2. 自动蹲状态下按空格：净空不足**跳不起来**；净空够则蹲着跳、全程不站起。
3. 高砖与屋顶之间空间小时：蹲着（必要时趴着）**能正常移动**，不再钉死；原地按 C/Z 想站起会被立刻压回。
4. 离开低矮处：自动恢复站姿；手动 C/Z 后姿态控制权归玩家。
5. 站姿护栏顶起跳、楼板下连跳、桌面跳等既有行为不变（见相关回归）。
