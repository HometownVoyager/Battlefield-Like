1. **布势期 Esc 实际弹暂停，不确认开战**（19-input）：`cmdMapUIOpen` 分支旧写嵌在 Esc 处理器的
   `player.deployed&&player.alive` 门**之内**，而布势期人未落地（deployed/alive 皆 false）⇒ 分支永远
   走不到，Esc 落进 else 变 `togglePause(true)` —— 与本文件/26-commander/设计 D21 三处"布势 Esc=确认"
   的宣言相反（三键失效批修了 E/F/R 却漏了 Esc 这条同级路径）。修法=分支上提到门外 +
   `&&!gamePaused` 暂停优先门（D20：暂停中 Esc 只解暂停，不操作被 cmdMapPauseGate 藏起的地图；
   顺带修掉旧写"暂停中 Esc 会去关被藏起的战斗地图"的同源边界）。
2. **布势配比被"摘自己"扣减对抗**（26-commander `cmdRatioWantBot`）：旧写把 respawn bot 自己的旧 cls
   从 have 里再扣一次，但唯一调用点（14-bots spawn 落装行）此刻 bot 还是**死人**（构造器/die 置
   alive=false，spawn 落装行之后才置 true），have 统计的活人分布天然不含它 ⇒ 扣减凭空虚增旧兵种位
   的 gap，死者总按旧兵种复活、玩家的布势配比被永久拉回旧分布。修=删扣减；want 合计=全组人数、
   死人=待补空位，sum(gap)=死亡数≥1 恒有正差，贪心天然收拢回 want。
3. **撤销布势不清初始令**（23-deploy `cmdDeployUndo` + 新单源 26-commander `cmdOrbatClearOrders`）：
   撤销复位了配比/锁章/看图账/私人小队，唯独没清布势期 E/F/R 下的 hold/attack/strike —— 撤销后改选
   普通兵种时玩家已不是指挥官（开不了图），全军按一份"没人能取消的幽灵令"打满整局。修=撤销链新增
   ④b-2 步调 `cmdOrbatClearOrders()`（全单位归 free + 飞机 strikePt/strikeT0 同清，静音幂等）。
4. **集火标记过期永挂"集火 0s"**（26-commander `cmdMapDraw`）：各 unit.focus 由 cmdFocusOf 自行过期，

   即清账（与 cmdFocusOf 同一口径）。
5. **布势重进门漏一条路径**（22-hud 兵种卡分支）：旧门 `!CMD.deploySeen||(player.cls===5&&!player.deployed
   &&!matchOver)` —— "撤销→改选步兵→再点指挥官卡"时 cls 已不是 5，布势不自动弹且无任何补进入口，
   该路径的指挥官局只能以默认布势裸开。修=去掉 `player.cls===5` 子条件（凡未落地点指挥官卡都进布势；
   `!player.deployed` 仍是"战斗中途/死了等重生不许重进"那道门，死亡不清 deployed 已核实）。

## 0. 定位

指挥官模式**不是独立对局模式**，而是**兵种级 RTS 附加层**：玩家选择"指挥官"兵种下场作战，
以通讯仪为媒介打开实时指挥地图，对己方所有单位（步兵小组 / 坦克 / 飞机）逐个下令微操，
配合受限的时间减速在慢放窗口内完成复杂指挥。对局本身沿用标准征服（票制 + 旗点），
BOOT_MODE 不动（campaign / procgen / zombie 三态不变）。

结构判断（讨论共识）：四块新地——新兵种、canvas 指挥地图、命令覆写管道、减速档——
均不触碰载具 / 武器 / 对局核心，回归风险低。无人局方案已否决（指挥官要下场）。

  建筑 footprint 按类型着色、旗点圈（**带占领态着色：蓝 / 红 / 灰 / 争夺闪烁，小地图同款复用**）。
  素材全现成（05c-layouts 布局函数；小地图同族渲染参照放大）。随机图天然适配；预设图逐图验
  烘焙效果。**不做建筑名标注**（R6）。**破坏补丁**（D19）：可破坏结构损毁时 footprint 变废墟色。
- **动态层（实时）**：己方各小组按队色 + 队号、坦克方块 / 飞机三角等形状区分；坦克战损
  重生中灰显、票尽封死后单位清空（15-vehicles 同对象复位重生已查实，22~29s）；
  **敌军显示复用小地图敌显管线单源**（R12：mmEnemyVis + 全图开关 + 视野圆蒙版）；
  选中单位 → 目标画命令线。滚轮缩放、拖拽平移。
- **交互**：点选单位 → 下令（选中后点目标点 / 旗点，弹命令小菜单或右键快捷）。
  命令分发走**单源函数**（squadOrderMove 的扩展范式：覆写目标 + 重置 repath）。
  下令反馈音（电台咔哒 / 电流声，AudioSys 合成器现成）。
- **实时性与边界**：地图开着战场照跑（所以才需要减速，见 §6）。Esc 在地图开着时只关地图，
  连按两次才到暂停；**暂停冻结地图操作、结算强制关图**（D20）。
- **UI 归属**：指挥地图挂 #ui 层，吃 inMenu / inDeploy / hudHide 既有显隐压制网，不另开特判。
  开 / 关地图伴随指针锁释放 / 重锁（鼠标点选需要）。

## 5. 编制与命令系统

- **编制（开局定编，挂世界构建尾生成、不挂玩家部署）**：己方 14 Bot 按 ceil(n/5) 分组、
  每组 3~5 人（≈3~4 个步兵小组）；每辆坦克、每架飞机各自一个单位（编制挂载具对象）。
  玩家不属于任何组。编制表挂在局数据上，开局面板可见。小局边界：n<5 单组；无载具图
  不生成载具单位。
- **布势阶段（D21）**：自动分组完成后进入冻结布势界面（布势版指挥地图），玩家查看编制、
  调每组兵种配比（生成期落装参数）、下初始命令（四词汇首批调用）；可跳过走默认布势。
  确认开战后解冻，走现有首次部署页。
- **命令词汇与状态机**（四态，命令 = 直接覆写目标状态，不动 Bot 决策核心）：
  - `free` 自由推进：恢复默认 AI（现有自主征服行为，含自发上车权，D16）
  - `attack_move` 进攻某点：attack-move 到点（**途中照常索敌接战**），到点后占旗
  - `hold` 到某点防守：定身守点（参照丧尸 zDefPosts 虚拟旗先例），接战还击
  - `strike`（仅飞机）指定投弹点：自动进入攻击航线投弹，**一次性任务，完成后恢复自由**；
    **途中被咬尾照常自卫**（"途中接战"语义扩展到空中）。接 16-aircraft 决策原语
    （区别于现有"航弹锁定制导"：目标点而非锁定目标）
- 心灵控制 ≠ 木头人（R3 + 词汇语义）：移动 / 进攻途中正常接战；只有 `hold` 是真定身。
  逐个选中当场微操（R4），不做编队 / 框选 / 队列命令。
- **编制纪律**（D16）：非 free 态禁自发上 idle 载具；组员阵亡重生自动回组并继承本组当前命令。

## 6. 时间减速子系统

- **实现底子**：时停已有帧长单源管道（specTimeShotDt）；减速 = 把 1.0/0.0 二值口径扩成
  三态（常速 / 减速 / 停）。物理、动画一起慢（时停管道趟过）。历史包袱：当年"时停之外的
  时间流速控制"是用户令删的——本减速是**兵种技能 / 观战工具级、带资源限制**的新机制，
  与 K 时停并存不冲突，叠加口径 D14。
- **触发**：按住减速键 → 流速 0.2x（D5）；松开恢复。开地图不自动减速（D7）。
  **死亡期间禁用**（D12 口径并入：不能下令则慢放无意义）；**观战模式无收支**（R8）。
- **资源（指挥读条）**：命名避开交互读条网的 readBarActive（建议 cmdFocus）。按住期间消耗，
  常速下缓慢恢复（恢复 < 消耗，防滥用）。**读条耗尽只回常速不关地图**（D5）。
- **读条时间口径**（D13）：减速期间所有交互读条吃游戏 dt，跟世界一起慢。
- **"对我无效"口径**（R9 / D4）：默认玩家同减速；开关打开 = 玩家豁免（超人档），
  豁免实现复用观战者不吃冻结的同源管道。**UI 层永不吃减速**。
- **音频口径**：一次性触发音（枪声 / 爆炸）照常速播 = 慢放中轻微音画错位，v1 接受
  （变调 / 拖慢 v2）；dt 驱动的引擎音是否自然变慢，实现期验证。
- **设置项（R9，"游戏内容设置"区，`地图全图信息` 开关同栏目）**：
  - `减速消耗读条`（默认开；关 = 观战级玩具档）
  - `减速对我无效`（默认关；开 = 超人档）
- 键位实现期对齐 19-input 现有占用表选空键（倾向按住式），观战与指挥官共用同一键；
  观战 HUD 提示行（J=信息层那串）补减速键词条。

## 10. 探针要点（verify-commander）

1. 兵种表：指挥官定义存在、cls 重映射无误；丧尸 / 海战局兵种卡列表不含指挥官；
   **兵种双向锁定**（首次部署后两个方向都禁选）；**指挥官局观战三路径全堵**。
2. 落装：主武器槽 = 通讯仪（无火力面板）、副武器冲锋枪、绷带 / 手雷同突击兵数。
3. 编制：15 人侧 = 指挥官 + 14 Bot；组数 ceil(14/5)=3、每组 3~5；坦克 / 飞机各成单位；
   小局 n<5 单组边界；编制生成时点在世界构建尾（玩家未部署即存在）。
4. 命令状态机：下令后单位目标状态覆写 + repath 重置；四词汇各自语义（attack_move 途中接战、
   hold 定身、free 恢复默认、strike 一次性 + 途中自卫）。
5. 编制纪律：非 free 态不上 idle 载具（free 态照旧 = 零回归锚）；组员重生后继承本组当前令。
6. 减速：帧长单源三态；读条收支（按住耗 / 常速恢复 / 耗尽强制回常速且地图不关）；两设置开关
   各自生效；观战局无收支；死亡期间禁用；交互读条吃游戏 dt（减速中换弹时长按比例变长）；
   时停优先叠加口径。
7. 指挥地图：底图烘焙产物非空；**敌显与同种子同状态下的小地图逐点一致**（R12 单源断言——
   晴天全显 / 夜间开火显形 / 全图开关豁免三种状态各验一组）；**可破坏建筑炸毁后 footprint
   变废墟色**；坦克战损灰显 / 票尽清空；点选 → 命令线渲染；姿态门（载具中 / 空中 / 水中开不了）。
8. **布势阶段**：冻结期间全体单位零位移（敌我都冻）；配比修改后组内 Bot 落装与配比一致；
   初始命令在解冻后即刻生效（状态机非 free 态）；跳过路径 = 默认布势（全 free）直接开战；
   敌情显示与 R12 同源（布势界面不另立分支）。
9. 回归：普通兵种 / 观战模式 / K 时停 / 小地图本身零变化；探针载入清单与 index.html
   实载对账（盲区教训）。

## 11. 实机验收清单（用户执行）

1. 标准征服局选指挥官兵种开局：装备三件套正确，持通讯仪无火力。
2. **布势阶段**：开局先进冻结的布势地图（敌我都不动）；改一组兵种配比 → 该组按配比落装；
   给 1 组下"防守东桥"、2 组"进攻某旗" → 确认开战后即刻照令行动；"默认布势"跳过按钮
   可直接开战（全组自由推进）。
3. **双向锁定**：死亡重生再部署兵种卡全禁选（保持指挥官）；另开一局选普通兵种：指挥官卡禁选。
4. 举通讯仪右键开地图（**坐进坦克 / 空中 / 游泳时开不了**）：底图含地形 / 建筑 / 旗点占领态；
   己方按队着色 + 队号；缩放平移顺手。
5. **敌显三态**：晴天全图红点；换夜间局 → 只有开过火 / 近距离的敌军上图；游戏内容设置开
   `地图全图信息` → 夜间也全图（与小地图口径一致）。
6. **炸塌一栋楼：指挥地图上该建筑变废墟色块**。
7. 点选一个小组 → 下令进攻某旗 → 全组 attack-move 前进、途中遇敌接战、到点占旗；
   中途打死组员，其重生后自动归队续令。
8. 防守令 → 定身守点；自由推进 → 恢复默认推进。
9. 坦克同词汇可用；飞机指定投弹点 → 进入攻击航线投弹（途中被咬会自卫）→ 完成后恢复自由；
   坦克战损后地图灰显、重生后恢复。
10. 开地图时**自己定身**、被打不退出；Esc 只关地图，连按两次才进暂停。
11. 按住减速键：全场慢放、指挥地图界面实时可操作；读条下降，松开缓慢回复；耗尽自动回常速
    但地图还开着；减速中换弹明显变慢；死亡待重生期间减速键无效。
12. 游戏内容设置两开关：关读条消耗 → 无限减速；开"对我无效" → 减速中自己行动如常。
13. 观战模式：同一减速键可用且不耗任何资源；指挥官局观战开关（含战斗中开关）是灰的。
14. 指挥官阵亡：地图关、无法下令，各单位维持最后命令；重生后恢复。
15. 丧尸局 / 海战图：兵种卡里没有指挥官。
16. 普通兵种 / 观战 / 时停 / 小地图：与现状零差异。
