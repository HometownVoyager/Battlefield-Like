## 〇、三问的答案 (先给结论)

### 问题① Bot 是否受打断机制影响？为何附身时看不到宿主消耗弹药/换弹？

**答案: 修复前完全不受影响。** 玩家在 2026-10-25 批建起的整套读条取消网 (`readBarActive` / `cancelReadBar` / `stealBar` / 受创>25 打断门 `READBAR_DMG_GATE=25`) 全部挂在 player 对象字面量上; `Bot` 类在 14-bots **完整重写了 `damage()`**, 通篇没有打断逻辑——Bot 换弹是独立 `reloadT` 计时器、举雷是 0.8s `nadeAnimT` 硬直、包扎是计时器, 挨 999 伤害也照走完, 只有死亡才会终止。

"附身看不到宿主动作"是三层叠加:

| 层 | 根因 | 现象 |
|---|---|---|
| 账 | Bot 的 `slots[0].mag` 只在出生/换弹完成时写, 开火只扣 `this.mag`; `slots[].reserve` **从不扣减** | 附身弹药面板: 弹数两次换弹间冻结不动、备弹恒满 |
| 门 | `updateViewModel` 只对 `player.alive` 跑; `specViewPossess` 视模式不换枪 (枪收起); `svHostFireFx` 出膛反馈只对调试附身 (`!player.specView` 门) | 死后观战 LMB 附身 (视模式) = 无第一人称枪、无换弹动画、无开火后坐 |
| 网 | Bot 动作根本不进读条网 | 即使画面有动作也没有读条条、也不会被打断 |

### 问题② 固定火力点上的 Bot 有减伤加成吗？

**答案: 全库不存在任何 gunner 减伤乘区** (dmgCut/dmgMul/减伤 全库命中仅四类: 玩家连杀增益、伞降 ×0.40、难度表、空对地 GROUNDGUN_VS_AIR——均与火力点无关)。"炮位 Bot 打不动"的观感来自四个真实机制:

1. **炮体物理挡弹 (主因)**: atGun/aaGun 注册了真实碰撞圆柱 (r=0.6/0.7, 高 1.2/1.4m), `fireBullet` 的 `raycastWorld` 在 `raySoldiers` **之前**截短 wallD——打向 gunner 的子弹大多先撞进炮体, 只见火花不见掉血。AT 炮间隙仅 0.3m、柱高盖住整个躯干, 是全游戏最强"自带掩体"站位。
2. **配套工事**: MG 正前沙袋墙 / AT 后方掩护墙 (MG/迫击炮本体无碰撞盒——所以它们明显比 AT/AA 脆)。
3. **压制反噬**: 1100rpm 的 emplMGFire 持续给攻击者叠 suppression → 攻击者散布 ×(1+suppression)。
4. **迫击炮手蹲姿**: 蹲姿命中体 (躯干圆柱 1.25m vs 站 1.55m) —— **这是唯一"Bot 有而玩家没有"的真实加成**, 已按用户条件式指令补齐给玩家 (见 §三.E)。

另外: 玩家当 gunner 走同一条 `raySoldiers` 判定与受击路径, 且额外吃难度 pDmg 列 (Bot 射手对玩家伤害 0.6/0.8/0.9) 与连杀减伤——**同一门炮上, 玩家本来就更硬, 不是更软**。刚重生的 Bot 有 2s 出生保护 (双方同规), 是短暂且非 gunner 专属的"无敌窗"。

### 问题③ 丧尸为何忽视火力点上的 Bot？

**答案: gunner 本来就是丧尸的合法候选** (候选过滤只排 `onVehicle`/`zombie`/`spectator`, gunner 不设 onVehicle、本体逐帧钉在站位、mesh 可见)。"完全忽视"是感知锁定层**两个真 bug** 的叠加, 对所有目标都成立, 只是钉死在炮位、蹲姿低轮廓的 gunner 没有"频繁重新暴露"的自救路径, 所以表现得最极端:

1. **脱见宽限=0s (主凶)**: `25-zombies:233` 旧式 `nowT-(this.zTgt?0:this._zSeenT)>6` —— zTgt 存活时恒为 `nowT-0>6`, 页面墙钟开局 6 秒后**恒真** ⇒ 追击中的丧尸只要有一个感知拍 (0.22s) 没看见任何人, 立即掉回游荡。注释宣称的"脱见 6s"实际宽限是 0s。
2. **同目标重锁门 (帮凶)**: `:227-228` 旧式 `if(this.zTgt!==best&&this.brain!=='chase')` —— 再次看见的**正是原目标**时此门为假, brain 永远救不回 chase; 丧尸带着 zTgt 在游荡分支里径直从目标旁边走过。会动的 Bot 靠"更近目标切换/受击迁怒/zAlertHorde"等旁路频繁自救; 炮位 gunner 一旦被丢就是永久忽视。
3. 佐证闭环: 迫击炮溅射炸到丧尸会触发迁怒 (`damage()` 直写 `brain='chase'`) → 冲向炮位 → 一个无视线拍被 bug① 打回游荡 → bug② 阻止重锁定 → "冲一下就散、从旁边过不打", 与实机观感完全吻合。

## 一、落地内容

### A. Bot 打断网 (js/14-bots.js `Bot.damage`)

`amt>READBAR_DMG_GATE(25)` (判在减免后 amt, 与玩家 `18-game:196` 同常量同语义) 打断五类动作, **取消一律不结算**:

| 动作 | 打断效果 |
|---|---|
| 换弹 (reloadT/pReloadT>0) | 计时清零, 弹匣不进弹 (结算只发生在自然走完) |
| 举雷/AT雷前摇 (state nade/atnade) | `state='combat'`+nadeAnimT=0, 雷不消耗 |
| 包扎 (bandageT>0) | 计时清零, 不回血不耗绷带 |
| 上炮前摇 (emCast) | emCast 清 + `g.user` 交还 (与 die():616 同式, 不吃 EMP_REARM_T 惩罚冷却) |
| 弹尽贴箱补给 (supplyT>0) | 计时清零 |

25 (门槛值) 与 ≤25 刮伤不断; 死亡清账仍由 `die()` 无条件收。

### B. Bot 弹药账对齐 + 弹尽补给 (js/14-bots.js)

- **开火五处同步槽位账**: `aimShot` 主武器/手枪、AT 枪、迫击炮曲射、舰船反坦克枪——`slots[0/1].mag` 随 `this.mag/pMag` 逐发同步 ⇒ 附身面板读数即宿主真账。
- **换弹真扣备弹**: 完成时 `take=min(need, reserve)`, mag/槽位mag/reserve 三账同写; 无槽位 (丧尸子类) 维持旧满仓行为。
- **`canReload()` 门**: 六处换弹起手全部要求备弹>0——备弹打空还照起 reloadT 会变成"永久换弹循环" (完成时无弹可进, 下一帧又起)。
- **弹尽寻补给 `drySeekSupply()`**: 最近岸上 AMMO_CRATES ≤45m (舰上弹药箱跳过——登舰走跳帮链) → `state='toSupply'` 步行 (decide() 承诺期不抢状态) → 贴箱 1.7m 站定 1.2s → 补满 (reserve=备用上限+一匣 + 投掷物照补, 与玩家 `doGrabResolve` 同账) → 弹匣空自然起换弹 (整链可见: "没弹了→跑去箱子→拿弹→换弹")。
- **保底**: 45m 内无箱 → 10s 战地搜刮 (就地补一个弹匣的备弹), 防无箱图/丧尸局永久哑火。
- **放弃条件**: 近敌 (<14m 且可见) 转身接战; 超时 30s/箱丢失/被安排上炮 即放弃; die/spawn 跨命清账。

### C. 丧尸追击双 bug (js/25-zombies.js)

1. 脱见宽限改 `nowT-this._zSeenT>6` (真 6s; nowT=墙钟, 同步 tick 驱动下判据确定)。
2. 同目标重锁门摘前置 (`this.zTgt!==best&&` 删除) —— 视野里有人即回 chase, 同目标/新目标一视同仁。
3. 视线保持刷新 `aggroT=nowT+ZCFG.aggroHold` (重锁即续仇恨窗, 否则 aggroT 到期先在 zTgt 分支掉)。
4. 顺手: 附身候选排除丧尸 (`specViewPickHost`/`specViewCycle` 加 `b.zombie`——Zombie extends Bot 同在 soldiers, 旧版可以附身丧尸)。

### D. 真附身呈现层全量镜像 (js/20-player.js / 24-main / 13-combat / 18-game / 10-viewmodel / 22-hud)

- `specViewPossess` **两模式统一换装**: 视模式附身不再收枪 (VM 挂宿主主武器); 附身时顺手收上一态的举雷账。
- `24-main` updateViewModel 门放宽到 `player.specViewHost` (视模式附身同样跑状态机)。
- **`svHostActionMirror(h)` 单源** (20-player, 调试/视模式两分支共用):
  - 换弹镜像: 宿主 `reloadT` 驱动 VM 换弹动画 (走玩家既有管线) + 读条条; **打断镜像**: `reloadT` 归零而弹匣未满 = 宿主被受创打断 ⇒ `vmAbortAction()` 同帧收 (弹药不结算语义与玩家一致);
  - 举雷/AT雷前摇镜像: 宿主 state nade/atnade 驱动持雷哨兵态 (`player.nadeHeld` 承接 hold 姿态); 离岗 (掷出/被打断) 即收, 不重放出真雷 (10-viewmodel 出手钩加 `VM.mirrorHost` 兜底门);
  - 包扎镜像: 宿主 `bandageT` 驱动 bandage 动画 (10-viewmodel 的"玩家 bandaging<=0 即打断"判定加 `VM.mirrorHost` 旁路; 自然收尾容差 0.12s 防掐)。
- `13-combat` 出膛反馈钩子放开到视模式附身: 宿主开枪 = 附身者的 VM 后坐+枪口焰/枪口灯+微震镜 (旧 `!player.specView` 门删除)。
- `18-game finishReload` 镜像让位: `specViewHost` 置位时直接 return (换弹镜像是宿主账, Bot 换弹完成时已自账写满; 显式让位防玩家侧跨账写)。
- `22-hud`: 读条门放宽到附身 + 宿主举雷/包扎镜像条 (`宿主 · 举雷 …`) + ✕ 按钮附身守卫 (镜像读条不可被玩家掐断; X/左键本就被吞) + 投掷物行带宿主雷账 (旧"宿主不带投掷物只显绷带"口径随弹药账对齐作废)。
- `VM.mirrorHost` 标记语义 = "当前 VM 动作是镜像, 不吃玩家账"; `specViewPossess` 换目标 / 两条 detach 链 (specViewDetach/dbgSpecDetach) 均清 `nadeHeld`+`mirrorHost`。

### E. 火力点命中体 parity (js/20-player.js / 20a-seats.js)

- `mountMortar` 玩家蹲姿 (`crouch=true`) + `updatePlayerMortar` 逐帧兜底 + 下炮还原——与 Bot 迫击炮手 (`14-bots:1785 crouch=true`) 逐位同规, 玩家在迫击炮位获得与 Bot 相同的小命中体 (即用户要的"给玩家也加上")。
- `mountMG/mountAT/mountAA` 强制站姿 (清附身上炮前的蹲姿) + 下炮不残留——与 Bot 站姿同规。
- **不新增任何减伤乘区** (问句是条件式"如果有的话"; 结论=无显式减伤, 物理挡弹双方同享)。

## 三、实机验收清单 (给用户)

1. **附身看动作 (问题①主诉)**: 死后进自由观战 → LMB 附身一个 Bot:
   - 屏上应出现**宿主的第一人称枪** (旧版视模式无枪);
   - 宿主开枪: 枪后坐+枪口焰+微震镜 (世界层弹道/音效照旧);
   - 宿主换弹: 换弹动画+读条条 (`换弹中: Xs`); 宿主换弹中被大伤打断 → 动画当场收回;
   - 宿主举雷/AT雷: 持雷姿态+读条条 (`宿主 · 举雷 …`); 包扎: 包扎动画+读条条;
   - 弹药面板: **弹数实时递减**, 备弹随换弹扣减, 补给后回升; 投掷物行显示宿主手雷/AT雷数。
2. **Bot 被打断 (问题①机制面)**: 观察交战中的 Bot——换弹/举雷中吃一发大伤 (狙击/爆炸) 应当场收枪/收雷; 刮伤不断。
3. **弹尽补给**: 长时间交战后观察弹尽的 Bot——应朝最近弹药箱走过去、贴箱站 ~1.2s、然后换弹; 无箱区域弹尽 ~10s 后原地续弹 (保底)。
4. **丧尸索敌 (问题③)**: 丧尸局让 Bot 操作迫击炮/机枪/AT炮: 丧尸应正常索敌扑咬 (尤其近身路过时); 之前"丧尸从旁边过不打"的现象应消失; 炮击溅射炸到尸群应引来冲锋且**不再冲一下就散**。
5. **火力点 parity (问题②)**: 玩家 F 键上**迫击炮**后是蹲姿 (第三人称看得到); MG/AT/AA 位站姿; 被弹面积与 Bot 相同。AT/AA 炮位"打不动"依旧 (炮体挡弹, 双方同享, 属设计)。
6. **回归关注**: ①Bot 整体弹药消耗变快了吗——应只在"打空整个备弹"后才去补给, 主动换弹节奏 (40%) 不变; ②丧尸难度是否被"更凶"了——重锁修复会让丧尸更粘人, 属 bug 修复范畴; 若觉得过强再调 aggroHold/宽限; ③附身中读条条只读不可掐 (✕ 无效是设计)。
