## 一、 核心重构原则（四大军规）

1. **显存不泄漏（Zero WebGL Leak）**：
   - 任何实体退场、池对象丢弃、武器切换、建筑坍塌，**严禁仅调用 `parent.remove()` 或置空引用**。
   - 所有 Three.js 网格必须递归销毁其 `geometry`、`material`（含内嵌贴图 `map`、`alphaMap`）。
2. **热循环零分配（Zero Hot-Loop Churn）**：
   - 在 `requestAnimationFrame`（主循环 60 FPS）中执行的代码，**严禁使用字面量对象、未池化闭包、以及无目标槽的 `V3()` / `.clone()`**。
   - 所有数学求交与向量计算统一走预置复用槽（Temp Out Slot）。
3. **物理与射线预算化（Budgeted & Swept Physics）**：
   - 彻底解除无意义的物理刚体狭相配对（布娃娃与碎块掩码置零）。
   - 高速弹丸（>100m/s）必须走连续扫掠射线（Swept Raycast），严禁离散点采样。
   - 全局 AI 感知射线施加帧预算配额（Frame Raycast Budget），杜绝 $O(N^2)$ 全图无界探测。
4. **渲染批次受控（Batched & Chunked Rendering）**：
   - 静态不可毁建筑构件按材质统一合并（Merge），严禁单栋建筑拆分数百个 Mesh。
   - 重复场景地物（如塔拉瓦椰树）100% 实例化（`InstancedMesh`）。
   - 巨幅地形与水面网格必须四叉树分块（Chunked），恢复硬件视锥体裁剪。

  在 Three.js 中直接遍历调用 `child.material.dispose()` 会导致灾难性后果：
  1. [`02-scene.js:904`](js/02-scene.js#L904) 的 `MAT` 表（`MAT.grass`、`MAT.wood`、`MAT.metal` 等）是全图全局共享材质；

  **一旦误将其 `.dispose()`，下一局新刷出的士兵与场景建筑将彻底丢失 WebGL Shader Program，引发全屏黑屏或网格隐形报错！**
  真正泄漏显存的是：① 士兵头顶名字画布 [`CanvasTexture`](js/11-soldiers.js#L366)；② 每个士兵独占的头盔 `SphereGeometry`；③ 士兵独占的帽徽/红星材质；④ 工事网格；⑤ 临时手雷/航弹网格。
- **施工指引（生产级安全释放实现）**:
  ```javascript
  // js/02-scene.js
  const _SHARED_MATS = new WeakSet();
  // 开局将全局共享材质登记入白名单
  function registerSharedMaterials() {
    if (typeof MAT !== 'undefined') {
      for (const k in MAT) if (MAT[k] && MAT[k].isMaterial) _SHARED_MATS.add(MAT[k]);
    }
    if (typeof uniformMats !== 'undefined' && Array.isArray(uniformMats)) {
      for (const u of uniformMats) {
        if (!u) continue;
        for (const k in u) if (u[k] && u[k].isMaterial) _SHARED_MATS.add(u[k]);
      }
    }
  }

  function disposeActorHierarchy(obj) {
    if (!obj) return;
    obj.traverse(child => {
      // 1. 释放独占几何体 (共享几何体若有缓存需跳过，普通单位几何体均为独占 new)
      if (child.geometry && typeof child.geometry.dispose === 'function') {
        child.geometry.dispose();
      }
      // 2. 释放独占材质与动态贴图
      if (child.material) {
        const mats = Array.isArray(child.material) ? child.material : [child.material];
        for (const m of mats) {
          if (_SHARED_MATS.has(m)) continue; // ★ 白名单守卫：跳过共享军装与世界材质！
          // 头顶 CanvasTexture 或独占动态贴图必释放
          if (m.map && typeof m.map.dispose === 'function') m.map.dispose();
          if (typeof m.dispose === 'function') m.dispose();
        }
      }
    });
  }
  ```

  function distSqPointToSegment(px, py, pz, x1, y1, z1, x2, y2, z2) {
    const dx = x2 - x1, dy = y2 - y1, dz = z2 - z1;
    const l2 = dx * dx + dy * dy + dz * dz;
    if (l2 < 1e-8) return (px - x1) ** 2 + (py - y1) ** 2 + (pz - z1) ** 2;
    let t = ((px - x1) * dx + (py - y1) * dy + (pz - z1) * dz) / l2;
    t = Math.max(0, Math.min(1, t));
    const qx = x1 + t * dx, qy = y1 + t * dy, qz = z1 + t * dz;
    return (px - qx) ** 2 + (py - qy) ** 2 + (pz - qz) ** 2;
  }

  // updateFlak (js/16-aircraft.js:1087) 改造
  const p0x = f.pos.x, p0y = f.pos.y, p0z = f.pos.z;
  f.pos.addScaledVector(f.vel, fdt);
  const p1x = f.pos.x, p1y = f.pos.y, p1z = f.pos.z;

  // 1. 步兵判定 (由末端离散点检测升级为扫掠柱体线段求交)
