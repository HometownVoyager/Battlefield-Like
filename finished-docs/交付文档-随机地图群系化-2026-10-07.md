## 一、群系表与抽取（js/00-config.js）

- **PG_BIOMES 单源表**（键序 = 哈希取模序）：`farm 农村平原 / town 城郊镇集 / water 水乡河网`。每个群系一个键收敛全部可调面：主题域 `themes` / 噪声参数组 `noise` / 水文开关 `hydro` / 田型 `fields` / 旗点布局族 `flagFam` / 建筑池 `pool`(core/mid/edge/lane/scatter/cluster/court) / 地标 `landmark` / 地图卡标题。
- **抽取口径**：`PG.biome` 由 **splitmix32(seed) 独立哈希**取模得到，**不占 PG 随机流** ⇒ 插群系不改 farm 既有种子的输出（红线④）。水乡仅中式 ⇒ 主题域不符时回收为主题域首位（不补抽，farm 两主题种子流不变）。
- 战役卡 `procgen` 的 title/sub 改读群系表（`PG_BIOMES[biome].title[theme]` / `.label`）。

## 三、town（城郊镇集）

**病根（实测）**：旧版按主街折点**比例**（0.32/0.55/0.78）取支巷/次街锚点，而 62~82m 主街的折点几乎全落"广场 22m 净空"内 ⇒ 105 张图里 73% 只有 2 面旗、次街长不出来、站前旗 48% 失败。

- **主街加长**：镇集 96~124m（`mainL` 分群系档），农路基线不动。
- **锚点制**：取"离核心 ≥26m 的主街折点"由远及近 → 支巷×3（锚点向外放射 42~58m）+ 次街×2（主街法向 ±(46~60)m，**新类 `cls='sub'`** = 街区轴）。
- **排屋采样**：`sub` 类步距 5.0~6.6m（恒建概率 1）——镇集身份=贴街连排（统计段"次街排屋"断言）。
- **铁路货线**：核心 66~80m 外近直线折线（`PGDATA.rail`）；05c `railLine` 逐段铺枕木+双轨（纯视觉不占位）；战术小地图与部署图各画一条折线（深底+细亮轨）。
- **旗点**：`广场`(核心) + `东街`/`西街`（次街端**外延 20/30m 接巷** 或 街内端点回溯首个合法路顶点）+ `站前`（货线 ±14 顶点窗口 × 两侧法向 × 半径 15/19/23 = 84 候选，预筛广场净空后取"与既有旗间距最大"者）。
- 无农田；林地 0~2；散居 5~8 + 旗环簇 3~5（镇集最密档）。

## 四、water（水乡河网）

- **主河**：流向角随机 + 三级中点位移（侧移幅 40/16/6）⇒ 9 顶点蜿蜒折线，端点钉半径 178；`RIVW=7~9`、`d=2.8`（深水=寻路阻挡/徒涉伤害）。
- **石桥 2~3 座**（`kind:'stone'`）：主桥=距原点最近河顶点；二三桥=±2 顶点（50% 双桥）。**徒涉滩**=距全部桥位 ≥55m 的外围顶点（渡口语义 + 03-terrain ford 豁免）。
- **支汊 1~2 条**（向图缘伸出，d=1.35 可涉渡）+ **鱼塘 2~4 口** + **水田 rice**（岸域小田）。
- **滨河街沿岸线偏移**（`bankPt(i,bank,ROFF)`，ROFF=RIVW+6）：旧版沿**主桥切线**直铺 62~80m，河湾处街尾滑到对岸/入水 ⇒ 跨河违规的根因之一；现街心=桥头核心/对岸堍，两翼沿岸线走。
- **growClear 四级阶梯**（跨河硬约束）：直连 → 远河 via 点绕 → 沿本岸绕（最近河顶点本岸外偏点）→ **拦河截断 `growCap`**（逐步判跨河，遇河即停，折线终点=本岸临水点）。旧版末级是"直连返回"，违规交给探针揪 ⇒ 实测 19/125 张图带跨河路面；现阶梯保证"任何路面线段×主河交点必落在桥矩形内"（探针零违规）。
- **岸别单源**：`bankOf / bankNrm / bankPt` 同为**左法向**口径（+1 侧 = `CORE_BANK`）。符号写反会让"本岸街"铺到对岸（seed 100350 实测：阶梯兜底随即造出跨河路段）——已固化为红线⑥。
- **旗点 = 路网折点**（贴路 0m 恒真）：`广场`(主桥头堍=核心) + `二桥`(非主桥本岸桥堍，road 阶段登记 `WATERWORKS` 锚点) + `渡口`(徒涉滩本岸滩头接巷端点；有滩才摆) + `对岸`(对岸路顶点) + `上村`(本岸路顶点)；后两者打分=「与既有旗间距最大 − 0.5×|环距−84|」。旧版极坐标抽样（74~95m 半径带）半数方向落水/被广场净空拒 ⇒ 实测 63% 的图只有 2 旗；现 water 旗数 **4~5 恒真**（4=无滩，5=有滩）。
- 两军基地分列两岸（河湾内收档 baseOK 逐档内收至 `rivDist ≥ RIVW+26`）。

## 五、建造阶段（js/05c-layouts.js / js/05-world.js）

1. **铁路铺装**：`D.rail` 折线逐段 `railLine`（05b 既有件，纯视觉 0.08m 可碾过）。
2. **桥头工事**（water）：每座石桥两岸桥头各一段沙袋（桥面轴向退 ±(len/2+3)，沿河向错位两节），`footFree` 门避开临河地块足迹——"桥=咽喉"的掩体感。
3. **placeAt 新增 `noWater` 门**（o.noWater=true 时 `inWaterBody` 拒绝）：滨河地块 8 次抖动（±2.5m）可能把建筑推进河/塘（数据层 canTake 只保证**中心**离水 ≥0.5m）。手摆图不传该选项 ⇒ 零指纹漂移。
4. **桥面旗弹药箱**（bug 修）：旧版硬编码**主桥** `bridgePt(-4,1.4)` —— ①水乡 2~3 座桥时二桥/三桥桥头旗的箱子被摆到主桥（距旗 ~90m，探针"附近无弹药箱"抓出）；②桥头旗（离桥心 >16m）也吃这条分支 ⇒ 箱子离旗 18m 且两旗箱位**完全重合**（道具互斥破坏）。现口径：旧位仍贴旗（≤16m）逐位沿用（淞沪/胡康桥面旗零漂移，已核）；否则改"**距旗最近的桥 + 桥面内夹取贴旗点**"。
5. 路旁树跳过 `sub` 类；`railDist` 参与地块/旗点/林地净空。

## 七、零回归红线与已知边界

- **farm 逐位零漂移**：所有群系分支都写在 `if(WATER)` / `if(biome==='town')` 内；共用件只新增"纯函数/不消耗随机数"的助手（`bankOf/bankNrm/bankPt/growCap`）。探针每次跑基线比对。
- **预设图零漂移**：改动集中在 procgen 分支；两处共享件为**加法**——`placeAt` 的 `noWater`（默认关）与桥面弹药箱"最近桥"（淞沪/胡康的桥面旗最近桥恒 = 主桥，已逐图核对）。
- **已知边界**：①"镇集地块总量 > 农村"未作断言（实测 33.7 vs 33.5 基本持平）——镇集身份改由**结构断言**承载（次街/铁路/无农田/排屋线密度），不追总量；②水乡支汊渡口只做地形下切与河岸踏勘，无独立渡船模型；③讨论稿 E 的其余候选群系（丘陵密林/黄土沟壑/雪原冻土/山地隘口）未实现，留作下一批（追加一个 `PG_BIOMES` 键即可接入，但**键序变化会改变全部非 farm 种子的群系归属**——若要保持既有随机图不变应追加到键尾并同步 `dev/_pgbase-capture.js` 的哈希表）。
- **待实机验收**：①同种子三群系观感（farm 田野/ town 街区+铁路 / water 河网+桥+鱼塘）；②镇集次街排屋与站前货栈的巷战手感；③水乡"桥=咽喉"（桥头沙袋、渡口滩）；④小地图/部署图铁路折线；⑤随机图整体建筑量（每图 30~37 地块）在低画质档的帧率。
