### 补充默认口径（本批按此实现，实机验收时可改参）
- 丧尸模式**固定使用随机生成地图**；常规战役不出现丧尸。
- 单队模式：玩家队（玩家+友军 Bot）撑过 **10 分钟**获胜；兵力（票）大池（60），票尽全灭即失败。
- 多队模式：**票=队命池**，票尽该队出局；最后未出局的队获胜。丧尸永不获胜。
- 点数（zombie points，下称 ZP）：击杀丧尸 +15（重尸 +40），占领旗点 +100，开局 200。点数跟随玩家跨重生保留。
- 丧尸近战单发 45（重尸 80），出手节奏 ~1.1s；被丧尸击杀的 Bot 原地变丧尸；人类武器击杀不转化。
- 玩家死亡**无论被谁击杀**都原地留一只普通尸（裁定 #3 字面口径）；Bot 仅被丧尸击杀才转化。

```

                     （在 00-config 之后、01-audio/02-scene/03-terrain 之前载入，纯2D零THREE）
js/03-terrain.js     + case 'procgen' 高度场（缓丘平原，可建性优先）
js/05c-layouts.js    buildWorld switch + case 'procgen' → layoutProcgen()（建造阶段，用 05a/05b 生成器）
js/25-zombies.js     Zombie 实体（extends Bot）/ 三变体 / 脑FSM / 刷怪导演 / 感染链 / ZP经济 / 胜负 / HUD
js/11-soldiers.js    buildSoldierMesh(+zombie 皮肤参数：褪色军装/灰皮)
```

**模式开关**：`ZOMBIE_MODE`（00-config 读 `sf_zsub`，'solo'|'teams'|''）。不改 `GAMEMODE`（const，避免全局翻新）；procgen 战役条目 mode:'conquest'，丧尸逻辑全部走 `if(ZOMBIE_MODE)` 前置分支。

**模式标识**：`CAMPAIGN.mode` 保持 conquest → 占旗/歼灭等既有判定在"普通玩法"下原样可用（裁定 #1）。

## 2. 随机生成地图（重点）

### 2.1 确定性与种子系统
- 独立 PRNG `pgRand()`（mulberry32），种子来源优先级：URL `?pseed=` > `sf_pseed`（菜单输入）> 每局随机。HUD 与结算显示种子号。
- 与现有 `wr()` 流**零交叉**：非 procgen 图 00c 直接 return，不碰任何随机流（红线：wr 调用序承载布局指纹）。
- procgen 图上把同一种子同步喂给 `wr()`（若 05-world 的 ?seed 通道可编程触发）→ 同种子全保真复现；若不可行则保证"布局级复现"（建筑内微抖动不承诺）。

### 2.2 生成管线（Parish-Müller 简化版，双阶段）
**数据阶段（00c，纯2D）**
1. **基底**：地图 640×640m。村镇核心 = 内偏随机点；两军基地 = 对角/对边对称位。
2. **路网生长**（全局目标+局部约束）：
   - 主路：从图边 2~3 个入口点向村镇核心直线生长，步进 8m，每步对目标方向加扰动、做"离水/离已建路太近则吸附"约束；
   - 支路：主路中段随机分岔 1~2 级，长度衰减，终点吸附回主路或散入田野；
   - 产出 `CAMPAIGN.roads` 线段数组 `[x1,z1,x2,z2]`（现格式：03-terrain 压平 :1054、22-hud 小地图 :109、15b 车队、22a 菜单沙盘均直接消费）。
3. **街区→地块**：路段两侧膨胀 8m 生成街区多边形带；对每街区做 BSP 递归细分（最小地块 90㎡，长宽比 1:4 内）→ 地块列表。
4. **旗点/基地/出生点**（战斗逻辑层，硬规则）：
   - 3~5 个旗点：广场旗（核心）、路冲旗（两条主路交汇附近）、边缘旗（村镇外围地标：教堂/水塔/谷仓）；
   - 旗点间距 ≥90m、距基地 ≥120m、旗点圈 r=13m 内不放建筑；
   - 双方出生强点对称镜像布置，净空 11m。

**建造阶段（layoutProcgen，05c 内）**
5. **建筑填充**：地块按区位选型——核心区民宅（华北=cnHouse / 欧洲=twoStoryHouse+logCabin），主街商铺面（欧洲两层楼/华北正房），外围大跨度建筑（谷仓/茧厂 silkFactory/教堂占整地块当 landmark），工厂类只摆村镇边缘；朝路摆放（正面朝最近路），foundation 垫平，freeSpot/B_FOOT 互斥。
6. **地物**：地块边界篱笆/树篱（hedgerow/stoneWall），路旁残骸/木箱/沙袋配额（掩体密度：每 40m 路段 ≥2 处掩体），村外农田(RURAL_FIELDS)+树丛+田埂。
7. **战斗审计**（布局尾部自检，违规自动修正）：
   - NAV 连通性：村庄核心区 walkable 分量必须唯一，否则打 NAV_CLEARS 补通道；
   - 通视走廊：主路每段最大连续无掩体视距 ≤70m（超了插残骸/拒马）；
   - 出生点/旗点占位复查（freeSpot 失败则换位重试 ≤5 次）。

### 2.3 主题双开
- 种子决定 theme：偶=华北（CAMPAIGN.theme='china'，复用 cnHouse/水车/茧厂/碳楼/石桥），奇=欧洲（theme='green'，barn/church/twoStoryHouse/windmill/水塔/木栅栏）。
- 不新增 THEMES/WX_IDENTITY 条目：00c 直接写 `CAMPAIGN.theme`，`WX_IDENTITY.procgen='clear'` 一条静态项。
- 语义表键防线：00c 生成时把所选 layout 家族要求的全键写齐（flags/bases/spawns/roads/steppe 族不适用则不挂），探针逐一断言。

## 3. 丧尸模式

### 3.1 Zombie 实体（25-zombies.js，`class Zombie extends Bot`）
- **复用面**：入 `soldiers` 数组 → 所有命中检测（fireBullet/raySoldiers/爆炸 damageStructures）/小地图/击杀播报自动生效；构造走 `buildSoldierMesh(team2, name, {zombie:true})` 换皮（褪色军装+灰皮+无枪）；腿部动画沿用 `Bot.updateMesh` 的 `legIKPose` 通路；**双臂前伸**=重写臂部 IK 目标为肩前方固定点（带 sin 晃动），不进枪械 mount 分支。
- **票务豁免**（红线，学 capCrew 14-bots.js:459）：`die()` 不扣 tickets、不触发兵力清场；`fieldCount`/`updateSpots`/`updateFlags` 占领计数/wipe z0z1 统统 `if(s.zombie) continue`（team=2 落在 `else c1++` 分支的坑由此堵死）。
- **三变体**（同模改参）：普通尸 speed 1.5/hp 100；跑者 speed 4.2/hp 60/见人即冲刺；重尸 speed 1.1/hp 380/伤害 80/对工事 3× 伤害/体型 1.12×。

### 3.2 脑 FSM（低智力，用户口径逐条落地）
```
SHAMBLE 游荡   —— 朝"最近人类聚集点"走（聚集点=存活人类位置加权质心 + 旗点位置，每 3s 重算）
SPOTTED 奔跑   —— 视距内(<28m)见到人 → 追击该目标，速度切跑步
AGGRO 迁怒     —— 受击瞬间：仇恨立即转移到攻击者（无视视距，持续 6s）
LOST 丢失      —— 目标死/超距(>45m)/失联 6s → 回 SHAMBLE
MELEE 近战     —— 距离 <2.2m：抬臂挥击，1.1s 一拍，45 伤害；对工事走 damageStructureBy
```
- 感知不做 FOV 限定（尸不转头）、不检 LOS 高级遮蔽（作物/烟可挡：复用 cropBlocksLOS/smokeBlocksLOS 即可， cheap）。

### 3.3 感染链
- Bot 被丧尸击杀：`damage(attacker=zombie)` 路径打 `zombieKill` 标 → `Bot.die` 检测：若 `killerIsZombie` → 不出担架/不掉票，原地 `new Zombie(该位置)` + 本体隐藏移除。
- 玩家死亡：`player.die` 末尾（zombie 模式）在尸体位 spawn 一只普通尸（无论死因，裁定 #3）；死亡/重部署流程零改动。

### 3.4 刷怪导演（三阶段连续压迫）
| 阶段 | 时间 | 场上上限 | 构成 | 刷速 |
|------|------|---------|------|------|
| P1 潜入 | 0–3.5min | 8 | 普通尸 | 1只/6s |
| P2 围攻 | 3.5–7min | 18 | 普通+跑者20% | 1只/3.5s |
| P3 白热 | 7–8.5min | 26 | +重尸10% | 1只/2.5s |
| 决战潮 | 8.5–10min | 40 | 三类齐上 | 1只/1.2s |
- 刷点：地图边缘 + 距任何存活人类 ≥55m 的合格点（复用 DEATH_HEAT 反向思路）；单队/多队同参。
- 上限含"感染转化"的尸。10 分钟撑过 → 单队胜利；多队按 §3.5。

### 3.5 胜负（21-match 前置分支）
- `ZOMBIE_MODE==='solo'`：倒计时 HUD；票尽全灭 = 失败；`surviveT≥600s` = 胜利（requestEnd(0)）。
- `ZOMBIE_MODE==='teams'`：票尽 → 该队出局（播报"红方全灭"），场上有 ≥2 队未出局则继续；只剩 1 队 → requestEnd(该队)。丧尸不占旗不被占旗结算（旗点仅人类队争夺，占旗给 ZP）。

### 3.6 点数经济与工事
- ZP：HUD 常显；击杀 +15/+40、占旗 +100、开局 200。
- 建造（复用 06-engineering 读条链）：免费件 sandbag/wire/hedge（全职业可用，丧尸模式下）；商店件 mg42(150)/弹药箱(80)/塔楼 watchtower(250)，扣 ZP，读条同链。
- **工事可破坏**：engBuildExec 落地后把 BUILDS 条目登记为轻量 DESTRUCTIBLES（hp：沙袋300/铁丝100/拒马150/MG400/塔楼500），命中走 damageStructures 既有 boxDist3 通道；重尸对工事 3×。摧毁返 0（不退款），敌方队伍可主动拆（打掉即可）。

### 3.7 表现层
- 皮肤：uniformMats 加 zombie 档（灰绿褪色）；跑步/走路腿动画正常，双臂前伸+晃动；死亡转化时原地起身（0.8s 爬起动画=从躺到站的 pose 插值，简版）。
- 音效：`AudioSys` 加一次性 `zgroan(dist,pan)`（附近尸随机低吼，2~4s 随机间隔，距离衰减复用 spatial()）；无循环引擎，endMatch stopAll 链零负担（红线 #10）。
- HUD：阶段横幅（"尸潮渐起/围攻/白热/决战"）、存活倒计时（solo）、ZP 计数、出局播报。
