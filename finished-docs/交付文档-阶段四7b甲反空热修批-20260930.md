## 2. 根因（实测，file:line 可溯）

1. **反空超雄**：难度表对空中挨打几乎无效——
   - 高炮瞄准点随机散布 ±25m **写死**（旧 js/14-bots.js:1866），不随难度变，主导弹着散布；
   - `Plane.takeDmg` **不乘** `DIFF_TABLE.dmgMul`（伤害倍率只接在打步兵那条链，js/13-combat.js:239）⇒ 新兵/老兵/精英挨同一发高炮都是 20~34；
   - AI 机 240m 内每帧 90% 进缠斗（旧值）+ 0.075s 齐射 + 3.2m 圆柱直检 11.9/轮，**全都不吃难度**；与你共用同一套飞行模型 ⇒ 甩不掉。
   - 机 hp 90~140，被 2~3 门高炮覆盖 ≈ 2~3 秒融化 ⇒「活不了几秒」。
2. **打不到**：`airmg` 档（2.6° 窗口 / 1.9° 上限）是「差半步」微调档，空战实际误差 5~20° 掰不动；命中是瞬时射线但无任何提前量/锁定指示，交叉目标角速度 30~45°/s 人手追不回。
3. **速度**：顶速 = spd1×overMul = 64×1.22 ≈ **78 m/s**，全油门与俯冲都顶在钳制上。

## 8. 追加：bootFail 黑屏事故修复（同日, 版本戳 c 的由来）

用户 Ctrl+F5 后主界面变「bootFail 态」（菜单静态 DOM 在、战役卡全空、战斗 HUD 全裸、画布全黑、左上小地图空框）。根因**不在游戏代码**：`three`/`cannon` 原从 jsdelivr CDN 现拉（index.html 原第 331-332 行、不带版本戳），硬刷新会连同 CDN 一起绕缓存重拉，CDN 拉不到 ⇒ `THREE` 未定义 ⇒ 脚本链首用即抛 ⇒ 页尾兜底摘 inMenu（`__sfBooted` 未置位）⇒ 截图症状。Node 沙箱全绿（桩化 THREE）所以此前无感。

修复（`?v=` 升 20260930c 的原因）：

1. **依赖库本地化**：`lib/three.min.js`（r152，与 dev/vendor 探针副本同源）+ `lib/cannon.min.js`（0.6.2）收进仓库，index.html 改引本地（file:// 离线可用，永绝 CDN 依赖）；`lib/` 为新增未入库文件，下次提交记得 `git add lib/`。
2. **boot 报错屏上可见**：头部全局 error 钩子（capture=true——资源加载失败不冒泡）记 `__sfErrs`；bootFail 时页尾兜底把错误写进 `#bootErr` 大字浮层（css 已配样式）。以后再出 bootFail，屏上直接可读错误行。
3. **回归守卫**：verify-spec T8 新增 `cdn.jsdelivr` 阴性断言（禁止改回外链）；全量 run-all-verify **36/36 全绿**。
