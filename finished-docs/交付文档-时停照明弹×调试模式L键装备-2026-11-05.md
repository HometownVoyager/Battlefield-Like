## 二、病根链（实证过程留档）

### ② 时停照明弹
沙箱用受控时钟直驱 `24-main` 的 `loop()`（时停账只在主循环里生效，直调 nightGearTick 测不出真实行为），逐帧插桩：时停开着时 `specTimeFrozen()===true`、`specTimeConsume(rdt)===0`、`dt===0` 全部正确，**而 nowT 照走**（3 帧恰好 +3×rdt）。

```
24-main.js:52   else if(dt!==rdt) nowOff+=rdt-dt;      // 秒
24-main.js:54   nowT=(now-nowOff)/1000;                // 表盘是毫秒
```

nowOff 每帧只"冻掉" 0.0167 **毫秒**而不是 16.7 毫秒 ⇒ 游戏时钟在时停里以 ~99.9% 墙钟速度继续走 ⇒ 一切 nowT 基相位（旗点照明弹 `p=((nowT-fl.t0)%period…`、探照灯扫掠 `sin(nowT*0.22…)`、火光 flicker）都在"冻结"里照常动。指挥减速（×0.2）同理失效。**照明弹只是用户看得见的那一个症状。**

**本批不修 24-main 单位错位本身**：整体修法是 `(rdt-dt)*1000`，但会一次性冻结观察者链上所有混用 nowT 的门（体能回充 `nowT-stamUseT>1`、观战补给节流 `_specSupT`、HUD 指纹节流等）——玩家本人是"时停不冻观察者"红线的主体，需要专项批逐处对账后再动。已在 24-main 病根行留已知问题注记。

### ① 调试模式装备
- **手电双门锁死**：`19-input` L 键步行分支 `else if(player.alive&&!player.spectator)` 与 `playerFlashlightTick` 的 `on=…&&!player.spectator&&…` —— 调试观战（spectator=true 但 **alive**，是正常作战单位）被这两道门排除；部署时 23-deploy 明明已按 isDarkEnvironment 给了 `p.flashlight=true`，渲染层不认。
- **幽灵坦克不在大灯链**：幽灵坦克是 15c 单例 `SPECVEH`，**不在 tanks/trucks/navalCraft 任何一张表里** ⇒ nightGearTick 的候选收集 / 真灯池竞选 / 假光锥防穿墙三段全扫不到它；L 键能开（vehHeadlightToggle 无观战门）但只有假光锥，真 SpotLight 永远轮不到 ⇒ "没有实际效果"。
- **晴天白天整段不放行**：24-main 门 = `NIGHT_MODE || isDarkEnvironment() || player.flashlight` —— 晴天图里 nightGearTick 根本不跑，真灯池（`_hlPoolEnsure` 惰性建）永不上场。

## 三、落地明细（六件）

1. **战斗钟单源（08-effects）**：`let _ngT=0` + nightGearTick 首行 `_ngT+=dt`；照明弹相位 `p=((_ngT-fl.t0)…`、飘移 `sin(_ngT*0.35…)`、探照灯扫掠 `sin(_ngT*0.22…)` 全换；`_fireT` 同法（updateFireLights 双入口经 `_lastT` 去重只累一次）供 flicker/抖动。时停 dt=0 全冻结；指挥减速 ×0.2 同步慢放；非时停零漂移（时序与旧版逐位同源，只是换表盘）。
2. **照明弹段 isDark 门**：`if(isDark){ …照明弹 init+循环… }`，`bestFlare` 声明提到门外 —— 亮环境恒 null ⇒ 灯池走全灭分支。随第 5 件（24-main 门放宽）新增的护栏：晴天开车灯不会凭空长出照明弹；雨昼（isDarkEnvironment 命中）行为与旧版逐位一致。
3. **调试模式战术手电**：`19-input` 步行分支改 `else if(player.alive)`（带批注）；`playerFlashlightTick` 的 `on` 判据删 `!player.spectator`。夜图部署自动持电走 23-deploy 既有单源不变；L 键开关+提示语+音效照常。
4. **幽灵坦克入大灯候选链**：nightGearTick 候选收集尾补 `if(typeof SPECVEH!=='undefined'&&SPECVEH&&SPECVEH.alive&&SPECVEH.lightsOn){ SPECVEH._d2=_hlD2(SPECVEH); cands.push(SPECVEH); }`（收车 `SPECVEH=null` 自动退出；isAI=false 天然不吃 AI 状态机，L 键自管口径不变）。挂点无需特判：`vehHeadlightBuild/_hlWorld` 的 `tkSpec(GHOST_DEF, undefined)` 落进 TB_TK_DEF 缺省档，默认 hullW 2.6 / hullY 1.0 / hullH 0.95 与幽灵车体建模参数完全同参（fz=L/2+0.04=2.99 对车鼻 2.95）。
5. **24-main 门放宽 `_hlRideOn`**：`player.onVehicle/onNaval` 开着大灯也拉起 nightGearTick —— 晴天按 L 才有真光。AI 载具不受扰（晴天 isDark=false ⇒ 状态机 want=false，本就全灭）。
6. **文案与词典**：部署提示补 `· L=手电/大灯`（23-deploy 与 00b-i18n 短词条键同步）；游戏说明「调试模式」段补 `<b>L</b> 战术手电(步行)/载具大灯(含幽灵坦克, 夜晚照明)`（index.html 与 00b-i18n 长词条 726 字键**全文一致已程序化验证**）。

## 五、实机验收清单（用户操作对应）

1. **时停照明弹**：夜图（或选「黑夜」）+ 调试模式，等旗点照明弹升空后按 K —— 照明弹应**冻在半空**（光点/地面亮斑/缓降全部停住），探照灯光柱不再扫动；按 K 解冻后继续缓降。指挥官减速（V）下照明弹应同步慢放。
2. **调试模式手电**：调试模式步行按 L —— 第一人称出现战术光束、地面真被照亮（夜图自动持电开机；白天手动开也有真光）；再按 L 关。第三人称时人身上有手电道具。
3. **幽灵坦克大灯**：调试模式 F 召唤幽灵坦克上车按 L —— 车前两道光锥 + **地面真被照亮**（夜图效果最直观；晴天也有真光只是不明显）；车灯射到墙上光锥应被墙截断不透墙。
4. **晴天护栏**：晴天图按 L 开大灯后，旗点上空**不应**冒出照明弹、探照灯不应出现。
