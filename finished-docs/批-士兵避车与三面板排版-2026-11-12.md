## 一、士兵避车（js/14-bots.js）

### 病根

`_botMoveProbe` 此前只查静态 OCC + 膝高射线；载具是动态实体不在 OCC 里，走位的 Bot 一头撞进车壳，只靠 `vehiclePushSoldiers` 的侧向推挤硬顶——观感就是"贴着坦克又推又卡"。残骸（state='wreck'，只注册 DynCollider 不再走推挤）是街口卡死最常出的实体。

### 修法（探针三件套 + 两个门）

- `_vehObsDims / _vehObsTest / _vehProbeBlocked` 三件套：车壳 OBB(+0.5m 余量) 也算障碍，尺寸与推挤几何**同参**（坦克 `hx=max(2.05,halfW)` / `hz=def.hullL/2+0.45`，卡车 `hx=1.05` / `hz=3.7`，两栖艇同坦克；15-vehicles:1041 / 15b-trucks:130 / 15d-naval:973）；
- `_botMoveProbe` 探针点（前方 1.1m）落壳内 = 此路不通，`moveDir` 的备选角扫描（MOVE_DA）自然沿壳绕行；
- **游泳态/甲板行人放行**（与水障格同规；甲板行人不躲甲板下的艇壳，否则大舰甲板上寸步难行）；
- **toVehicle 认领目标豁免**：要贴壳才够到上车判定（2026-11-03 `_surf<0.55` 口径）；朝旁车探仍挡；
- **yMax=1.9 高门**：高处步兵不躲车壳（与 `vehiclePushSoldiers` 同门）；
- **残骸照挡**；
- `moveDir` 全向堵死时的 dirFlip 兜底侧移也要过探针——侧移向不通就本帧驻足（speed=0），不再无探针位移；
- 脱困绕行点（stuckN≥3 垂直插点，14-bots:2219）也拒壳内。

### ★端到端探针实锤的第二病根：粗筛轴界不随 yaw 旋转

首版端到端 T7 红（minSurf −0.5）：横车（yaw=HPI）拦路时 ±0.55/±1.1/±1.65 角全被误放行，侧腹撞壳。逐帧插桩（pos/sd/分支/探针点独立挡放+壳距/七角探针序列）定位：`_vehObsTest` 的轴对齐外接盒粗筛拿**局部** `mx/mz` 直接当**世界**轴界——车一横（yaw=HPI）两个界正好互换，探针点偏出横向廊 2.55m 但仍在纵向廊 4.4m 内时被判"界外"=放行=侧腹撞壳。`probes[BFBFBFB]` 的对称红绿模式（西侧角全 F、东侧角全 B）是决定性指纹。

修 = 世界 AABB 半宽 `wex=|mx·cs|+|mz·sn|` / `wez=|mx·sn|+|mz·cs|` 随 yaw 旋转（yaw=0 时与旧界相同，T3/T4 判据不受扰动）。修后 T7：minSurf **+0.23**（贴壳 23cm 绕过 + 越过坦克纵深 + 到达目标邻域）×5 轮全绿。

## 八、探针坑（本批新）

1. **粗筛轴界必须随 yaw 旋转**：OBB 前的轴对齐外接盒粗筛，其界不能拿局部半宽直接当世界轴界——车一横就互换（T7 端到端实锤；`probes[BFBFBFB]` 对称指纹定位）。判别点要取"两界之间"的窗（|dx|∈(mx,mz)）才能钉住。
2. **lookahead 探针的"盲区"是假病根**：插桩曾显示"探针点已出界仍挡不住人"，追真身是粗筛误放行——端到端红先逐帧插桩（pos/sd/分支/七角探针序列/探针点独立挡放）再归因，别急着给探针加"当前位也查"一类的补丁。
3. **openSpot 净空环要带周边环**：只查落点本身会踩在静态水格边上（occBlocked 第三参未传时深水按挡处理——undefined ≠ false），探针点 1.1m 前瞻一伸就进水格，行为判据全歪。
4. **NEG 'to' 串要数括号**：去中间条件的单行 patch，删完必须括号平衡（本批 patch B 实为平衡，虚惊记档）。
