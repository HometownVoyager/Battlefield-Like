## 1. 目标 / 非目标

**目标**
1. 开始界面新增「昼夜」选择，对 **14 张战役图全部生效**（每图都有白天/黑夜两个模式）。
2. 黑夜不止换色：视觉、Bot 感知、信息规则、（二期）照明装备全面差异化。
3. **白天档零回归**：白天档所有常量与现值逐位相等，任何夜档改动不得泄漏到白天。

**非目标**
- 不做昼夜循环/黄昏过渡（固定两档，无插值）。
- 不做运行时热切换（沿库内 reload 惯例，切档即 `location.reload()`）。
- 不改地图布局/摆件/植被数量/旗点/出生点——**昼夜两模式地图几何完全一致**（保布局指纹与探针可复现）。
- 不做夜视仪、不做动态天气×夜的组合新档（夜档系数与既有天气系数简单相乘即可）。

## 3. 架构：夜间修正层

**核心思路：夜档不是一张通用夜景，而是叠加在每图 THEME 之上的"夜间修正层"**——雪夜、丛林夜、海夜各是各的，14 图自动获得夜景。

### 3.1 开关与存档
- 菜单（与难度/画质同面板）新增「昼夜」optBtn：`昼/夜` 两档，存 `sf_daynight`（'day'|'night'，缺省 'day'），切档 reload。
- 00-config 启动回读 `sf_daynight` → 全局常量 `NIGHT_MODE`（bool）。**全库唯一判据**：`isNight()` 语义等价于读它（是否包一层函数以探针友好，动工时定，但必须单源）。
- ironbottom：昼夜钮置灰显示「固定·夜」，`CAMPAIGN` 为 ironbottom 时强制 `NIGHT_MODE=true`。

### 3.2 单源系数表 `NIGHT_CFG`（00-config，初值为调参档，实测后可调）

```js
const NIGHT_CFG = {
  // —— 视觉 ——
  sky:            null,   // 夜空渐变统一用 nightsea 色板基线(00-config.js:1107 那组);
                          // 若某 THEME 配 skyNight 则覆盖(留口子，一期可全空)
  fogFarMul:      0.55,   // dryFogFar ×（半月偏暗：比满月档收得更紧）
  fogNearMul:     0.8,
  fogMix:         0.6,    // fog 色向夜蓝 0x101a28 mix 的比例（保留各图 fog 色相差异）
  hemiMul:        0.45,   // hemi 强度 ×（nightsea 满月档是 0.55，半月更暗）
  sunMul:         0.30,   // sun(月光)强度 ×，色固定冷蓝 0xa8c0e0
  exposure:       0.72,   // 覆盖 toneMappingExposure(白天 1.05 不动)
  vmLightMul:     0.5,    // 第一人称 vmScene 灯 ×（枪不能在夜里独亮）
  flashRangeMul:  2.2,    // 枪口/爆炸 PointLight 作用半径 ×(白天被环境光淹没的补偿)
  // —— 感知/玩法 ——
  viewDMul:       0.55,   // Bot 索敌(实战档 R2)
  hearGunMul:     1.5,    // 听枪声/枪口事件半径 ×(开火暴露加大)
  aimMul:         0.65,   // aim assist 搜索距离 ×(吸附不替你打看不见的人)
  rangeMul:       0.7,    // huntR / EMPL_AA_ENGAGE_R 等独立交火半径 ×
  // —— 小地图夜规(R3) ——
  mapNearR:       60,     // 近距常显半径
  mapFireT:       2.5,    // 开火后显形时长(复活 2026-09-06 之前的旧规则值)
};
```

## 4. 二期装备（R4 四项全批）

### 4.1 车辆大灯
- 坦克/卡车/小艇可开关（**键位已定：L** —— 动工时通读全键表，候选 V/H 都被近战/包扎占用；提示走 showScorePop + i18n）。
- 渲染：玩家附近车辆=真 SpotLight（数量上限 2-3，超出降级为假光锥 mesh additive）；远处=假光锥。大灯同时照亮路面与暴露自身。
- 玩法：开灯车辆进入 Bot 索敌时 `viewD` 对其放大（如 ×1.8，调参档），无视部分 FOV 门；AI 车辆夜间行进开灯、交火关灯（简单状态机）。

### 4.2 旗点周期照明弹
- 仅占旗图（assault/conquest）：旗点上空周期（≈28s，相邻旗错峰）照明弹升空→缓降→照亮半径内地面，持续 ≈8s。双方公平、零操作。
- 渲染：同屏最多 1-2 盏真 PointLight（复用 flashLight 模式或灯池），照明圈用地面亮斑 mesh + 粒子。落点/周期**不进布局种子**（保持几何一致红线）。
- 玩法：照明半径内 Bot viewD ×1.4（调参档）。

### 4.3 探照灯
- 复用塔拉瓦炮台/灯塔静态几何：光柱锥 mesh（additive）+ 扫掠动画。
- 玩法：光柱照中玩家 → 对该玩家 Bot 索敌距离翻倍 + 无视 FOV 门（被咬死的惩罚要重）。
- 海战：旗舰可配一具（二期尾巴，做不做看工期）。

### 4.4 飞机夜航灯
- 翼尖红/绿闪（Sprite 或 Points），纯视觉零玩法，所有夜档固定开启。便宜货，可提前到一期尾巴。

## 6. 已知坑与纪律（动工必读）

- **白天零回归是第一红线**：所有夜档改动必须门控，合并后先跑一遍白天档冒烟。
- 探针载入清单必须与 index.html 实载脚本一致（D1 两轮假绿的根；**实数 43 个**，2026-10-05 勘误——本设计文档旧写"41"已过期，19b-gamepad 与 15h-capital 后加入）；新探针按 FILES_SPEC 样板登记，最好与 index.html 动态对账不写死数字。
- 布局断言类探针在种子下约 1/20 偶发（mgSpot 用 Math.random）——夜档验收判据避开布局指纹；照明弹/大灯不得进种子。
- 版本戳按惯例两处一起升；judgment 别写死行号。
- ironbottom 的 overcast×夜档双重压暗是现成校准样本：先调它，再推广全图。
- 曳光弹（1/(def.tracer||3) 发射概率）夜里天然醒目，一期不额外加强；若实测夜战"开火=必暴露"过强，调 `hearGunMul` 而非改弹道。
