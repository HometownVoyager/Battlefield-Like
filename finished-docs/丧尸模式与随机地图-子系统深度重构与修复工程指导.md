## 一、背景与问题总览

近期引入的“丧尸模式”（单队生存/双队对抗）与“随机地图”（Procgen 三大群系）子系统虽然搭建了基础原型，但在实机运行中暴露出大量结构性冲突、逻辑断层与实现 BUG。

核心病灶集中于：
1. **胜负规则与对局流断裂**（`js/21-match.js`、`js/25-zombies.js`、`js/14-bots.js`）：旧版丧尸感染将 Bot 置为不再复活（`respawnT = 1e9`）且不扣兵力票，导致淘汰判定逻辑错位或在全员阵亡时直接判负，玩家虽剩余数百票却无法重生且被判定战败。2026-10-11 用户裁定修复为：感染消耗兵力票并允许正常倒计时重生；在场人员覆灭但有票数时进入票数自然流失状态（2票/秒），失败判定恒为“无票数（`tickets <= 0`）+ 无在场人员（`fieldCount === 0`）”。
2. **AI 与寻路机制缺失**（`js/25-zombies.js:184-214`、`js/25-zombies.js:155, 405`、`js/14-bots.js:845`、`js/15-vehicles.js:1161`）：丧尸完全没有接入 A* 寻路，直线冲锋导致大面积撞墙卡死；双队模式下两队均值质心落在中心无人区，导致全图丧尸在中心发呆、人类见不到丧尸；人类 Bot 面对丧尸自杀式拔刀肉搏；坦克 AI 驻车后沦为只能被扒车刮痧的不会动的靶子。
3. **物理判定与时钟漏洞**（`js/25-zombies.js:246-248`、`js/25-zombies.js:90-103, 297-316`）：丧尸近战挥击缺少垂直高度（Y 轴）门限，隔着数米高台或楼板击杀玩家；伤害延时采用原生 `setTimeout` 脱离游戏主时钟，暂停时仍受创；自爆尸（Boomer）被射杀不殉爆。
4. **随机水乡群系严重破损**（`js/00c-procgen.js:457, 845`、`js/03-terrain.js:665-678, 1008`、`js/05c-layouts.js:2517`）：水网地形在 `case 'procgen'` 下完全未进行地形下切，导致鱼塘和支流整片水面悬空浮在干草地上 10cm；水乡被误判为“深谷激流”，导致乡村小河秒杀步兵与坦克；副桥桥面未连通路网。
5. **单队生存对聚落肌理的破坏**（`js/00c-procgen.js:194-197, 496`、`js/00c-procgen.js:330-334`、`js/05c-layouts.js:2320, 2371`）：主基地强行设于市中心，触发了 30m 基地净空门，将整个村庄核心广场掏空成不毛荒地；干道与主街重复叠加；预设图基地移至中央教堂引发严重模型穿模。
6. **建造经济与文化资产破损**（`js/19-input.js:254, 260`、`js/06-engineering.js:168, 201`、`js/00-config.js:155-188`）：非工程兵按键锁死无法建造“免费件”；建造缺少造价配置导致显示 `undefined`；中式群系（华北/水乡）充斥欧美小木屋与美式红砖谷仓。
7. **界面 HUD 阵营穿帮与多局泄漏**（`js/22-hud.js:919, 922`、`js/21-match.js:472`、`js/25-zombies.js:388-393`、`js/22-hud.js:1256`）：选 1 队开局时顶栏兵力条与结算页硬编码显示 0 队；顶栏征服时钟与正中生存倒计时双钟冲突；`zHudEl` 与 `ZOMBIES` 跨局未清；菜单点“开始新游戏”强行退回普通模式。

## 二、架构原则与开发红线

在执行后续重构与修复时，必须严格遵守以下六条工程红线：

1. **胜负判定与兵力票流失（红线 1，2026-10-11 用户裁定）**：
   * 淘汰/负场判据恒为“无票数（`tickets <= 0`）且 无在场人员（`fieldCount === 0`）”。
   * 丧尸感染转化为丧尸时扣除 1 兵力票，士兵进入正常重生倒计时（`respawnT = rand(7,11)`），仍可消耗票数重生。
   * 若一方在场人员全部被感染/阵亡（`fieldCount === 0`）但仍有剩余票数（`tickets > 0`），赋予票数自然流失状态（2票/秒）；期间仍可正常消耗票数重生/部署，一旦有人重返战场（`fieldCount > 0`）则流失立即停止。单队模式撑过时限胜利由 25-zombies 导演判定。
2. **寻路与物理一视同仁（红线 2）**：
   * 丧尸单位必须受场景障碍（房屋、围墙、河流）约束，不得依靠粗暴穿模，也不得简单依靠直线移动。
   * 近战、自爆伤害必须具备完整三维判定（包含高度差 `Math.abs(dy)`），严禁出现高台/楼上隔空受创。
   * 严禁在游戏战斗逻辑中使用真实世界时钟 `setTimeout` / `setInterval`，所有延时必须由主循环帧长 `dt` 积分驱动。
3. **水文与高度场单源驱动（红线 3）**：
   * 水体（水面网格、物理水深、涉水减速、激流）与高度场必须严格对齐。下切深度是多少，水面就必须落在该深度之上，严禁出现水面浮空于地表或地表高过水面的脱节现象。
4. **文化风格与主题严格匹配（红线 4）**：
   * 中式战场（华北/水乡）建筑素材池严禁混入西欧原木木屋（`logCabin`）与美式大谷仓（`buildBarn`）；欧美战场严禁出现中式碉楼（`watchtower` 中式贴皮）与中式砖瓦房。
5. **既有战役与模式零回归（红线 5）**：
   * 随机地图与丧尸模式的任何改动，对既有 13 张预设战役卡（诺曼底、斯大林格勒、柏林等）在非丧尸模式下的运行必须实现**逐位零漂移**。
6. **自动化回归与实机体验并重（红线 6）**：
   * 探针不能仅仅停留在“配置存在、函数不抛错”，必须覆盖真正的行为级不变式（如：单队全灭当场判负、双队各自追逐最近人类、水面低于两侧河岸）。

#### 【改造规范】


#### 【改造规范】

##### (1) 多队质心独立采样
修改 `zAnchor()` 与游荡目标计算：
```javascript
function zAnchor() {
  // 按照队伍分别统计存活人类
  const teamsAlive = [[], []];
  for (const c of combatants) {
    if (!c.alive || c.zombie || c.onVehicle || (c.isPlayer && c.spectator)) continue;
    if (teamsAlive[c.team]) teamsAlive[c.team].push(c);
  }
  // 随机挑选一支还有活人的队伍作为本轮尸潮施压目标，严禁跨队伍求几何平均
  const candTeams = [0, 1].filter(t => teamsAlive[t].length > 0);
  if (!candTeams.length) {
    return (typeof BASES !== 'undefined' && BASES[player.team]) ? BASES[player.team] : { x: 0, z: 0 };
  }
  const tgtTeam = candTeams[Math.floor(Math.random() * candTeams.length)];
  const members = teamsAlive[tgtTeam];
  let sx = 0, sz = 0;
  for (const m of members) { sx += m.pos.x; sz += m.pos.z; }
  return { x: sx / members.length, z: sz / members.length };
}
```

##### (2) 结合 NAV 网格的轻量级寻路修正
丧尸不需要每帧进行沉重的 A* 计算，但当向目标直线前进遭遇 `occBlocked` 碰撞阻挡且卡死超过 0.4s 时：
* 取当前格坐标 `toG(this.pos.x, this.pos.z)` 与目标格 `toG(tx, tz)`；
* 若距离大于 8m 且直线不通，调用 `NAV.findPath(this.pos.x, this.pos.z, tx, tz)` 获取前 2~3 个局部路标（Waypoint）；
* 沿路标拐过建筑转角后，重新切回低开销的直线冲锋。

```javascript
      const cw = (CAMPAIGN.delta && CAMPAIGN.delta.w) || 3.4;
      for (const ch of PGDATA.dchans) {
        for (let i = 0; i < ch.length - 1; i++) {
          const d = segDist(x, z, ch[i][0], ch[i][1], ch[i + 1][0], ch[i + 1][1]);
          if (d < cw) h -= 1.2 * sstep(1 - d / cw);
        }
      }
    }
  }
  return h;
}
```
