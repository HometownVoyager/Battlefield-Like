# 批：油桶殉爆延续 × 弹坑系统 × 油桶残骸 × 火池六分钟（2026-11-18）

> 版本戳 20261118a→**20261118b**。前置：油桶殉爆机制与投射物弹性削减已随 b906eb0 落库（用户原始令"被子弹/炮弹/爆炸/火烧攻击一些次数后爆炸并留下火焰"+ "有限减少手雷等投射物的弹性"），本批是其延续与用户三道追令的落地。

## 用户令（本批四道）

1. **残骸**：油桶爆炸之后就地留下一个残骸，残骸的模型要足够"油桶残骸"。
2. **开局爆炸坑**：地图总是一开始就有几个爆炸坑，而且不会消失——"我认为这是一个严重的系统性全局性问题"。经问询裁定：布局遗迹坑**保留，但一段时间后自然消失，时间不超过人造弹坑的几倍**。
3. **甜甜圈坑（全局性 BUG）**：地板略高于地面时（如胡康河谷的大桥）爆炸坑呈甜甜圈形（环形）。一轮修（盒顶骑升）后用户实测"成了厚一点的甜甜圈形"，并处方：**将地板视作一种"地面"**。
4. **火池二令**：油桶爆炸的火改为**持续 6 分钟且不受天气等影响**。

## 根因

- **开局就有坑**：05c-layouts 35 处刻意的布局遗迹坑（战场氛围装饰），2026-11-15 弹坑渲染修复（terrainSurfaceY 黑弧修）后从"隐形"变"显眼"——不是运行期误爆（无开局火源/油桶受热门把关）。
- **永不消失**：弹坑系统无生命周期——runtime 坑只有 36 上限 FIFO（挤旧不留账），静态布局坑完全无人管。
- **甜甜圈**：桥面/楼板是"结构盒(solidBox, 有碰撞) + 纯视觉铺装层(mesh 0~7cm, 无碰撞)"双层结构；坑盘按地形弦面画，沉在铺装层之下 → 只露唇缘脊=甜甜圈。一轮修按**结构盒顶**骑升（dy+0.05）仍沉在铺装顶（dy+0.07）之下 → "厚一点的甜甜圈"。
- **火短命且怕天气**：BARREL.poolTtl=14s；植被点燃链吃天气三乘子（暴雨浇灭 stormExtinguish / 受潮消耗 burnRateMul / 蔓延压火 FIRE_SPREAD=0.8×fireMul，暴雨档积热 0.85×0.8×0.35≈0.24/s < 冷却 0.25 ⇒ 火不成链）；灼烧伤害吃 fireDmgMul（暴雨 0.45）、士兵燃烧时长吃 burnDur（暴雨 0.8s）。

## 实现

### ① 油桶残骸（05b barrelWreck，05-world barrelBlast 接线）
- `barrelWreck(x,z,gy)`：压瘪焦黑桶身（复用 `_BARREL_G.body` 几何，scale 1.14/0.37/0.92 + 歪斜）+ 掀飞残留翻口沿 + 滚箍残片×2（一道平躺地面/一道斜搭瘪桶肩，复用 `_BARREL_G.rib`）+ 地上焦土贴花 `crater(x,z,1.15,true,gy)`（supY=桶底支撑面 → 桥面上的残骸焦土贴面层顶）。材质懒建三档（burnt/rust/steel，与 wkPaint 残骸同参），Group 随地形法线摆正 + rotateY 随机自旋。
- **纯视觉**：不入 CYLS/BOXES 账（5c688ae"非盒几何碎块兜底回滚"用户裁定口径的延伸——0.3m 高残骸挡坦克炮弹/寻路是负提升）；不进快照 → 世界还原 ① 场景台账自动摘除，下一局是全新战场。

### ② 弹坑生命周期（00-config CRATER + 05b CRATER_LIFE 双账）
- `CRATER={freshTtl:150, scarTtl:450, fadeWin:45}`：战斗新坑 150s / 布局遗迹坑 450s（=3×，符合"不超过人造坑几倍"裁定）/ 尾窗 45s opacity 0.85→0 线性淡出。
- `CRATER_LIFE` 与 `runtimeCraters` **双账并行**：后者保持 mesh 数组原形（36 上限 shift / 23b 快照 craterN / 24-main 性能清账三处既有消费点**零改动**），新账管年龄/淡出/退场。
- 24-main `updateCraters(dt)` 每帧驱动（updateFires 之后；dt<=0 时停冻结——与火焰/投射物同一冻结口径）；账条靠 `m.parent` 探活自愈（被世界还原/性能清账/36 上限挤掉的网格不重复 remove、账不留尸）。
- 23b 还原钩 `cratersResetLife()`：快照里的布局旧痕原对象放回来=全新战场 ⇒ 寿命清零+不透明度回底；局内战斗坑不在快照 → parent 已无 → 出账。

### ③ 弹坑支撑面跟随——"地板视作地面"（05b crater() v2 + 04-collision craterBoxTop）
- `crater(x,z,r,runtime,supY)`：capY=supY（爆点所在支撑面，explosionFX 透传 p.y）+0.45 允差；未传（布局遗迹坑/炮火犁地）=中心地形+0.45。
- **逐顶点**：地形弦面 vs `craterBoxTop`（04-collision，盒顶探查，capY 门+footprint 0.05 容差，noTop/dead 跳过，盒-only 不吃树干圆柱）取高者——地板顶=真支撑面，坑盘贴着地板顶画。
- **面层感知（二轮修，用户处方落地）**：坑心一次探 `craterFloorTop(bt,cx,cz)`——扫 world 顶层纯视觉薄盒件（boxGeo parameters，高 ≤0.16，窗口 (bt, bt+0.15] 对齐铺装族 0~7cm 注记，水平罩住坑心）——有面层 ⇒ 骑**面层顶+0.02**（grandBridge：盘面 dy+0.09=铺装顶 dy+0.07+0.02，贴花档深度偏移吃掉残差）；裸结构盒顶（=渲染面）⇒ 与地形同规 **+0.05**。逐顶点支撑各自取、ride 统一用坑心读数（同一块地板内部一致）。
- **台阶门**：支撑面包络起伏超出地形基线包络 0.9m = 坑正跨在地板/桥沿上（半盘贴地半盘悬空=尖刺裙）⇒ 整坑放弃；静态坑占位照旧保留（无网格无害）。

### ④ 火池二令——6 分钟 + 整链免天气（00-config BARREL + 04b noWx 链 + 05-world 接线）
- `BARREL.poolTtl:14→360`（6 分钟）。火池本体 ttl 只吃纯时间衰减，本就天然免天气。
- `addFireSource(...,noWx)` 第 9 参（barrelBlast 传 `null,true`）：灼烧伤害 `fs.dps*0.4*(fs.noWx?1:fireDmgMul)`（兵+坦克双路）；`igniteCreature(s,att,noWx)` 燃烧时长视同晴档 3.5s + `s.burnNoWx` 燃烧态落账；`updateCreaturesBurning` 伤害 `3.2*(s.burnNoWx?1:dmgMul)`（最新点火源定真伪）。
- **植被格豁免**：`FNOWX=new Uint8Array(FN*FN)` 落格标志（igniteCell 第 4 参/igniteArea 第 6 参透传，火池周期点燃+首圈点燃带 noWx）——**暴雨浇灭门跳过 / 受潮消耗按 1 / 蔓延积热按 1（不吃 fireMul）**，且 `igniteCell(nj2,...,FNOWX[ci])` **蔓延继承**=整条火链同源视同晴档；浇灭/烧尽清零。
- **树冠火保持全局天气博弈**（暴雨浇树=既有有意设计）：树链有自己的 burnDur/bRate/sExt 模型，不随格子豁免——"油桶爆炸的火"指火池本体+灼烧+草地链。
- 时停/布势冻结照旧（dt 账），世界还原清 FIRE_SOURCES 照旧（按局生命周期）。

### ⑤ 顺带修：hp 跨局残留（23b）

## 实机验收清单

1. **残骸**：打爆任意油桶（子弹 5 发/反坦克枪 2 发/手雷/火烧）——原地应留下**压瘪焦黑的油桶残骸**（歪斜矮桶+翻起的桶口沿+一两道滚箍残片+地上焦土贴花），可辨认是"烧毁的油桶"；人/车可直接走过（无碰撞）；回主菜单再进=残骸消失（下一局全新战场）。
2. **开局遗迹坑**：进任意地图开局——地面上应还能看到几处旧弹坑（布局遗迹，保留裁定）；**放置约 7.5 分钟**后应自然淡出消失；对局中炮击/爆炸的新弹坑约 **2.5 分钟**后开始淡出、随后消失；时停（K）期间坑不老化。
3. **甜甜圈修复**：去**胡康河谷大桥**（或任意楼板/桥面）上引爆（手雷/油桶/炮击）——弹坑应是**贴着桥面板的完整圆形凹坑**（不是环形/厚环）；桥面木铺装、混凝土楼板、裸结构盒顶三种面都验一下；弹坑跨在桥沿上时该坑自动放弃（不出现半悬空尖刺裙）。
4. **火池 6 分钟**：打爆油桶后原地火池应持续**约 6 分钟**（此前 ~14 秒）；期间走近应持续掉血灼烧；把天气切到**暴雨/暴雪**再炸一只——火池亮度/伤害/点燃周边植被的能力应与晴天**完全一样**（此前雨天点不着草、灼烧减半）；火池引燃的草地火会在雨中照常蔓延。
5. **跨局油桶血量**：第一局把某只油桶打到残血不爆 → 结算/回菜单 → 再进同一地图 —— 该油桶应恢复满血（可再承受全额 5 发步枪）。
