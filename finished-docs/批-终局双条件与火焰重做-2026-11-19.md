## 三、火焰重做 (08-effects + 02-scene + 04b-fire + 16-aircraft)

### 3.1 贴图 (塑形归贴图, 色带归材质 color)
- **PT.flame** = `flameTex()`: 64×64 Canvas 三段径向渐变沿纵轴堆叠泪滴 (火根最宽最亮→火尖收细上扬), **白芯** —— 与 radialTex 同 API 面 (沙箱桩零新增); 颜色由生命色带逐帧染。
- **SVG 精修**: 02-scene `svgFlame(seed)` 泪滴轮廓 (三椭圆) + feTurbulence 各向异性 (baseFrequency "0.08 0.14" 纵向拉丝) + feDisplacementMap, `svgReg('puffFlame',64,64,…)`, 08-effects `svgApply(PT.flame,'puffFlame')` —— 与烟/黑烟/尘同款管线, 风格统一。

### 3.2 spawnFlame 活体账
- `spawnP` 补 `return p;` (旧调用不消费, 零兼容风险) + 老路 `p.ramp=0` **清账行** —— 池化复用不串样式 (与 uuid 分池无关的确定性隔离; 沙箱 CanvasTexture 无 uuid 合池场景照样安全)。
- `spawnFlame(x,y,z,vx,vy,vz,size,grow,life,opa,grav)`: 走统一池+预算门; 附加账 stretch=rand(1.7,2.2) 纵拉 / swayA=rand(0.45,0.95) / swF=rand(5,9) rad/s (nowT 秒钟, ≈0.8-1.4Hz, 与云火舌 fk 同数量级) / 双轴异频相位 (z ×0.83 频率 ×1.7 相位 = 扭动) / rotation=0 (舌形朝上, 不吃随机旋转) / ramp=1。

### 3.3 updateParticles 火苗分支 (零分配)
- 摇摆: `position += sin/cos(nowT·swF+swPh)·swayA·dt` 双轴; 纵拉: `scale.set(s, s·stretch)`; 色带: FLAME_RAMP 静态表 [[1,.98,.87],[1,.79,.40],[1,.55,.17],[.78,.26,.07]] 线性插值 `material.color.setRGB` (复用既有 Color 对象); 老粒子 (无 ramp) 原路径逐位不变; 透明度衰减式照旧。

## 五、实机验收清单

**终局双条件**
1. 遭遇战 (强点图): 把对面打到最后一人后**不立即结算** —— HUD 应显示"占满全部点位(余 N 处)+清场残敌"倒数; 占满全部强点且清场后才结算。
2. 攻防/征服 (旗图): 老双条件行为不变 (全旗+歼灭残兵)。
3. 破袭战: 炸掉弹药库照样直接胜利 (目标路径不加门槛); 但"对面人数先归零"时须占满全部点位+清场残兵才结算。
4. 劫道战: 护送车队到点照样胜利; 归零结算须占满全部点位 (劫道图无点位 = 自然豁免归零即结)。
5. 双方同帧归零 → 平局; 1v1 对峙 → 30s 倒计时对齐后平局 (10-06 口径不变)。
6. (修复回归) 被清场方持全旗时, 30s 倒计时到期应判**对方**胜 (不再反判被清场方)。

**火焰特效**
7. 草丛/树林/庄稼火: 火苗为**上窄下宽的舌形**并有扭动摇摆 (不再是一个圆圈), 起火白热偏黄 → 熄灭暗红渐变, 高度≈旧火头 (与现状相近)。
8. 燃烧弹云: 云底火舌同款舌形纵拉; 灼烧伤害/遮蔽视线行为不变。
9. 士兵/树冠/载具残骸/坠机拖火: 同款舌形火苗, 冒烟照旧。
10. 枪口焰 / 爆炸闪光 / 灼痕 / 高炮炮口焰: 仍为原圆盘光斑 (本批未动)。
11. 火情大规模蔓延时帧耗不劣化 (粒子数/预算门全未动)。
12. (风格) 火苗贴图由 SVG feTurbulence 精修, 与烟/尘的蓬松扰动观感同族。
