# 死亡掉落手中雷 + 引信继承读条 — 2026-11-03（死亡掉雷批）

> 用户裁定（承《排查-射手死亡与在飞弹体-2026-11-03.md》的遗留口径）：**「死亡时手里捏的雷要'掉落在原地'，并继承读条时间」**。
> 本批把它落地为游戏机制：死亡瞬间手里那颗雷就地脱手，引信按读条进度继承——越接近出手被杀，尸体上的雷越烫。

---

## 一、病根（为什么手里雷会"消失"）

排查批已证：在飞弹体（nades/shells/flak/鱼雷）全部无射手存活门、子弹=即时射线、巡飞弹死亡原地起爆——
**手里雷是全游戏唯一真"原地消失"的弹体**，有三条路径：

| # | 路径 | 机制 |
|---|---|---|
| 1 | 玩家 >25 受创打断 / 死亡清账 | `damage()` 单次伤害 >READBAR_DMG_GATE(25) 走 `cancelReadBar`；die() 内再兜一次——账旗 `nadeHeld` 摘除、雷回袋不消耗（2026-10-25 打断网设计） |
| 2 | Bot 前摇被打断 | 三问批（2026-11-03）把 Bot 接入打断网：>25 伤清 `nadeAnimT`、state 回 'combat'，雷不消耗 |
| 3 | **出手弧中阵亡** | 松手后 VM 仍处 'nade' 态走投掷弧、出手帧在 k>0.5；但 `updateViewModel` 被 `(player.alive‖specViewHost)…` 门控（24-main）——**死后弧冻结，releaseNade 永不触发**；且 `vmAbortAction` 明确不收弧（"出手弧…不属于可中止段"）⇒ 雷凭空蒸发 |

## 二、落地实现（三处游戏代码）

### ① `dropHeldNade` 单源（js/13-combat.js，throwNade 之后）
- 位置=胸口 +0.15m 微抖，速度=小抛落（±0.9 水平 + 1.3 竖直）——照常翻滚/弹跳/入水哑火。
- 走 `throwNade` 同链：弹种/归属/队伍/击杀账与出手件完全一致，**死者照记击杀**（与死亡弹道留存同规）。
- 保险丝：载具/大舰内死亡不落雷（登车路径本就收雷）。

### ② 引信继承读条（本批机制核心）
- **玩家普通雷**：掉落引信 = `nadeFuse` 余值直带——厨雷账举起即烧（20-player 每帧烧减，NADE_FUSE_T=3.8 全长），
  烧到 0 = 已武装 ⇒ 掉地即炸（与持雷"武装+接触"双条件一致，nadeStep 单源）。
- **烟雾/燃烧/反坦克**：无厨雷账（nadeFuse=99 哨兵），掉落带各自标准引信（1.8/1.6/1.6）——
  **哨兵 99 绝不带走**（否则引信到点永不武装 = 掉落即哑弹）。
- **Bot 前摇**（state 'nade'/'atnade'，nadeAnimT 0.8→0）：掉落引信 = 3.4 × (nadeAnimT/0.8) **按剩余比继承**——
  前摇越接近出手被杀，尸体上的雷越烫；反坦克雷表外弹种掉落即武装（触地即炸）。

### ③ 接线三点
1. **玩家 >25 致命一击 = 打断点就地掉雷**（18-game damage 内）：hp≤0（已扣减）∧ nadeHeld ⇒ `dropHeldNade` 代替收回；
   随后的 `cancelReadBar` 照跑——只收玩家侧账目/模型，碰不到已入账的弹体。**2026-10-25 打断网语义零改动**（非致命照旧收回）。
2. **玩家 die() 钩**：nadeHeld ∨ (VM 'nade' ∧ nadeThrowT≤0) ⇒ 掉落 + **收弧**（VM 回 idle + nadeM 隐 + 枪还原）——
   死后残留弧绝不能再走出手（防复活后双雷）；兜住出手弧与 ≤25 致命两档。
3. **Bot >25 致命 = 打断点掉雷**（14-bots damage 内，清 `nadeAnimT` 之前）；die() 内钩兜非打断路径。

### 口径边界
- 受创**<致命**：照旧收回不消耗（打断网不动）。
- 丧尸尸变：die() 感染分支早退，不掉雷（人没死透，尸体起身）。
- 载具/大舰内：不掉（随车没）。
- 空手死亡：零掉落（不得凭空生出弹体）。

## 三、判据（dev/verify-deathdrop-20261103.js，已入 run-all 名册）

全部真死亡链（damage(9999)→die）+ 弹体按引用追踪 + 只步进 updateNades：

- **T1** 玩家真实哨兵态持雷半程（VM 'nade'+stateDur 999，nadeFuse=2.0）：掉落引信**精确 2.0**（继承判据核心）+
  距尸 1.16m + 账旗摘 + VM 收回 idle + **40 步 ≈2.0s 引爆**（时序与继承引信独立吻合）。
- **T2** 全熟雷（nadeFuse=0 已武装）：掉落引信 0，**0.60s 触地即炸**。
- **T3** 烟雾（nadeFuse=99 哨兵）：掉落引信=标准 1.8（哨兵不带走）。
- **T4** 出手弧中阵亡：照样掉落 + VM 'nade' 收回 idle（死后不出手）。
- **T5** Bot 前摇 nadeAnimT=0.2（剩 25%）：掉落引信 0.85 = 3.4×0.25。
- **T6** Bot 反坦克雷前摇：掉落即武装（表外弹种）+触地即炸。
- **T7** 对照：玩家/Bot 空手死亡零掉落。
- **结果**：正向 **25/0 绿**；--neg 六补丁 **6 红**（两处打断点掉雷拆 / die 钩拆 / 引信继承断 / 比例断 / 哨兵带走病），T7 保持绿=判据具备分辨力。
- deathflight 守护探针复跑 **14/0**（die() 被改无扰）。
