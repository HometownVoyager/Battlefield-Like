## 探针坑（记账）

1. **部署装备链 VM `draw` 态在无 rAF 沙箱不推进**（stateDur 0.45 永远走不完）——所有带 VM 门（idle|fire）的按键测试前必须直接置 `VM.state='idle'`（throwq 批同款坑的第一现场复认）；**切枪 vmEquip 后 VM 会再次进 `draw`**，连续两次按键测试之间要各置一次 idle，否则第二次被 switchSlot 的 idle 门静默挡掉（本次 T1a/T1k 两处假红均此根因）。
2. **NEG 精确红名集合判定**：七补丁并施时部分断言会被"改道接力"绕开（如 T1c 松手判据——N2 把 Digit4 改道给烟雾块后照样举雷照样松手，判据恒绿），映射标注要写"正向专判"而不是硬塞进期望红；红名集合用 `EXPECT` 数组**精确比对**（漏红/多红都 exit 1），比"只查漏红"更能抓补丁写错锚。
3. **负向锚在 NEG 并施下会翻红是特性**（T0a2/T0d2/T0e2 断言"旧串绝迹"，补丁把旧串还原回来⇒翻红）——这些 id 要进 EXPECT 集合，否则"多红"误报。
