## 2. 修复① 玩家死亡播报丢爆头位

- **现象**：玩家被 Bot 爆头击杀时，右上角击杀播报永远显示 `✕`，从不出现 `☠`——被爆头杀与被普通杀在播报上不可辨，读作"爆头判定没生效"。
- **病根**：`18-game die()` 里 `addKillfeed(attacker,this,false)` 硬编码 `false`；而 Bot 死亡链（14-bots:548）传的是真实 `isHead`。全库对账仅此一处丢参。
- **修法**：爆头位透传 `!!isHead`（`die(attacker,isHead)` 形参本就在手，行为面只有播报图标一行）。

## 3. 修复② 反坦克雷链爆挂浏览器时钟

- **现象类**：草原雷区一颗雷被引爆后，邻近雷按 `setTimeout(120~300ms)` 链爆——**Esc 暂停 / K 时停期间照常到点**，冻结的战场里链爆照样炸人（暂停中掉血/死人，解冻后现场已变）。
- **病根**：链爆延时挂浏览器时钟，脱离游戏主时钟。与 2026-10-28a 丧尸近战 `setTimeout→dt 账` 同族病（本库第三例；前两例：丧尸近战、刺刀延时账）。
- **修法**：链爆改挂游戏时钟账 `MINE_CHAIN`（`{m,t}`），`updateMineTriggers(dt)` 逐帧消费——账消费排在 `!MINES.length` 早退**之前**（MINES 里 dead 项常驻，不依赖底数）；`24-main` 传世界帧长。语义：时停/布势 `dt=0` 整列停住；Esc 暂停/菜单/结算整段不跑（冻结分支 return 之前）；非时停逐位同延时（0.12+rand×0.18s）。

## 4. 修复③ 出生保护"开火即解除"契约漏洞

- **现象类**：`fireBullet` 的出生保护清账注释宣称"玩家/Bot/炮位共用的**唯一出膛口**"——但**火箭筒 fireRocket / 坦克主炮 fireCannon / 反坦克炮 emplATFire / 迫击炮 emplMortarShell 四条路不走 fireBullet**，清账对它们不生效 ⇒ 部署落地 2s 保护期内照样开火：载具出生直接进车开主炮、落地掏火箭筒即打，都是"免疫输出"窗口（注释宣称≠实现病型）。
- **修法**：四处同契约补 `if(shooter&&shooter.protUntil) shooter.protUntil=0`（fireBullet 原清账不动；炮位冷却"在炮上换人不重置"口径不受影响；空车 `crew` 对象无该字段=空操作）。探针侧本就"全清 protUntil 再开火"，行为面零波及。

## 6. 实机验收关注点（请逐项试）

1. **爆头播报**：被 Bot 爆头击杀 → 右上角播报应出现 `☠`（此前永远 `✕`）；普通击杀仍是 `✕`。
