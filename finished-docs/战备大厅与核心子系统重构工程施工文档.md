## 1. 工程背景与重构总原则

### 1.1 核心痛点与缺陷盘点
* **路由与交互割裂**：主菜单“新游戏”（`#mPlay`）与“小游戏”（`#mMini`）两套入口完全平行且互斥，多达 9 处使用 `location.reload()` 暴力重启，导致状态丢失、白屏闪烁；战役卡片点击即刷新，与开局按钮形成冗余双重确认；
* **环境光效失真**：阴天与两种雨天缺乏自然界严谨的亮度递减分级，存在小雨直射日光（`sunMul=0.55`）反而高于阴天（`0.5`）的数值倒挂；环境天光（`hemiMul`）压低不足，漫反射地面过度苍白；且小雨天缺少相匹配的水汽漫射雾；
* **战时时钟漂移**：切后台或失焦导致游戏时钟 `nowT` 瞬间暴涨几百秒，暂停与后台运行状态脱节；鼠标丢锁强弹部署界面而非真暂停；
* **数据与表现不一致**：丧尸模式直接覆写静态战役配置；Bot 手持主武器却打出副武器/火箭弹特效；战斗中兵种卡随意切换缺乏战术约束。

### 1.2 施工总原则
1. **有限可自定义（Constrained Customization）**：自定义项（阵营、天气、规模、兵种）必须遵循地图历史背景、环境群系与战术补给约束，严禁无拦截的非法组合；
2. **单页应用（SPA）零重载原则**：除初始资源加载外，所有界面流转、战况调整、光影切换完全基于运行时状态机重绘，杜绝调用 `location.reload()`；
3. **数据不可变原则（Immutability）**：全局静态模板（`CAMPAIGN`、`WPN_DEFS` 等）只读，战局必须基于深拷贝生成的运行态上下文（`RunContext`）运行。

## 3. 模块施工规范

### 3.1 天气与光学物理递减阶梯重构
* **涉及文件**：`js/00-config.js`、`js/02-scene.js`、`js/08-effects.js`
* **问题诊断**：
  * 当前 `WEATHER_CFG.rain` 的 `sunMul` 为 `0.55`，而 `overcast` 为 `0.5`，出现“下雨天比阴天太阳更晒”的严重数值倒挂；
  * `hemiMul` 在阴天为 `0.9`、暴雨为 `0.72`，环境光压低不足，漫反射地面过度苍白；
  * 小雨缺乏近距水汽雾，视距过大（Far 达到 168m），无法营造雨丝弥漫的朦胧感。
* **工程改造方案**：
  在 `js/00-config.js` 中重构物理光照递减梯度（严格执行：晴朗 ➔ 阴天 ➔ 小雨 ➔ 暴雨）：

| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **clear (晴朗)** | **1.00** | **1.00** | **1.00** | 1.00 (420m) | 1.00 (40m) | 1.00 | 0 | 阳光耀眼，阴影清晰，远山通透 |
| **overcast (阴天)** | **0.22** | **0.62** | **0.88** | 0.90 (378m) | 0.90 (36m) | 0.80 | 0 | 云层蔽日，无锐利直射影，柔和冷灰 |

### 3.2 运行时时钟与切后台防暴涨修复
* **涉及文件**：`js/24-main.js`、`js/19-input.js`
* **问题诊断**：
  * 切出浏览器标签页后，`loop()` 中 `if (document.hidden) return;` 导致 `lastT` 冻结在切出瞬间；
  * 切回前台时，`now` 突增，而由于未处于暂停态，`nowOff` 未累加，导致 `nowT = (now - nowOff)/1000` **瞬间快进整段切出时间**；
  * 键鼠丢锁 `pointerlockchange` 误触发 `showDeploy`，而部署状态仍在执行世界物理演算。
* **工程改造方案**：
  1. **切后台自动挂起（Visibility API）**：
     在 `js/19-input.js` 注册全局事件：
     ```javascript
     document.addEventListener('visibilitychange', () => {
       if (document.hidden) {
         if (!gamePaused && player.alive && player.deployed && !matchOver) {
           togglePause(true); // 自动触发规范暂停
         }
       } else {
         lastT = performance.now(); // 切回瞬间对齐帧时间基准
       }
     });
     ```
  2. **主循环丢帧与后台补偿（`js/24-main.js:loop`）**：
     ```javascript
     function loop() {
       requestAnimationFrame(loop);
       const now = performance.now();
       if (document.hidden) {
         if (gamePaused || matchOver || menuHold) nowOff += now - lastT;
         lastT = now;
         return;
       }
       const rdt = Math.min((now - lastT) / 1000, 0.05);
       if (gamePaused || matchOver || menuHold) nowOff += now - lastT;
       lastT = now;
       nowT = (now - nowOff) / 1000;
       // ...后续渲染管线
     }
     ```
  3. **丢锁行为规范**：
     修改 `pointerlockchange` 监听：丢锁时如果处于战斗中，呼出 `togglePause(true)` 暂停面板，而非 `showDeploy()`。

### 3.3 丧尸模式静态配置脏写根除
* **涉及文件**：`js/05c-layouts.js`、`js/25-zombies.js`
* **问题诊断**：
  * `js/05c-layouts.js:2322` 中，单队生存直接对 `CAMPAIGN.bases[0]` 及 `CAMPAIGN.spawns` 进行就地改写，破坏内存中的静态模板，迫使重开必须整页重载。
* **工程改造方案**：
  1. 引入运行时上下文克隆：世界生成时执行 `ACTIVE_CAMPAIGN = deepClone(CAMPAIGN)`；
  2. 地形与据点生成仅读写 `ACTIVE_CAMPAIGN`，原始常量 `CAMPAIGN` 施加 `Object.freeze()` 防护；
  3. 彻底消除“必须整页重载才能重置地图”的硬性阻碍。

### 3.4 Bot 动态武器切模与开火效果对齐
* **涉及文件**：`js/14-bots.js`
* **问题诊断**：
  * Bot 仅在生成初始化 `setClass` 时建一次主武器枪模；
  * 当反坦克兵掏出火箭筒（`fireRocket`）、工兵掏出卡宾枪或手枪近战（`shootAt(..., def2)`）时，Bot 手中依然悬挂主武器，视觉与开火完全脱节。
* **工程改造方案**：
  1. 维护 Bot 当前握持武器标识 `this.heldWpnKey`（默认为主武器 `wset[0]`）；
  2. 扩展 `Bot.prototype.switchVisualGun(wpnKey)`：
     当 `heldWpnKey !== wpnKey` 时，移除旧枪模，调用 `mountGunModel` 挂载对应枪模并重设姿态；
  3. 在开火入口挂载切换钩子：
     * 反坦克开火前调用 `this.switchVisualGun(this.slots[1].key)`；并在 1.8 秒后（或脱离反坦克姿态时）自动切回主武器；
     * 副武器射击时切换为手枪模型，副武器射击完毕后切回主武器。

### 3.5 局内补给箱交互限定重部署机制
* **涉及文件**：`js/22-hud.js`、`js/23-deploy.js`、`js/20-player.js`
* **交互规则设计**：
  1. **状态判定**：
     检测玩家位置是否处于任一有效弹药箱内：
     ```javascript
     function isNearSupplyCrate(pos) {
       if (!AMMO_CRATES || !AMMO_CRATES.length) return false;
       return AMMO_CRATES.some(c => Math.hypot(c.x - pos.x, c.z - pos.z) <= 2.8);
     }
     ```
  2. **部署界面（Deploy Screen）分态渲染**：
     * **阵亡状态**：所有兵种卡正常开放，自由部署；
     * **存活状态 且 远离补给箱**：
       * 兵种卡加盖锁形图标，半透明置灰（`opacity: 0.5`）；
       * 鼠标悬停或点击提示：`[战地整备受限: 需在友方补给箱 2.8m 内方可调配装备]`；
       * “部署”按钮变为“返回战斗”。
     * **存活状态 且 处于补给箱旁（整备模式）**：
       * 兵种卡点亮解锁，支持点击切换；
       * 界面显示金色角标：`[补给站整备中 - 换装立即生效]`；
       * 点击“确认换装并返回”后，立即更新玩家武器模型与弹药插槽，扣减补给箱短冷却，无缝重返战斗。
