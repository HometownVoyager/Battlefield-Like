## 二、修复清单

### 1. NAV 直写时代快路径（js/07-nav.js + js/03-terrain.js）

- **快路径本体**：运行期占用改动自 2026-11-11 起已全走直写四路（registerDynCollider/killDynCollider/killOne/occMarkFire：直接写 OCC.data + occTouch 登记簇）⇒ 稳态 `NAV.refresh()` 里的 buildOccupancy 全量重建对这些改动是纯冗余（OCC.data 已正确、全图差分恒空、真正要烘的只有登记簇）。快路径**跳过全量重建、按登记簇直接烘焙**（火情期每 5s 一帧的 2.6-7.4ms → 亚毫秒）。
- **1全:3快 配额**：连续 3 次快刷后回插一次全量重建——收敛 killOne 盲置 0 可能擦掉共格标记的角案（重建是唯一纠正者）。
- **门控双计数**（03-terrain `_occAddSeq`/`_occAddSyncN`）：addBoxCollider 只入 BOXES 表不写 OCC.data，占用要等全量重建从表里收编；registerDynCollider 则入表后同时直写收编。**追加数==收编数 ⇒ 表账与占用账齐平放行快路径；有未收编的表级追加（探针/合成摆件裸直调 addBoxCollider）⇒ 回退全量**；全量重建尾部两计数清零。首版单计数（_occAddSeq vs 上次全量基线）把 registerDynCollider（载具/飞机/卡车残骸——坦克战高频事件）也误判成未收编=快路径永远不 engage，写探针时发现后改双计数（A/B 实锤回归案的专项闸保留：裸 addBoxCollider 仍强制全量，verify-nav 1m 厚墙案）。
- **旗翻型改动强制全量**：碾铁丝网（15-vehicles 只置 alive=false 无占用直写）改 `markNavDirty(true)` ⇒ 下次 refresh 强制全量重烘，否则快路径下碾平的铁丝网在 NAV 里长期留陈旧格。**兼修旧漏报**：玩家拆除（06-engineering updateDemolish）旧版从不 markNavDirty——拆掉的拒马（CYLS.splice 无直写）/铁丝（旗翻）/沙袋（killOne 直写但盲置 0）在 NAV 里留陈旧格直到下一次无关事件；本批补 `markNavDirty(true)`（06 加载早于 07 ⇒ typeof 守卫）。
- **mutator 审计结论**：运行期占用直写四路全覆盖；裸 addBoxCollider 调用点全部在构建期（05-world/05a-buildings/05b-props）；fire 烧尽留格到周期性全量（≤4 次 refresh，无害）。

### 2. 14-bots SAFE 集六项（js/14-bots.js + js/17-emplacements.js + js/11-soldiers.js）

## 六、探针坑入档（本批新增）

1. **NEG 同文件补丁互毒**：多支补丁 patch 同一文件同一表达式时，"全部同跑"会让各自世界互相污染（N1 门杀让 N2/N3 世界也门死）⇒ 逐补丁隔离 boot（每补丁独立编译+独立世界），loiterview `--only` 单补丁先例的推广。
2. **raycastWorld 桩语义（findCoverFrom 判据口径）**：null=视线穿=**不算**掩体；hit.dist≤dist-0.8=威胁与候选间有遮挡=合格掩体。且 dir 为 3D 归一而 dist 为 2D ⇒ 端点欠冲，桩须按 `dir.y`（平地下恒 -0.6/|v|）反解候选身份，不能按端点阈值分档。
3. **heightAt 裸名重绑可平地化场地**（探针专局）：top-level function 声明=可变全局 lexical 绑定，跨脚本赋值生效（frameperf2 raycastWorld 同款），finally 还原。
4. **buildOccupancy 调用计数是快路径判据的唯一出口**：navStats 不区分"全量重建跑没跑"（fullBakes 只数 fullBakeGrid，差分驱动时全路径也只涨 partBakes）⇒ 探针裸名重绑计数。
5. **grep -rl 输出路径在本机带反斜杠**（`dev\verify-…`）：批量 sed/tr 改写路径都会踩坑，用 `find -exec`（正斜杠）或把原样路径直接喂 perl。

## 七、实机验收清单（用户操作）

1. **火情图顿挫**：植被起火/油桶火池期间，"每隔几秒一顿"应明显减轻（NAV 快路径后大部分 refresh 亚毫秒；剩余 1/4 频率的全量仍存在但同改前单次成本）。
2. **碾铁丝网**：坦克碾平铁丝网后，Bot 应较快改走原网位置（NAV 陈旧格及时解除——与改前观感一致或更快）。
3. **工程兵拆除**：拆掉拒马/铁丝/沙袋后 Bot 能走过去（★旧版拆除从不报 NAV 的漏报兼修——改前偶尔"拆了还绕着走"）。
4. **大规模交战**：30v30 连续死亡重生期顿挫减轻（出生链融合+枪模缓存=每 respawn 免全套枪模几何/材质分配）。
5. **高炮打飞机**：多门高炮分摊目标不闪烁；飞机被击落当帧其余炮即换目标（0.25s 缓存+alive 门）。
6. **Bot 掩体/走位**：观感应与之前一致（top-12=前 12 近候选同果近似；defend 拥挤账同参）。
7. **雨雪/手雷**：与之前一致（本批零触碰天气；F8=判据等价的算术改写）。
8. **整体帧耗**：与 20261118d 批验收基线一致或更好；枪模相关应有轻微改善（GC 压力源削减）。
