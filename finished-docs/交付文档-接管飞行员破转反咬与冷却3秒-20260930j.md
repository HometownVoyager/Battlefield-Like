# 交付文档——AI 接管飞行员"过度躲避"改破转反咬 + 接管冷却 8→3s（2026-09-30j）

> 用户实机反馈原话："AI 接管后总是过度躲避，然后等到队友击败了锁定敌人后进入冷却，
> 甚至躲避还躲不好总是被击中，窝囊且废物。"
> 另一项裁定：AI 飞行员 CD 8s → **3s**。
> 版本戳 `20260930i → 20260930j`。

## 一、病根（对账 16-aircraft aiPilotFly 规避链逐分支推演）

接管规避是 7b-丙热修⑤ 加的："挨打/被咬尾 → 满舵破转一拍 → 2.6s 冷却 → 回攻击"。
实机跑起来却是"无限躲、不还手、躲了还挨打"，拆开是三条叠加：

1. **咬尾侦察漏了"后半球"判据（过度躲避主源）**。
   代码注释写"敌机在我后半球且机头大致指向我"，实现只判了后半句（`f·dv>0.72|dv|`，
   "他机头瞄我"）。对头遭遇战（双方机头相对、互相瞄着）同样满足——于是合并阶段的每一次
   对头都触发一拍"逃命破转"，老飞行员见面对射的天职变成了掉头就跑。
2. **躲避动作 = 随机方向的恒定满舵转圈（"躲还躲不好"主因）**。
   匀速圆周是提前量（planeLeadAim, leadT=280）**最好跟**的轨迹：角速度恒定、速度恒定，
   敌机 AI/高炮的 lead 解算照打不误。破转方向还是掷硬币，与威胁方位无关。
3. **规避窗内零开火 + 窗后扫描立刻再触发（"等队友收人头"主因）**。
   旧版整窗禁射；窗毕 2.6s 冷却一过，咬尾条件只要仍成立（敌人确实还在后面）就再躲——
   被咬尾是持续性态势，于是循环"躲→冷却→再躲"，攻击几何永远不回来，
   直到别人（队友/高炮）把目标打死，接管以"目标已击落"收账进 8s 冷却。

## 二、修复口径（全部在决策层，flightStep 积分一行未动）

- **① 真·后半球判据**：咬尾侦察补 `mf·dv>0.05·|dv|`（mf=我机头方向）——
  他在我机尾 ±87° 之外不再触发。对头遭遇不再弃攻。
- **② 破转方向 = 朝威胁转**：`aiEvDir = dyT>0 ? -1 : 1`（dyT=威胁方位航向差；
  bank −1 → yaw 增，与 steerToward 同一因果链）。大角速度偏转敌机跟踪的同时，
  把炮口往他头上带——为反咬段铺路。
- **③ 两段式规避窗**（`aiEvDur` 记窗长，45% 分界）：
  - **前 55%（破转段）**：满舵带爬升甩弹道，零开火——R10a/b 的"窗内满舵且零开火"口径原样保留；
  - **后 45%（反咬段）**：反舵回扫威胁方向（steerToward + planeLeadAim 同一原语），
    进咬尾机炮同一门限（`|dy|<0.14 ∧ d<160×eng`）即开火，
    走**同一 `fireMGBurst(player,0.8)` 诚实弹道管线**（S9 方法体审计不变，无制导旁路）。
  - 窗毕照旧 `aiEvCd=2.6s` 冷却防连躲；此时威胁已在机头方向，咬尾扫描不再触发，
    接管自然回到攻击剖面——"躲"以"转完能打"收尾，不以"躲到队友收人头"收尾。
- **④ 威胁源记账 `aiEvSrc`**（对象引用不过夜纪律，与 lockTgt/dogTgt 同族）：
  - 咬尾侦察触发 → 记触发的那架敌机；挨打触发（takeDmg 玩家分支，amt>2 不掷概率）
    → 攻击者是敌机才记源（并按攻击者方位定破转方向），高炮/航弹等对地威胁不记源
    （"转过去打"对地面单位无语义）→ 全窗破转；
  - **敌机射手是机组 Bot，不是 Plane**（`fireMGBurst(this.crewBot||this.crew,·)`）——
    挨打置窗时把 `attacker.onVehicle.kind==='plane'` 归位到那架 Plane 再记源；
    不归位则"挨打"这条最高频的置窗路径永远记不到敌机，反咬段退化成纯破转；
  - 威胁中途被击落 → 反咬段自动退化为破转段（`!src.alive` 分支）；
  - 清账六处：构造 / 接管激活 / planeTakeoverEnd / die / respawn / 跳伞离机收账。
- **⑤ 接管冷却 cd 8→3s**（用户裁定）：`PLANE_TAKEOVER.cd=3`（00-config 单源，
  接管收账/交还/跳伞离机三处共读），玩家拿回控制权的空窗期 8s→3s。

## 四、待用户实机验收清单

1. 锁定敌机（E/中键）→ Space 接管：让敌机咬住我方尾 → 接管飞行员破转后**转回去咬他并开火**，

4. 低空（AGL<40）接管时保底高度改出优先级不变（不会为了反咬往地里扎）。
