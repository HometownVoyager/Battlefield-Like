# 交付文档 —— 终局判定补漏（同归零死局 + 1v1 倒计时对齐）× 雨雪顶面遮挡（2026-10-06）

> 承用户两报：①「现在在雨雪天气下，即使在有房顶的室内也会有雨雪落下来」；②「现在双方都是 0 剩余人数的时候无法结束战局，双方都剩 1 人的时候先只剩一人的会先跑完 30 秒而输掉」。
> 两案取舍经 AskUserQuestion 用户裁定：终局=**对齐倒计时+平局**；雨雪遮挡=**所有水平顶面**（非仅建筑）。

## 一、终局判定补漏（js/21-match.js + js/22-hud.js）

### 病根（两条路径都坐实）
- **同归零死局**：`updateFlags` 清场判定里 `z0&&z1` 分支唯一的出口是"双方场上都清空→平局"；一方先被清空（如 1v1 里一人被打死、对方还有 1 人）时该分支什么都不做——既不平局也不判胜，而 `else if(z0)` / `else if(z1)` 在 else 链上够不到 ⇒ **战局永远挂着**。且同归零局里"占满全旗"的旗权条件根本无人能完成（双方都封重生、没人在占旗博弈里有票力），旧口径在此场景自相矛盾。
- **1v1 倒计时各自为政**：30 秒清场倒计时门槛 `flagsLostOf(1-zt)===0`（2026-09-05 防躲藏设计：对方须占满全部旗点）。攻防/征服的同归零局旗权不可能占满 ⇒ 倒计时永不启动（叠加上一条=彻底死局）；遭遇战（无旗）门槛恒 0 ⇒ **双方倒计时独立跑**，先剩 1 人的一方先到点、先被判负——对称局面不对称结局。

### 修复（用户裁定口径）
- **同归零旗权豁免**：`z0&&z1` 时补两个出口——一方清空 → 对方立即判胜；同帧双清 → 平局（T3 既有口径保留）。旗权条件在同归零局整体豁免（倒计时门槛同步豁免）。
- **1v1 倒计时对齐**：双方同处"最后 1 人"时，后启动者把**双方计时都重置为 30s**（先剩 1 人的一方不再"先跑完先输"，对称局面给对称决斗窗）；双双存活到点 = 平局；期间打死对方 = 立即胜（走同归零新出口）。
- **到点判定移出累计循环**：同帧双到点 → 平局；单侧到点 → 对方胜（旧口径不变）。
- **实现教训（沙箱抓出来的）**：启动/对齐与扣减必须拆成两段——对齐若发生在扣减之后，先启动方的本帧扣减被回满抹掉而后启动方照扣，造成**永久 1 帧错位**（0.05s），到点帧一先一后、先到点方按旧口径被判负（T18 首跑实测 `wT=[0.05,-0.00]` 抓获）。
- **1v2 等非对称残局**：倒计时语义沿用旧口径（人数为 1 且票归零的一方进倒数，到点仍存活判对方胜）——同归零时只是豁免旗权门槛，不改变"最后一人须在 30 秒内翻盘"的压力方向。
- HUD（22-hud wipeLine）：同归零后不再显示"须占领全部旗点(余 N 点)+"（与判定同口径，逐帧重算）。

## 二、雨雪顶面遮挡（js/08-effects.js）

### 病根
雨雪是跟随相机的粒子盒（雨 460 线段 / 雪 900 点，`WEATHER_CFG.precipN`），唯一的终结条件是落到盒底（盒底夹在水面之上，2026-09-26E 审计 38 口径）——**没有任何屋顶/遮挡判断**，雨雪穿透一切顶面。

### 修复（用户裁定"所有水平顶面"）
- **顶面表 `RAIN_COVERS`**：每 1s 重扫一次 `BOXES`（03-terrain 单源碰撞盒），收编"**带可见网格的水平面板**"——厚度 ≤1.5m + 最小边 ≥0.8m + 投影面积 ≥1.6㎡。判据设计：
  - `!b.mesh` 拒收（`addBoxCollider` 纯碰撞体/隐形体积不算——雨不会在半空凭空消失）；
  - 厚度挡掉竖墙/柱，最小边 0.8 挡掉沙袋墙类竖薄件（厚 0.5）与薄条块，面积 1.6 挡掉小箱类；
  - 建筑屋顶/楼板/桥面/碉堡顶/帐篷顶/瞭望塔台/大屋盖贴片（solidBox 斜置件 2D 贴片小方块逐个过筛）全部命中。
- **粒子终结语义**：粒子头部进入某顶面水平投影且低于其顶面 ⇒ **原地回收**（y 回盒顶 + x/z 重随机，与落地/落水同款视觉：雨到顶即消失）。x/z 重随机是刻意的——回收不重随机会让屋顶上方的粒子永久滞留、"单向迁移"把旷野粒子密度越抽越薄。
- **破坏自动接线（零钩子）**：屋顶被炸塌 = `killBox` 置 `dead` ⇒ 每帧短名单里 `b.dead` 即时剔除（**塌顶当帧即漏雨**，不等 1s 重扫）；23b 世界还原复活同批盒对象 ⇒ 自动恢复遮挡。重扫只做账本刷新，不挂破坏/还原系统任何钩子。
- **短名单**：每帧从 RAIN_COVERS 里筛"顶面高于盒底 + 水平投影搭上粒子盒(±26m)"的子集（复用数组，热路径零分配）。盒顶之上的高顶面保留——大桥/高架下方整片遮蔽本来就是干的（物理正确）。
- **性能**：1s 全量重扫（~5k 盒 × 8 次比较）+ 每帧短名单过滤 + 每粒子 5 次比较 × 短名单，实测量级均在亚毫秒。
- **已知边界**：大舰甲板走 15g 独立碰撞体系（不在 BOXES）⇒ 舰面仍穿透——与本批之前行为一致，需要时另批接 `capSolidAt` 系查询。树冠不挡雨（植被不在 BOXES，且枝叶本来也不挡水）。

## 四、实机验收清单（用户执行）
1. 雨/雪任一档，进任意有屋顶的建筑内部 → 室内**无**雨丝/雪点；站在屋檐/桥下亦干燥；屋顶外雨声照常。
2. 站在楼内朝屋顶开炮把顶打塌 → 塌顶后雨/雪**当帧**灌进屋内。
3. 桥面下方（桥不在建筑体系也算顶面）→ 桥下无雨。
4. 打一局让双方兵力都耗到 0：一方残兵被清空的瞬间 → 立即结算对方胜（不再卡死）。
5. 打到双方都只剩最后 1 人：后进入倒数的一方触发"⚖ 倒计时对齐"播报，HUD 双方倒数秒数一致；两人都躲过 30 秒 → 平局结算；期间任何人被打死 → 立即结算对方胜。
6. 遭遇战（草原）复现 5（无旗模式原本就有倒数，重点核对对齐与平局）。
