## §1 病症（前两次为什么没治好）

前两批都在**同一个东西**上打补丁：一个 `(trkW × 1.12 × L+0.25)` 的**实心履带盒**（从地面一直砌到车体下缘）。

| 批次 | 打补丁 | 结果 |
|---|---|---|
| 2026-09-27a | 盒子的六个面逐面烘焙花纹 UV（摆正花纹位相） | 位相对了，但盒子还在 —— 侧视图整条下缘仍是一块板 |
| 2026-09-27b | 盒子的 ±X 面改喷装甲侧板（M.tone），负重轮横向外移 6cm 好露出来 | 轮子露出来了，却是**从侧板里穿模凸出**（用户第三次实报的"让坦克轮穿模凸出来"） |

**症结在盒体本身**：一个从地面到车体下缘的实心块，侧面**只能**是一整块板（要么挡轮、要么被轮穿）。
真实坦克的行走机构是两件互不遮挡的东西：**轮** + 绕轮的**带**。

## §2 修法：带环 + 轮 + 独立裙板（`js/15-vehicles.js`）

### 2.1 履带 = 绕全部轮子的**闭合带**（`trackBandGeo`）

侧视轮廓 = 接地段直线 + 两端圆弧（绕过主动轮/诱导轮）+ 回程段直线（+ 端轮抬起时从"端部负重轮正下方"
斜切上去的一段切线）。内轮廓与外侧廓**同构等长**（直线外移 `TB_TH`、圆半径 +`TB_TH`）⇒ 两条轮廓按索引
一一配对，直接连成 4 面带：

- **外表面** = 履带花纹（材质段 0，`TEX.track` 克隆）；
- **内表面 + 两侧断面 + 端轮** = 金属（材质段 1，`M.dark`，与负重轮同源）。

两侧共用同一份几何；每站 8 个顶点（径面用 4 + 侧面用 4），逐面法线；三角形绕向在 `tbBuilder.tri()` 里
**按几何法线与期望外法线同向自动校正**（写反了也不会整件在 FrontSide 下消失）。

### 2.2 端轮（主动轮 / 诱导轮）不再缺席，也不再单独占网格

- 端轮 = 带环两端圆弧里嵌的那个圆柱（半径/圆心与圆弧**逐位相同**），**烘在同一几何里**：
  德系黑豹原本已经顶到 `verify-vehmodels` 的网格数上限 36，再挂 4 个 Mesh 就破线；烘进几何后
  整车网格数**反降**（黑豹 36→33，四号 34→29）。
- 抬高档按剪影档 `TB_END_LIFT = {sherman:[0.22,0.10], pz4:[0.34,0.34], t34:[0.10,0.28], chiha:[0.18,0.14], vickers:[0.20,0.12]}`
  （单位 = 轮径的倍数，`[前, 后]`）：谢尔曼主动轮在前抬高、四号/黑豹前后都抬（德系标志性的高位主动轮
  轮廓）、T-34 前置大诱导轮几乎贴地而后置主动轮抬得最高。抬高量同时决定端轮半径（端轮顶面恒与回程段
  同高 ⇒ 回程段永远是**水平直线**）。
- 端轮纵向站位：前后对称（带环两端各超出车体 0.10m），但**至少**与端部负重轮相切 + 2cm ⇒ 取更外站的那个。

### 2.3 负重轮回到带环之内（不再穿模）

| 量 | 旧版（2026-09-27b） | 现版 |
|---|---|---|
| 轮心横向 | `trkSx + 0.06`（外移到侧板之外） | `trkSx`（履带中心线） |
| 轮宽 | `trkW + 0.02`（比履带宽） | `trkW − 0.02`（比带**窄** 2cm） |
| 轮面外沿 | 比侧板外沿凸 **+7cm**（穿模） | 比带外沿**内收 1cm** |
| 轮底 / 带环 | 轮底 0.06、履带底 0.03（两张皮） | 轮底 = 带环**内底面**（0.08）；带环外底面 = **0.03**（与旧口径逐位相同） |

回程段内面比轮顶高 `TB_TOP_GAP = 0.05`：悬挂每轮 ±0.17m 的上跳行程里，轮顶不会顶出带面。

### 2.4 花纹沿环向滚动（UV 口径重做）

- 花纹只铺在**带环外表面**，`v` 沿**环向**累加、`u` 跨带宽 ⇒ 花纹条永远**横跨履带、沿环向排开**；
- **环长取整贴**：`tileLen = 环长 / round(环长/1.5)` ⇒ 闭合处花纹对齐（无接缝），条距 8 条/贴 ≈ 17~20cm；
- **闭合段反卷**：环是闭合的，最后一段（接地段）要从第 n−1 站接回第 0 站 —— 第 0 站的 `v` 若是 0，
  那一段的 UV 就得倒着插值（接地段花纹会**反向跑**）。解法：给第 0 站另做一份 `v` 加**整圈**的副本，
  只给收尾那一段用（`C/tileLen` 是整数，对平铺贴图与 0 完全等价）；
- `update()` 的滚动量式子不变（`vel*dt/trackTileLen`），**符号改成 `-=`**：`v` 沿材料流向递增
  （接地段向后、回程段向前），前进时花纹整体沿材料流向走 ⇒ offset 必须减小。符号与 UV 方向由探针
  **闭环校验**（两者都反 = 履带倒转，改哪个都会报红）。

### 2.5 侧裙板 = 独立分片（`tankBuildSkirt`）

- **4 片/侧**（`00-config` 的 `skirt: 4`，四号/黑豹；旧值 3/2），片间 6cm 缝；
- 挂在**翼板外侧**：外沿 = `halfW`（与翼板同面），内面离带环外沿 1.5cm（永不共面/不穿模）；
- 下缘停在**轮心略上方**（`whY + whR*0.10`，露下半个轮），上缘到车体顶面下 4cm
  （**→ §6 追加修**：上缘改到与翼板顶面齐平）；
- 分片**合并成一个网格**（自建 BufferGeometry，逐面法线/UV）—— 旧版每片一个 Mesh，德系多出 4~6 个 draw call。

### 2.6 翼板下移 + 半宽口径零漂移

- 翼板（0.08 薄板）从"旧履带盒顶 + 5cm"下移到"带环顶面之上 5cm"（压着履带，不再是悬空的一块板）；
- **半宽 `halfW = trkSx + trkW/2 + 0.06` 逐位不变**：无裙板车的翼板照旧 `trkW+0.12`；有裙板车的翼板
  收窄到 `trkW+0.02` 把外侧让给裙板 —— 两条路的外沿都落在 `halfW` 上 ⇒ **推力框口径（`vehiclePushSoldiers`
  的 `max(2.05, halfW)`）与旧版完全一致**（`verify-vehmodels` 实测半宽逐型不变，最大偏差仍是 M26 的 +3.6mm）。

### 2.7 幽灵坦克同步（`js/15c-specveh.js`）

观战专属的"幽灵坦克"旧版也是一只实心盒（`0.62×0.92×(L+0.25)`）。现改为**复用同一套带环几何**
（`tkSpec` 派生 + `trackBandGeo`），材质换成幽灵的浅灰两段（不挂花纹贴图，全白剪影口径不变）。

## §6 追加修（同批，用户实机截图反馈）：裙板太高——“高出来一块”
