## 二、随机生成地图（A 批）

### 2.1 双阶段架构（时序是本批第一约束）
- **数据阶段 `js/00c-procgen.js`**（载入序 00-config → 本文件 → 01-audio…）：纯 2D 零 THREE。种子 → mulberry32 单源 → 村镇核心/两军基地 → 路网生长（全局目标+局部抖动，步进 13m）→ 带状地块（沿路段采样+侧向外扩 8.5~11.5m）→ 旗点（广场/村巷×1-2/两翼前哨）→ 农田/林地。产出写回 `CAMPAIGN.{flags,bases,roads,fields}` + 全局 `PGDATA`（建造阶段唯一输入）。
  - 时序依据：`FLAGS/BASES` 在 05c `buildWorld()` 调用后映射 `CAMPAIGN.flags/bases`（05c :2540/:2543），03-terrain `RURAL_FIELDS` 载入期捕获——00c 全部赶在它们之前 ✓。
  - `THEME`/`TEAM_FACTION` 在 **00-config 载入期**捕获（00-config :1176/:1345）——主题/阵营选择前移为 00-config 内 `PG` 引导（种子解析 + mulberry32），00c 不再改它们。
- **建造阶段 `layoutProcgen()`（05c）**：kind→既有生成器映射（cnHouse/logCabin/twoStoryHouse/buildBarn/silkFactory/buildChurch/watchtower/windmill **全部复用零新模型**），落位走 `placeAt` 统一互斥；掩体审计（干道每 ~42m 交替两翼一处 + 村口拒马）+ 旗圈沙袋/木箱 + 林地撒树 + 田缘围栏（中式矮石墙/欧式树篱）。

### 2.2 战斗逻辑层（"符合战斗逻辑"的硬规则，探针断言）
- 旗点 4~5：广场（核心净空 19m 无建筑）+ 村巷旗（与既有旗 ≥62m，违规自动沿巷回退）+ 两翼前哨（基侧干道 30% 处，距基地 ≥55m，own:0/own:1 开局归属）；两两间距 ≥60m。
- 路网连通：两干道必从各自基地抵达主街两端（谁近进哪头）；主街过核心；探针断言首末点几何。
- 建筑净空：距路 ≥6m、距核心 ≥19m、距基地 ≥38m、距旗圈 ≥r+4.5m、互斥圆不叠。
- NAV 放行：旗圈 `NAV_CLEARS` r=5.2；通视走廊靠掩体审计（干道 42m 间隔）控制。
- 地形 `case 'procgen'`（03-terrain）：缓丘平原（幅 ~1.7m，foundation 垫平即可建），相位出自 `PG.ph`（同种子同地形）。

### 2.3 种子系统
- 种子来源：URL `?pseed=` > `sf_pseed`（迷你游戏面板输入框）> 每局随机；选中值由 00c 写回 `sf_pseed`（仅 procgen 图，普通图零接触）。
- 布局级确定性：05c `wr()` 加 `PG_WR_SEED` 编程播种钩子（05-world，其他图恒 0=逐位现状）；00c 数据阶段自备 n32 流——**同种子：地形相位/路网/地块/旗点/建筑落位全同**（探针两次运行逐位断言）。
- 菜单：迷你游戏面板「随机新种子」立即掷新 + 种子输入框（留空沿用上局图）；战役列表的「随机战场」卡 = 普通占旗玩法（卡片点击清 `sf_zsub` 双保险）。

## 三、丧尸模式（B 批）

### 3.1 实体（`js/25-zombies.js`，载入序 23b 后 24-main 前）
`class Zombie extends Bot`（team=2 假想队，00-config 按 `ZOMBIE_MODE` 给 `TEAM_FACTION/uniformMats` 挂档——**非丧尸局零数组变化**）：
- 覆写 `setClass`（压掉枪械链，无 WPN_DEFS/TEAM_FACTION[2].cls 消费）、`damage`（尸不伤尸；受击迁怒）、`die`（**零票务**：不扣 tickets/不 noteDeath/不进 fieldCount/wipe；击杀归因+玩家 onPlayerKill 照走）、`update`（自绘脑）、`updateMesh`（**腿=legIK 正常步态；双臂前伸**肩前举 ~85°+步频摆动+挥击下劈；尸变起身 0.9s）。
- 入 `soldiers/combatants` ⇒ 玩家子弹/爆炸/坦克弹/小地图/击杀播报全链自动生效（Bot perceive 的 `e.team!==this.team` 过滤天然把丧尸当共同敌人）。
- 三变体：普通尸 spd1.5/hp100；跑者 spd2.2(+冲刺1.6)/hp60/视距34；重尸 spd1.1/hp380/伤害80/拆工事 3×/体型 1.12×。

### 3.2 脑 FSM（用户口径逐条）
`游荡（3s 重算存活人类质心 + 摆头）→ 视距内见人（28/34m，无 FOV，raycastWorld 墙体遮挡+烟/庄稼遮蔽复用）→ 奔跑追击 → 近战（2.2m 进入，1.1s 一拍，380ms 延迟判定仍在 2.6m 内才结算）`；受击瞬间仇恨转攻击者（`aggroT=nowT+6s`，无视视距）；丢失（死/超距 46m/到期）→ 回游荡。卡住 1s → 抡臂砸前方结构（`damageStructures`，重尸 3×）。

### 3.3 感染链
- Bot 被尸杀：`14-bots die()` 头部钩子 → `zombieInfect`（alive=false + `respawnT=1e9` 学 capCrew 不占用重生 + 本体隐藏 + 释放机/炮位 + 原地 spawnZombie 18% 跑者）；载具乘员/飞行员/大舰炮手不尸变走原链。
- 玩家死亡（裁定③ 字面口径=无论死因）：`18-game die()` 内 `spawnZombie(尸体位)`；死亡/重部署流程零改动。

### 3.4 刷怪导演 + 胜负（24-main 每帧 `zombieFrameTick`）
- 刷点：边缘环 288~316m，距存活人类 ≥55m，occBlocked 放行，12 次尝试。
- solo：撑过 600s `requestEnd(player.team)`；票尽+全灭走 21-match 丧尸分支（无旗权门槛）。单队模式 team≠player.team 零编制（23-deploy 步兵/坦克/飞机三处 continue）。
- teams：票=队命池；占满全旗不触发兵力归零、旗权压制关闭、无时限结算（21-match 三处 `!ZOMBIE_MODE` 守卫）；票尽全灭=出局，最后未出局的队胜。导演补「兵力耗尽·全灭后出局」播报。
- 占领计数排除丧尸（updateFlags/updateSpots 两处 `if(c.zombie) continue`——team2 落 `else c1++` 的坑由此堵死）。

### 3.5 ZP 经济 + 工事（裁定④/⑧）
- ZP：开局 200；击杀普通尸+15/重尸+40（onPlayerKill 钩子）；占旗+100（21-match 占领完成块）；HUD 顶栏 `☣ ZP · 阶段 · 倒计时/存活队伍`。
- 商店件（工程建造轮选追加）：重机枪 150 / 瞭望塔 250 / 弹药箱 80，扣 ZP 读条建造；沙袋/铁丝/拒马/医疗箱照旧免费建造点。
- 工事血量：`registerFortHP`（25-zombies）把 BUILDS 新增碰撞盒按 dBegin/dEnd 同一数据形状登记为轻量 DESTRUCTIBLES（bi 索引+dGroup 回指针+structBounds）；命中走 `damageStructures`/`boxDist3` 既有单源，hp 归零走 `destroyStructure` 通用拆毁；导演扫表把死组对应 BUILDS 条目下线。血量表：沙袋300/铁丝100/拒马150/MG400/医疗箱200/塔500/弹药箱150。
- 已知取舍（实机验收关注）：MG 阵地被打烂后 MG42S 编制件仍在（可再占用）——与"摧毁固定炮位"同款现状，未在本批扩深。

### 3.6 表现
- 皮肤：丧尸档制服（灰绿褪色+灰皮）+ 双臂前伸；尸变起身动画；名牌隐藏。
