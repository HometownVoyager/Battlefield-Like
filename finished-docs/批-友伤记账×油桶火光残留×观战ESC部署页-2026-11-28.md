## 探针新坑（记账）

1. **桩 classList 惰性空实现**：`_bootstub` 的 `mkElement.classList` 是 `add(){}/remove(){}/contains(){return false}` 全 no-op——对 `#deploy` 的显隐断言全部空转，`showDeploy` 后"部署页开着"的判据是**虚绿**。修法：探针侧给目标元素换真 Set 版 classList（起始态对齐 index.html 的 `class="screen hidden"` 基线）。承 specpose 批 `querySelectorAll` 空表同族（第二件桩不忠实）。
2. **独立 boot 忘开局**：T4 用第二个 `boot()` 防污染，但没调 `startBtn.onclick()+deployPlayer()` ⇒ 停在主菜单，`loop()` 冻结 ⇒ `updateFires` 从未跑 ⇒ 灯池断言全空转虚绿。多 boot 探针每个 boot 都要走一遍开局链。
3. **连杀账跨测试污染**：T1 给玩家攒 4 连杀后，T2 的 `registerKillScore` 吃连杀倍率（300×mul）⇒ Δ分断言失真。多杀测试链之间要 `killStreakN=0; killStreakT=-99`。
4. **相机会被写回**：直接 `camera.position.set()` 放火源观测点会被 `updateCamera` 逐帧抹回玩家机位——火源要放**玩家出生点旁**，不是挪相机。
