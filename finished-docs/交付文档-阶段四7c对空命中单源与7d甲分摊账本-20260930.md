## 4. 保留面（红线）

1. **判定几何只许调 planeHitTest/planeNearTest**，不许再手写 size/距离对机判定；`planeHitR` 是唯一机型命中半径。
2. `GROUNDGUN_VS_AIR`(0.5) 只朝 Bot 射手收：玩家操作的高炮/步兵枪不减；空对空机炮（mgDmg×0.7）与航弹不吃。
3. `noAirHit` 旗标 = 飞机机炮对空伤害的唯一豁免单源（AI 机射手是 crewBot，身份判据不可靠——本轮 R2a 钉值抓出的生产级双伤已以此堵死）。
4. 索敌不放开：步兵/坦克/两栖车**仍不主动点名飞机**（平衡批裁定）；还击路径 botEngageR 口径不动。
5. 引信≠机体：高炮近炸 8/11 是引信半径，保留在 updateFlak 调用点，不进 planeHitR。
6. 交接面冻结：AAGUNS 条目结构 / flak 弹管线 / TV 三件套 / 15d-f 冻结签名零改动（S4 钉住）。

## 5. 实机验收单（Ctrl+F5，戳 20260930g）

1. **空空机炮**：缠斗手感不变，隔着一道山梁不再打中机（旧隔山打）。
2. **贴地扫射步兵阵**：挨扫的兵会朝你还击，命中只是刮血（~0.5-1.5/发 Bot），可以无视但别悬停。
3. **机枪工事**：被你扫射时还击的机枪刮血略多（[2,5]×0.5）；你操作机枪工事朝敌机扫射同样有效（玩家全档 [2,5]）。
4. **多门高炮阵地**：两架编队过顶不再全部火力集中第一架（分摊）；目标击落后火炮转火。
5. **上一轮未验收项一并**：接管保底高度/规避（7b 热修）+ 空对地平衡四条（高炮 140m/减半、玩家高炮火力不变、跳伞不点名、伞上开枪被还击）。
