# 钢铁前线 · ONE-FILE 战役合集 —— 辅助开发文档

> **《钢铁前线》(STEEL FRONT) 是一套二战主题的单机 FPS 战役合集游戏**，
> 基于 Three.js WebGL 渲染 + Cannon.js 物理，纯前端、无后端，双击即可运行。

**⚠️ 重要约定：每次更新游戏代码，都必须同步更新本 README！**

> 本文件是项目的唯一开发手册，供你（和任何接手的人）理解结构与维护游戏。
> 如果你改了代码而没有更新这里，下一次改版时就会迷失方向。
> 具体做法见文末「更新工作流」。

---

## 一、快速开始

1. **直接运行**：用浏览器（Chrome / Edge）打开 `Index.html` 即可开始游戏。
   - Three.js 与 Cannon.js 通过 CDN 加载，需要联网。
2. **本地服务器（可选，推荐调试用）**：
   ```bash
   # 在项目根目录执行
   python -m http.server 8000
   # 然后访问 http://localhost:8000
   ```

## 三、技术栈与运行架构

| 项目 | 说明 |
|---|---|
| Three.js 0.152.2 | WebGL 渲染（CDN 引入） |
| Cannon.js 0.6.2 | 布娃娃/碎块刚体物理（CDN 引入） |
| 语言 | 原生 JS（无构建工具、无打包器） |
| 运行方式 | 浏览器直接打开 `Index.html`，`file://` 或 `http://` 均可 |
| 存档 | `localStorage`：`sf_campaign`(战役)、`sf_size`(规模)、`sf_tsize`(触控键大小)、`sf_mobile`(强制移动端)、`sf_exp`(实验模式) |
| 调试服务器 | `node .serve.js` → http://localhost:8000（本机无 Python 时的替代方案） |

### 主循环（js/24-main.js 的 `loop()`）

每帧按固定顺序执行：寻路脏标记 → 铁丝网/上浮动画 → 玩家更新 → 相机 → 阴影 → 天气 → 烟雾 →
Bot（带 LOD 跳帧）→ 医疗箱 → 坦克 → 飞机 → 坠机残骸 → 布娃娃 → 炮弹 → 防空弹 →
手雷 → 颗粒/拖痕/弹壳/血渍 → 旗点 → HUD。
**新增【每帧逻辑】时，请把调用挂进 `loop()` 的对应环节，不要自己再开循环。**

### 坐标系约定

- 全局：地图中心为 `(0,0)`，X/Z 为平面坐标，Y 为高度；地图边界 ±160（`MAP_SIZE=320`，**雪峰山 1945 为 `mapSize:800`→±400**，其余战役不变）。
- Yaw 朝向：`Math.atan2(dx,dz)`，与 Three.js 默认一致；玩家相机为负 Z 前向。
- 地形高度一律通过 **`heightAt(x,z)`** 查询（含平整区/战壕/河流修正）；
  物体与地面贴合请用它，不要自行估计。
- 出生点、旗点、基地、道路均由 **`CAMPAIGNS` 战役定义表**（js/00-config.js）驱动。

## 四、开发纲领与计划（后续所有地图改造的准绳）

> 2026-08-24 由「诺曼底博卡日试点」与断崖公路打磨经验沉淀。这里写的是"为什么这么改、接下来改什么、怎么验收"，代码现状看第五~七节。

### 4.1 总纲领

1. **地貌语义化**：核心问题不是"做坏了"，而是地图没有地貌语义——地形是数学函数（正弦叠加）、布局是旗点撒点。**每个地图必须有一个语义分区表**（田块/山脊线/街区网格，如 `CAMPAIGN.fields`），地形高度、地面色带、植被、建筑、掩体全部由它驱动，玩家一眼能认出"这是山、这是田、这是城"。
2. **从断崖公路学到的事**：`roadDist` 相对公式（谷道走廊+山坡+山肩）是"像山"的正确姿势；同样，农田的相对语义是"田块网络"。所有新地图优先考虑**距离场+分区表**，而不是再加一层正弦。
3. **真实感与玩法的三条红线**（不可违反）：
   - 地貌可以陡、险、密，但**主要通道必须可通行**——公路走廊、桥、垭口、树篱豁口；
   - 旗点/基地/出生点必须可达，Bot/坦克寻路不得堵死（沙箱断言兜底）；
   - 软遮蔽（庄稼/烟雾）**不挡子弹、不挡移动**，只遮 Bot 视线——与"硬遮蔽（树篱/石墙/建筑）挡人挡弹挡视线"严格分层。

### 4.2 三种遮蔽层（玩法-视觉双设计）

| 层 | 载体 | 挡人 | 挡弹 | 挡 Bot 视线 | 典型玩法 |
|---|---|---|---|---|---|
| 硬遮蔽 | 树篱/石墙/建筑/沙袋 | ✓ | ✓ | ✓ | 正面掩体、侧翼遮挡、Bot 绕行进田 |
| 软遮蔽 | 庄稼（麦/玉米/稻丛）、烟雾 | ✗ 可穿行 | ✗ 穿透 | ✓（庄稼按顶高分级） | 蹲麦田虚隐/露头、玉米站隐、抽冷枪后转移 |
| 开阔区 | 田间空地/村心/谷道走廊 | — | — | — | 装甲对轰、低杆火力对射 |

庄稼顶高分级（`CROP_FIELDS.h`）：麦 1.15m → 蹲伏(1.0~1.15)隐、站立(1.4+)露头；玉米/稻丛 2.0m → 站立(1.62)也隐。视线判定=线段与田块相交区间内任一点低于作物顶即遮蔽（线性插值两端取 min，单点判定会漏斜射）。

### 4.3 语义分区表规范（新战役/改造必须遵守）

- **一个表驱动全部**：分区表定义在 `00-config` 战役条目（如 `CAMPAIGN.fields`），地形色带（03-terrain）、作物/树篱（05c-layouts）、避让（野树不落田）共读——严禁两处各写一套坐标。
- **每个分区绑定**：地色调制、软遮蔽顶高、外围掩体（树篱/田埂/断崖）、禁入区（植被、残骸、弹药箱兜底）。
- **随机一律走种子流 `wr/wri`**（`?seed=N` 可复现同一布局），禁用 `rand()` 摆布局。
- **新碰撞体走占位互斥链**（`propFree/propTake` + `freeSpot` 建筑足迹），并被沙箱断言覆盖。
- **软遮蔽不写 CYLS/BOXES**（会进 OCC 堵 Bot 寻路、挡子弹），只登记 `CROP_FIELDS` 矩形。

### 4.5 每关改造后的验收标准（用户实机验收，我不碰浏览器）

1. **一眼辨识**：截图对照——这关一眼能看出是农村/山地/城市，而不是"草地撒房子"；
2. **遮蔽层可用**：蹲/站差异明显、Bot 搜田有手感、开枪暴露后 Bot 会压制扫射庄稼；
3. **通路无死档**：豁口/桥/垭口可通行，Bot/坦克能跟进战局；
4. **HUD 同步**：小地图/部署图把语义分区（田块/沟壑/街道）画出来；
5. **沙箱全过**：verify-layouts/buildings/rooffall/boot 四沙箱全量回归（13 战役）+ 对应新断言（如旗点净空）。

## 六、关键数据结构速查

- **`CAMPAIGN`**（当前战役）：`{id,title,sub,f[],theme,terr,layout,mode,atk,flags[],bases[],roads[],trench[],spawns[],tankN[],botMul[],convoy?,bridge?}`；
  `mode` 取值：`assault`(攻防) / `conquest`(征服) / `demolition`(破袭) / `clash`(遭遇·无旗点绞肉) / `convoy`(劫道·车队)；
  `flags` 为空时配合 `spawns`(前出点) / `tankN` / `botMul` 生效；`convoy` 字段：`trucks/hp/spd/gap/escapeN/escortTeam/supplyLife`（仅劫道，roads[0] 需按行车方向书写；supplyLife=劫道方临时补给点存续秒数）；`bases` 可为空数组（断崖公路=无基地: 劫道方限时补给点+护运方随车队/贴车补给）；`bridge` 仅胡康河谷(大桥拉锯战)。
- 旗点 `id` 支持多字中文名（胡康河谷为 西岸/桥西/大桥/桥东/东岸），旗帜贴图/HUD 旗标/小地图/部署图已自适应。
- **`PLAYER` 对象（js/18-game.js）**：`pos/vel/yaw/pitch/hp/stamina/slots/curW/nadeCount/onVehicle/onMG/...`，
  及其方法 `damage() / suppress() / fireT` 等；`player.isPlayer===true` 标记。
- **`Bot` 类**：`team/cls/pos/hp/target/objective/path/suppression/...`，核心方法是 `update()`。
- **实体数组清单**：`soldiers / tanks / planes / shells / flakShots / nades / rockets / particles /
  tracers / casings / SMOKES / MORTARS / BUILDS / MED_CRATES / DEATH_HEAT / planeWrecks`。
- **判定管线（js/13-combat.js）**：`raycastWorld()` 打静态体 → `rayCyl()` 打坦克/士兵 → 伤害/溅射；
  `explodeAt()` 是本作所有爆炸的最终裁决点。
- **效率约定**：静态碰撞体用 `RGRID`(BSP 网格)加速射线；Bot 视野判定前有 `raycastWorld` 遮挡检查；
  Bot 重活走 `NAV.findPath()`（A*，带路径平滑与占用栅格）。
