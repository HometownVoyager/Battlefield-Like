## 一、七条复报的根因与修复

### ① "撞船穿模仍十分严重, 这就是 Bot 集体落水的原因之一——被其他大船挤下去"

两个独立病根, 全修:

1. **舰-舰穿模 = 旧版只测对方"中心点"是否落进本舰外接矩形**。T-bone / 斜擦时 b 的舰艏已插进 a 的舷侧
   十几米, b 的中心还在外面 ⇒ 判不出重叠, 整条船对穿。修复: `capPushCap` 升级为**双 OBB 的 2D SAT** ——
   取两舰各自的局部 x/z 轴共 4 根分离轴, 任意一根投影不重叠 ⇒ 未接触; 全部重叠时沿**穿透最浅**的轴
   两舰各退一半 (+5cm 余量防浮点贴合)。四角点由新助手 `capCorners` 单源 (capPushCraft 共用)。
   分离量口径: 每轴取 `escR=maxA−minB / escL=maxB−minA` 的**较小者** (逃逸量), 不用"重叠深度"
   (`min(maxA,maxB)−max(minA,minB)`) —— 一方投影被另一方包含时 (同心/大压小), 重叠深度给的是被含宽度,
   推不开; 逃逸量才是把 B 完全推出 A 投影所需的最小位移。`capPushCraft` (艇-舰) 同口径升级。
   **S19** (新): T-bone 摆位 (b 艏向垂直、舰艏插入 a 舷侧 5m) 必须被检出且推开后四角 SAT 复查分离。
2. **Bot 被挤下海 = capPushBody 水线层没有上限高度门**。邻舰的 hull 矩形在本舰**甲板高度**上照样横扫
   (人站在甲板上 = 邻舰水线推出波及范围), 整片乘员被推离舷缘落海; 且两舰贴帮时两片甲板矩形重叠,
   两道护栏各自为政互相对挤。修复 (15h capPushBody 双门):
   - **水线上限门**: `pos.y > s.pos.y+hullH×0.75` ⇒ 这艘舰的舷侧不挡 (整个人已在舰体干舷之上, 只可能站在
     邻舰甲板上) —— "被别的大船挤下海"的根;
   - **护栏执法单源**: 先判"脚下这片甲板" (支撑舰 sup, 容差与承载同口径 −1.2m), 甲板层里
     `s!==sup` 的舰**只跳过不再夹** —— 别舰的甲板与本舰重叠时, 护栏只归脚下这片甲板管 (对挤的根)。
   **S20** (新): ① cv 顶到本舰甲板旁, 甲板上的人不动 (上限门); ② 同档 bb 贴帮, 重叠带内的人不对挤
   (阴性对照: 无邻舰时舷缘夹回 0.34m 照常)。

### ② "大炮塔仍然有浮空的"

上批把炮位坐标收进了甲板室足迹, 但 bb 的**超射塔** (中部第二座主炮, ringZ 36) 塔底 y=15.2 而
甲板室只铺到 z=24 —— 塔底以下没有任何结构, 从主甲板面看塔是悬空的。修复 (15g capBuildModel):
- 每座"塔底高于甲板面"的主炮塔补**炮座 (barbette)**: `cpCyl` 环形塔基 (半径 ringR×0.95, 上宽 6%),
  从甲板面顶到塔底; 命中盒 `cpBarbette{i}` 入 R.boxes (能被打、能被命中判定)。
- 主炮塔命中盒下沿从塔顶延到**塔底** (cpTurret 盒的 ly/hh 重算) —— 旧版只包塔体本身, 炮座一段打不中。
**S21** (新): 逐塔审计 "塔底>甲板面 ⇒ 必须有炮座, 且炮座顶=塔底 (埋深 ≤0.5m)"; bb_us/bb_jp 各补 1 座。

### ③ "Bot 操作炮的动作非常不自然, 航母上的小炮等建模简陋、无法转向和开火"

三个层面, 全修:

1. **建模简陋** (15g cpBuildMount 重写, spec 驱动): `CAPITAL_SPEC` 各炮位新增 `barrels` (bb 副炮单管 /
   bb 防空双联 (us) 三联 (jp) / cv 防空四联 (us) 三联 (jp) / cv 副炮双联), 按管数布管距
   ([±0.11] / [±0.22,0] / [±0.21,∓0.07]) + 环形炮座圈 + 弹药箱 + 随管数加宽的防盾 (shW=0.30+nBar×0.30)。
   **S26** (新): 四联/三联/单管逐 spec 出模 + 主炮盒下沿=塔底。
2. **动作不自然 = 炮手网格不随炮转** (15h capCrewTick): 炮手网格挂在舰体局部系, 转角必须用**局部**
   瞄准角 —— 修复: 每帧 `mesh.root.rotation.y = turYaw/secAimY/aaAimY[t.idx]` (与炮同一数据源, 零同步),
   出生时的初始朝向同步修 (旧版用了世界系 b.yaw, 局部系里读作横躺)。**S23** (新): 网格转角与
   secAimY/turYaw 逐位相等。
3. **无法转向和开火 = 索敌圈被开火圈锁死** (15h _pickPlaneTarget + aiTick):
   - 旧版 `_pickPlaneTarget` 按开火圈 aaR 170 索敌 ⇒ 170m 外连目标都拿不到, "转都不转", 远圈炮位读作死件。
     修复: 索敌/跟踪圈改按新常量 **aaAimR 420** (00-config 单源, 注明"瞄准圈≠开火圈"), 开火圈 aaR 170
     **是 2026-10-01 平衡裁定, 不动** —— 420 内跟踪瞄准 (转得着=炮活着, 进圈即有诸元), 170 内才出弹。
   - 舷角闸门 (aaArc) 的舷角改按**舰体中心**取 (旧按炮位自身): 炮位自带 ±12m 横向偏置, 死艉线/艏线上
     的目标从每个炮位看都"偏在对舷" ⇒ 全部炮位被闸成哑巴 (艏艉直线接近不可交战); 按舰心取则目标
     真在何舷、何舷参战, 艏艉窄角由 |rel|≤aaArc 的全开门覆盖。
   **S22a** (新): 副炮打小艇出弹 + 防空开火圈内敌机出弹 (假想敌注入, 240 帧全链)。**S22b** (新):
   远圈 300m (瞄准圈内/开火圈外) —— 塔必须照转, 且不出弹 (瞄准圈≠开火圈的两侧都验)。

### ④ "总是有 Bot 在 0 血时赖着不死"

溅射/伞降倍率等**非整值伤害**把 hp 打到 0<hp<1 的残血 —— 名牌 `Math.round` 显示 "0/100" 而人还活着,
玩家读作"赖着不死"。修复 (14-bots Bot.damage): `hp∈(0,1) ⇒ 钉到 0 = 击杀` (走正常死亡链, 票务照常)。
**S24** (新): damage(99.5) 后 hp=0.5 ⇒ 即死 + 队伍票 −1。

### ⑤ "巡飞弹在离甲板比较近却没有接触的时候会被引爆"

capitalSolidAt (上批新单源) 的实体带旧到 `甲板面+2.6` —— 甲板上空 2.6m 都是"实心", 巡飞弹贴甲板掠过
还没碰到就撞空气引爆。修复: 实体带收窄到 `甲板面+0.25` (甲板上空=空域, 与"甲板以上没有碰撞"的
用户预期一致); 13-combat 的航弹甲板触发带同步收窄。**S17a** 判据随新带宽重钉 (甲板面+0.1 实体 /
+1.5 必须不拦)。

### ⑥ "飞机在起飞之前是嵌在甲板上的"

机模原点在机身轴线 (螺旋桨 y=0, 无起落架建模), 机腹散热器最低点在原点以下 ⇒ 按甲板面摆放时
下半截埋进甲板。修复 (16-aircraft 新单源 `plParkLift`): 抬升量 = `fr×size + 0.24×size` (机头整流罩 +
机腹余量), 接线三链: capParkPlanes (开局停放) / capTryArrest (触舰拦阻) / capArrestTick (拦阻保持)。
**S25** (新): 停放+拦阻两链的高度 = 甲板面 + plParkLift; phase5-capital R17/R19/R20 期望同步重钉。

### ⑦ "在大舰上 Bot 和玩家的行进仍然会被严重影响"

与 ① 同根 (capPushBody 水线横扫 + 跨舰对挤) —— ②的双门修复即本条修复; S20 的三个站位判据
(护栏内 8.0m 不动 / 重叠带 6.6m 不对挤 / 舷缘 8.8m 夹回) 就是"行进不被影响"的量化口径。

## 二、顺带修复 (探针卫生, 本批发现)

- **verify-navalcap S18/S19 残位毒化**: `capitalReset()` 不还原 pos.x/z/yaw (respawnClear(null) 只复位

  +1e-13 的假重叠 (~1/6 偶发)。修复: 分离判据 `<=0` → `<=1e-6` (8 连跑稳定)。

## 四、实机验收清单 (对照七条复报)

1. 两舰对撞/斜插: 应被顶住互推 (各退一半), 不再对穿; 贴帮航行时甲板上的人不再被邻舰扫下海。
2. bb 中部超射塔: 塔下应有炮座承托 (不再悬空), 打炮座有命中反馈。
3. 航母甲板缘小炮: 有管数差异 (四联/三联) 与炮座圈/弹药箱; 炮手面向目标随炮转; 远至 ~400m 炮塔
   跟踪、~170m 内才开火。
4. 溅射后名牌 "0/100" 的 Bot 应即死, 不再赖着。
5. 巡飞弹贴甲板掠过不再凭空爆; 触到甲板面/舰体才炸。
6. 航母停放/拦阻的飞机整机坐在甲板面上, 不再半埋。
7. 大舰甲板上跑动不再有莫名阻力, 不会被推向舷外。
