## 一、逐条根因与修法

### ① 阵营栏一方显示灰色，而非该有的蓝色
**根因（id 撞车）**：顶部旗点图标行的 DOM id 用**旗点名字**生成（`fi旗舰舰桥`/`fi前主炮`…），而海战图两军的旗点**同名**（各有一组 前主炮/舰桥/后主炮，珊瑚海同款三对）⇒ 同页 6 个图标只有 3 个唯一 id。后果两头：
- 22-hud `updateHUD` 按 `el('fi'+f.id)` 上色——`getElementById` 永远命中**前一个**（先建的那个）元素，于是前半行（team0 的三面旗）每帧被 team1 的旗状态**覆盖**成红；
- 后半行（team1 的三面旗）对应的元素**永远查不到**（返回的是前一个）⇒ 从未获得 className ⇒ 停留在建出时的无 class 态 = CSS `#flagIcons span` 的**灰底灰字**。
日军玩家视角：`[红红红 | 灰灰灰]`——"一方显示灰色，而非该有的蓝/红"。

**修法**：图标 id 改按 **FLAGS 索引**（`fi0…fi5`），`23-deploy.applyFlagOwnership`（建）与 `22-hud.updateHUD`（读）同一序（`forEach` 双参）。陆战图 A..E 逐位兼容（原来旗名即 A..E）。

### ② 旁观模式下甲板以上的所有东西没有碰撞 ＋ ③ 在船上移动非常慢（同根）
**根因**：`15h capRideCollect` 的乘员收集循环里有一句 `(a.isPlayer&&a.spectator) continue`——观战玩家被排除在"甲板乘员"之外，于是：
- **搬运链（capRideCollect→capRideApply）不含他** ⇒ 舰以 4~4.8 m/s 巡航时甲板在他脚下变成"跑步机"：步行 4.3 m/s 逆舰向走净速度≈0，横穿飞行甲板还会被持续带偏——"在船上移动非常慢"；
- **局部障碍绕行（capLocalSolve）只跑在乘员表上** ⇒ 上层建筑/舰桥塔/炮塔/烟囱/舰岛对他**全体不拦**——"甲板以上全都没有碰撞"。

**修法**：删掉该排除（观战者既已站上甲板就是"甲板上的人"，与普通玩家同一支搬运+绕行）。**时停不冻观察者的口径不受影响**：冻结帧舰不动（step(0)），搬运=恒等映射，观战者本体链照走 pdt；时停中在甲板上走动，绕行照常生效（冻结的是战场不是人）。

### ④ 旗帜卡在甲板以上的结构里
**根因**：两张全海图的"舰桥"旗点坐标落在舰桥塔足迹里：
- 珊瑚海 旗舰舰桥 旧世界坐标 (±220,∓70) = 舰体局部 **(0,+10)**——正落在甲板室（lx±5.8）/塔基层（可视 ±6.0/命中盒 ±6.19，z 带 [−19.8,+25.8] 覆盖 +10）**正中**：旗杆整根插穿甲板室顶进塔身，旗面（杆高 6.25m）在塔层 1/层 2 的墙里挥舞，从外面看旗"没了"；
- 铁底湾 舰桥 旧局部 (7.2,+2)：杆身距塔基层墙面只有 1.2m，旗面（挂边在杆上、外伸 2.4m、方向随舰 yaw 旋转）**挥向内侧时深入舰桥塔墙面 1m+**——舰一转向就"旗面插进舰岛"。

**修法**：两图四处旗点统一改到舰体局部 **(+8.3,+14)**（右舷舷侧走道，00-config 单源，坐标=各舰 t=0 位姿换算）：
- 杆身距塔基层可视墙面 2.3m / 距命中盒 2.1m / 距甲板缘 0.7m（护栏夹持带内，玩家贴得着、占领圈照常覆盖）；
- 旗面挥向内侧时距 pagoda 外挑层（±5.88）相切、距美式二层（±5.16）0.74m；z=+14 避开舰桥翼台（z≤+4.1）与艏炮座（z≥+29.8）；主炮炮管扫掠圈（塔心 ±12m）不覆盖 lx=8.3；
- 换算（`yaw=±π/2 ⇒ x=基准±lz, z=∓lx`）：珊瑚海 (−216,−78.3)/(216,78.3)，铁底湾 (−151,−8.3)/(151,8.3)。
旗点随舰的搬运链（`capitalFlagTick` 按局部坐标反算）自动跟随，无需另改 15h；甲板弹药箱按旗点 ±4m 落位，随之离开塔基。

### ⑤ 友方之间仍会撞船和穿模，且十分严重（两半各修一半）
**a) 穿模半边**：`15d navalPushCraft`（艇↔艇/艇↔坦克分离）的推挤位移有一道 **0.5m 绝对限幅**——两艇 PT 全速对开（29+29 m/s，相对 58 m/s ⇒ 每帧闭合 0.97m@60fps）时，每帧**穿透增量 > 限幅**，推挤永远追不上运动积分，两条艇几帧内互换位置 = 对穿。旧注释"限到 0.5m ⇒ 深穿透分几帧解完"只对"深穿透静止对叠"成立，对"持续对开"不成立。**修法**：删掉绝对限幅，只留 `(3+spd)*dt*2.2` 的平滑限——它在低闭合速下限住抖动（每帧至多 2.2 倍闭合量的修正），在高闭合速下恒大于当帧穿透增量 ⇒ 穿透当帧解完；真正的深穿透（出生重叠/被炸叠上）仍按该限分几帧解完，观感是"顶住"不是"瞬移"。舰↔艇（capPushCraft）与舰↔舰（capPushCap）本来就是当帧全量解算，不涉及此病。
**b) 撞船半边**：Bot 艇的驾驶相位（advance/hunt/engage/evade/reefOut）全部经 `14-bots navSteer` 单漏斗出舵，但**没有任何"前方有船"的感知**——两条友艇追同一条环带航点、或推进航线撞上己方大舰时，就顶着对方开。**修法**：新增 `navVesselAhead` + `NAV_AI.avoid{Look,Pad,Turn,Slow}` 四参数单源，在 navSteer 里做**让路预折**（唯一接线点，全相位共用）：
- 探测：本艇朝向前方 `(双方半长和)×2.6+12m` 带内、舷向偏移落在"正瞄着它"走廊（双方半宽和+5m）里的最近一条船，**不分敌我**（撞谁都算事故）；
- 让路：朝目标所在舷的**反侧**打 1.0 rad 舵偏——镜像对称 ⇒ 两艇对开时自动一左一右错开（对开公约）；
- 减速：距它船体 <22m 油门打 0.45 折，地板 0.2——"艇永远在动"纪律（防触发车组驻守下船）不破坏；
- 只折 `fwd>0` 的前进舵：倒车脱困（navUnground 直调 drive）与撤退不归它管。

## 四、实机验收清单（请按条操作）

以**珊瑚海**（或铁底湾）开局，观战模式：
1. **阵营栏**：顶部旗点图标行应为 6 个图标、各自颜色正确——我方三面蓝、敌方三面红；任一舰瘫痪后它的旗就地变灰（既有裁定），另一队仍蓝/红不再连带变灰。
2. **甲板碰撞（观战）**：走上任一巡航中的战列舰甲板，朝舰桥塔/炮塔/烟囱走——应被实体挡住绕行，不再穿模；飞行贴着甲板掠过舰岛也应被推开。
3. **船上移动（观战）**：站在甲板上静止不动 ⇒ 应随舰平移（不再像跑步机）；逆舰向行走应有正常步速（相对甲板），不再"原地踏步"。
4. **旗帜位置**：找到"旗舰舰桥/舰桥"旗点——旗杆应立在舰桥塔**旁边**的舷侧走道上，旗面全程可见、不再插进结构里；舰转向/巡航全程跟随。
5. **友舰不穿模**：己方两艘 PT 艇对开/追同一航点时应当"顶住+错开"，不再互相穿过；Bot 艇接近己方大舰应提前让路绕开，不再贴着舷侧磨。高速对穿若仍偶见，请截图报位置。
6. 回归底线：随便打一局确认炮塔/炮手/鱼雷/瘫舰占旗等既有功能无异常（phase5 41 + navalcap 58 + seabatch 8 + specbatch 79 沙箱全绿背书）。
