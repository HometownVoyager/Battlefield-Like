## 1. 空战系统全貌（现状事实）

### 1.1 规模与结构
- 飞机本体+AI+防空炮弹 全在 `js/16-aircraft.js`（663 行）：残骸更新 12-68 ｜ 地形巡航层 69-83 ｜ 剪影建模工厂 84-174 ｜ class Plane 175-605（构造/建模/update/planeAI/playerFly/takeDmg/die/respawn）｜ 防空炮 607-663。
- **空战 AI 主体在 16-aircraft 的 `planeAI`（354-478，约 125 行），不在 14-bots**。14-bots 只有防空炮 Bot 生态（登炮/火控/让位）。
- 机型数据单源：`00-config.js` FACTIONS[f].planes，六阵营×2 架（P-51/BF-109/La-5/零式/霍克III/隼 等），speed 区间 26~66 m/s（00-config.js:1028-1101）。

### 1.2 飞行模型 = 纯运动学，无任何物理
- 位移=`位置 += fwdDir × speed × dt`（16:331-333），只有 yaw/pitch/speed 三标量+视觉 roll。**无升力/阻力/失速/能量**：俯冲不加速、爬升不掉速、倒飞不掉高度。
- 玩家输入链：鼠标**只出俯仰**（19-input 写 player.pitch→16:486 阻尼跟随），水平鼠标无效；A/D 压坡转向+手搓侧滑补偿（16:481-484）；W/S 油门 ±13m/s²（16:490）；LMB 机炮/RMB 炸弹。相机=追尾 13m、fov 随速度（20-player:1604-1613）。
- AI 驾驶与玩家是**两个平行分支**（16:323-324 按 playerDriven/crewBot 二选一），无共享控制接口——AI 直接写姿态字段。
- 环境：天花板 y>110 强制压头（16:334）；出界 MAP_SIZE/2+140 折返（16:335-339）；地形规避=航向 60/130/200m 三点采样（16:360-379）；撞地死亡线 y<gh+2（16:351-352）；巡航层 max(62, terrainMaxH()+42)（16:414-415）。

### 1.3 AI（planeAI 四态）
- **patrol**（绕圈巡航+选目标）→ **dive**（俯冲扫射+解算投弹）→ **climb** → **dogfight**（对敌机 lead 追踪）。
- 目标评分：坦克 150/60 分档、步兵 40-220m 加权、**防空炮手/机枪手 +70 优先点名**（16:424-441）；投弹解算 tof=√(2h/9.8)+前抛量（16:461-467）。
- dogfight 提前量=目标位置+velVec×clamp(d/280,0,9)（16:393）；各态转向速率 0.5~1.0 rad/s 硬编码。
- **无**：反应窗口（发现→攻击的公平延迟）、规避概率模型、双机分离（多机聚团）、对头交汇处理、难度表接入（AA 侧只有 spreadMul，14-bots:1879）。

### 1.4 武器与被击落链
- 机炮 `fireMGBurst`（16:247-268）：对地走 fireBullet 单源（vehDmg=mgDmg×0.18，P1-9 修过遮挡/装甲/友军），玩家接瞄准吸附；**对空却是函数尾部独立第二套**：邻近球垂距 <3.2m → takeDmg(mgDmg×0.7)（16:263-267），无遮挡检查（隔山可打）。无限弹药，只有射速冷却。
- 航弹 `dropBomb`→nades 表 bomb:true→nadeExplode 溅射 9.5/170/260+毁建筑（13:479-484）；挂弹 1~3、rearmT 8s/枚（16:322）。
- die() 已按 D1 加固：`alive=false → grp.visible=false 最先（16:542）→ 交接块（信标摘挂/grp.clone 残骸/入列）整体 try/catch（16:543-560）→ 记分/布娃娃链第二层 try/catch（16:561-588）`。重生 35~48s；AI 飞行员 hp<32% 跳伞逃生（16:513-523）；专属飞行员 10s 归队闸 PLANE_PILOT_WAIT_MAX（16:11,287-311）。
- 残骸 `updatePlaneWrecks`（16:12-68）：fall（-8.5 重力+冒烟）→ 落地爆炸（无差别 9/165/240+焦黑+持续火源+动碰撞柱）→ rest 24s → 沉没销毁。**时停冻残骸=既定口径**。

### 1.6 防空炮 / 巡飞弹 / 舰船
- AAGUNS：基地两侧×2+中央旗×1（+柏林防空塔 FLAK_DECKS，17:159-168）；射速 EMPL_AA_CD=0.34 玩家/Bot 同档（00-config:1268）；弹速 SHELL_SPD=380（verify-20260921B-speed 三层证据把守）；玩家炮位有 leadPip 提前量圈（280m，20a:273-285）。
- Bot 防空：登炮动机（敌机在场+未交战+15m 内空炮+随机 0.4，14-bots:727-732）→ 认领 empT=rand(14,24)s → 火控半提前量×0.5+散布误差（14-bots:1860-1884）；**无反应门**（AT 炮有 reactT，AA 没有）；被打不弃炮，敌机清空/到期/近敌才下炮。
- 巡飞弹：TV 制导三件套=**冻结契约**（19-input 只记账 tvDX/tvDY → 13:632-638 消费清零 → loiterDetonate/loiterDespawn 各有清账行）；与飞机交点=rayCyl 命中+贴近兜底+900 直伤。
- 舰船：15d/15e/15f **没有任何对空武器**（15f Battery 只扫 navalCraft）；冻结签名不许动。飞机打船走 fireBullet→navalBulletTest（13:225-228,289）与航弹→navalSplash（13:609）。

### 1.7 地面 Bot 与飞机（14-bots 实测）
- 步兵 Bot **完全无视飞机**：感知只遍历 combatants（=士兵+玩家，14-bots:508-512）；坦克 Bot 同样无 plane 引用（15-vehicles 全文件零命中）。
- 被飞机扫射无专属反应（逃跑/进掩体/还击都没有），只有通用压制的副产品；即使 damage→noticeThreat 也因 attacker.onVehicle 被掐断（14-bots:393,1340）。
- 防空炮 Bot 是唯一"地面反飞机"生态；pilotBot 专属流程在 23-deploy:666-672，14-bots:1132-1135 只有"步兵重生让位"钩子。

## 5. 子批走向（推荐案，§6 裁定后定稿）

- 判据：probe-planes 语义保持重建 + 新增 intent 等价性/协调转弯/伪升力钉值。

### 7b 空战 AI
- **重写**：steerToward 原语+四态扩展（engage 加 reactTimer 反应窗、新增 evade 态+evadeChance、双机分离 O(n²)——每队 2 架规模不需要空间网格）、lead pursuit 统一（对空 rearDot 双态+对头交汇）、对地攻击态保留现有评分/投弹解算、难度表接入（airAcc 字段候选）。
- **保留**：目标评分体系（防空炮手优先点名是好设计）、巡航层、投弹解算、pilotBot 归队链。
- 判据：90s 推演"无撞山"保持 + 反应窗/规避/分离行为断言 + 对头交汇率。

### 7c 武器与被击落链
- **统一**：对空命中单源 `planeHitTest`（四套口径→一源；高炮保留独立近炸半径 8/11 但判定几何同源）；fireMGBurst 双轨合并（对空判定并入 fireBullet 管线或显式分层，消 F7 隔山打）；F2 对空生态按 Q3 裁定动 fireBullet/坦克炮。

- 判据：verify-phase2 D1-K1~K7 与 verify-loiterfix L1-L3 **原样保持通过** + 命中单源等价性断言。

### 7d 防空/巡飞弹/舰船交接 + 回归链重建
- 交接面冻结内核不动（AAGUNS 结构/flak 弹管线/TV 三件套/15d-f 冻结签名），只做边界内核对与接线适配。
