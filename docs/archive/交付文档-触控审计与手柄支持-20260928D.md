## 二、手柄支持(新增 `js/19b-gamepad.js`,index.html 挂载于 19-input 之后)

- **架构**:与触控同一套"合成输入"——只写 `keys.* / mouseDown / mouse2Down / yaw/pitch / tvDX/tvDY` 这些单源,20a/16/13 的消费端**零改动**。三入口共存,手柄只在战斗中接管(菜单/部署/结算仍用鼠标/触屏)。
- **键位**(standard mapping,Xbox 布局):RT 开火 · LT 瞄准 · 左摇杆移动(推满外圈=疾跑) · 右摇杆视角/巡飞弹制导 · A 跳 · B 蹲 · X 互动(F) · Y 换弹(R) · LB 疾跑(按住) · RB 手雷(按住烹饪) · LS按 切枪 · RS按 近战 · Back 战况(按住) · Start 暂停;十字键 上 绷带/气动飞行(H) · 下 趴(Z) · 左 烟雾(4;**工程兵=选工事 5**) · 右 AT雷(3)。
- **手感**:右摇杆按 rad/s 模型(yaw 3.4 / pitch 2.4,灵敏度吃 `SETTINGS.sens` 与 `lookZoomMul()` 变焦);TV 制导满杆记账 ≈1000px/s,恰好压住弹体 2.5/1.9 rad·s⁻¹ 角速度上限;径向死区 0.22。
- **健壮性**:连接/断开事件提示(showScorePop);**断开即释放全部按住态**(held 表 + padReleaseAll,防拔线卡键);非战斗帧逐帧归还 mouseDown/移动键(死亡/切面板不再"带车走");LT 的 ADS 门与键鼠/触屏逐条同款。
- **游戏说明**:主菜单「游戏说明」新增「手柄操作」节(中英双语),设置面板不加开关(连上即生效)。
