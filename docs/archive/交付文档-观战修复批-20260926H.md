## 1. 逐条修复（口径 → 改动 → 判据）

### 1.1 #1 / A1 —— 观战者不再是弹道上的"活体掩体"

- **口径**：观战者**不参与命中判定**。他免伤 ⇒ 子弹停在他身上对双方都是白费；而他站在队友前面时，等于一面
  无敌的活体掩体（反过来他开火也会"吃掉"对面射向别人的弹）。与 14-bots/15-vehicles/16-aircraft/21-match
  既有的"观战者不计入"同一条口径。
- **改动**：`13-combat.js` `raySoldiers` 的候选过滤 `!s.alive||s===shooter||s.onVehicle` → 补 `||s.spectator`。
  一处生效即覆盖全部调用方（子弹 `fireBullet`、坦克炮弹 `updateShells` 的 `raySoldiers(...,SHELL_R)`、
  近战 `doMeleeHit`、载具同轴机枪、准星拾取）。
- **判据**：`verify-specbatch T1` —— 三点一线（射手 → 观战者 → 靶兵，眼位同高）时射线**跳过**观战者命中靶兵
  （靶兵 100→70、观战者 100）；**阴性对照**：同一站位取消观战后同一发弹重新停在他身上（靶兵不掉血、观战者 100→70）
  ⇒ 判据确实只来自 `spectator` 这一个条件。`_spec-audit S1` 同判据（含旧读数对照）。

### 1.2 #2 / A2 —— 出生列表观战闸门（舰艇例外）

> ★**2026-09-27I 取代**：舰艇/两栖车也一并置灰（用户实报"观战模式仍能选几个海战相关载具"）—— 见 §6/I1。

- **口径**：观战者的明写口径是"常规载具/阵位/补给一概不用（自由观察专用）"，**但舰艇例外** ——
  2026-09-22 用户裁定②「观战者不走路登艇，想开艇请从部署界面选舰艇出生项」是唯一上艇路径，不能一起挡掉。
- **改动**：`23-deploy.js buildSpawnList` 里 `const specBlocked=!!player.spectator&&(v.kind==='tank'||v.kind==='plane')`
  → 该按钮置灰 + 名字后缀「 (观战不可征用)」（复用既有 `disabled` 样式）；`deployPlayer` 侧不需要新闸门
  （不可选中的 id 不会被写进 `selectedSpawn`；文件里那句 `if(!opts.some(o=>!o.disabled&&o.id===selectedSpawn)) selectedSpawn=-1`
  就是既有防线）。
- **判据**：`verify-specbatch T2`（塔拉瓦图，3 台坦克/战机 + 5 台舰艇/两栖车）：观战者列表里 tank/plane **全部**
  `disabled===true` 且含「观战不可征用」；**阴性对照**普通玩家的同一份列表照常可选；舰艇/两栖车对观战者
  `disabled===false`（5 台全亮）；两个列表都**没有**「幽灵坦克」项。

### 1.3 #3 / A3 —— 观战开关的生效点

- **口径**（审计建议 + 用户圈定）：不允许"正在交战的活人二次点击 → 当场免伤+无限弹+无差别火力"。改为

    确认后写 `player.specWant=true`（**不动 `player.spectator`**）；关闭时立即落地并顺带收车 + 时间倍率复位。
    卡片外观三态：`观战中` / `观战待生效` / 无。
  - `23-deploy deployPlayer` 开头结算 `player.specWant`（放在 `playerClassWeapons` 之前 —— 配枪、副武器换装、
    重生提示都读 `player.spectator`）。

### 1.4 #4 / A4 + 新增① —— 观战者座驾保护

- **口径**（用户实报原文："观战模式操纵双方载具会被索敌和击毁，而且会带着观战模式的玩家一起死"）：
  **观战者驾驶的载具 = 观战者身体的延伸**。C.14 已裁定"对战局无上限的干预"是测试需求 ⇒ 观战者**对**战局
  的作用照旧（火力改战局），但**战局反噬观战者本人**（含他的座驾）一律无效。
- **改动**：
  - 新增判据单源 **`13-combat specRide(v)`**：`v.playerDriven && player.spectator && (player.onVehicle===v||player.onNaval===v)`
    （座位字段与 20a-seats 的"两座位互斥"契约同源）。
  - **不被索敌**（5 处）：`15-vehicles enemyTankNear`（反装甲兵/AT雷/水面对舰的共同取目标入口）·
    `15-vehicles tankPerceive`（敌车 + 敌舰两个候选环）· `16-aircraft` 战机俯冲选靶 · `15d-naval navalNear`
    （步兵对舰 + 艇对艇的共同入口）· `15f-battery pickTarget`（岸炮）。
  - **不被击毁**（3 处伤害入口）：`Tank.takeDmg` / `Plane.takeDmg` / `NavalCraft.takeDmg` 早退。
  - **不共死**（兜底）：`20-player specRideEject(v)` —— 车毁链（`Tank.die`/`Plane.die`）在驾驶员是观战者时
    改调它：座位字段清干净、落到车旁平地（与幽灵坦克下车同一套落点探测）、0 死 0 票 0 杀；
    同车 2 个轻量乘员名额**也不结算**（A4 的劈叉就此关闭），战报也不再吹"乘员×3"。
- **判据**：`verify-specbatch T4` —— 999+500 反装甲直击后车体毫发无伤；反装甲兵扫描**跳过**该车（临时置亡其余同队
  坦克以隔离判据）；强制 `die()` ⇒ 0 死/0 票/0 杀、座位解绑、落点在车旁 3.4m；**阴性对照**普通玩家驾驶的同款车
  被毁照旧走死亡链（阵亡 +1、本方 330→327 = 1 驾驶员 + 2 乘员名额）。

### 1.6 #11 / B7 —— 时间控制（暂停/慢放/单步）

> ★**2026-09-27I 取代**：慢放与单步整段删除，只留 `K` 时停；且时停不再冻结观察者本人 —— 见 §6/I4。

- **口径**：慢放必须是**真慢放** —— 世界推进与游戏时钟 `nowT` 同速，射速/引信/重生倒计时/旗点进度一起慢下来。
- **改动**：`22b-speclayer` 的 `SPEC_TIME / specTimeConsume(rdt)` + `24-main` 主循环：
  ```
  const rdt=min(帧时间,0.05); dt=specTimeConsume(rdt);        // 非观战: 原样返回 rdt (零漂移)
  if(暂停/结算/菜单) nowOff+=now-lastT; else if(dt!==rdt) nowOff+=rdt-dt;   // 未消费的时间进 nowOff
  nowT=(now-nowOff)/1000;
  ```
  —— 复用既有 `nowOff` 机制让 `nowT` 与世界同步减速，不改任何系统的时间口径。
  键：`K` 暂停/继续（=0）· `,`/`.` 在 `[1, 0.5, 0.25, 0.1, 0]` 档位表上来回 · `L` 单步（排队 1 帧，主循环消费一格 `1/50s`）。
  生效条件单源 `specTimeActive()`：观战者 + 活着 + 未结算 + 未暂停 —— 关掉观战/换局/回菜单自动回 ×1。
- **判据**：`verify-specbatch T7`（真键位链）—— 暂停时 `specTimeConsume` 返回 0；`L` 恰好放行一格（0.020 → 0）；
  半速档把 0.02 缩成 0.01；档位循环 0.5→0.25→0.5→1；**非观战态倍率恒 1 且帧时间原样通过**。
