## 1. 口径单源（`js/00-config.js`）

审计的第一条结论是"这些数字散在各处，玩家读不出规律"。本批把**破坏的全部数字**收进 `00-config`
一处（与 `STRUCT_SCORE` 同一纪律：使用点只读常量）：

| 常量 | 值 | 含义 |
|---|---|---|
| `STRUCT_HIT.pad` | 3 | 爆炸有效半径 = 弹种 `radius + pad`（手雷 7.5 / 坦克炮弹 10 / 航弹 12） |
| `STRUCT_HIT.falloff` | 0.6 | 距离衰减：`amt × (1 − d/R × 0.6)` |
| `STRUCT_HIT.vGate` | 3.4 | 竖直门限（≈一层楼）：爆点与该盒的高度差超过它 = 不同楼层，不结算 |
| `STRUCT_RAM` | `minSpeed 1.9 / k 2.2 / velAbsorb 0.58 / face 0.35 / cd 0.32` | 撞塌：伤害 = `k × 车速²`，需正撞（法向·行进 ≥ face）、车速 ≥ minSpeed、同车 0.32s 冷却 |
| `STRUCT_CRUSH` | `infBase 70 / infPerM 9 / infMax 200 / vehMul 0.55 / pad 0.6 / vBand 4.0` | 坍塌碾压：按落体高度线性加码的步兵伤害，载具 ×0.55 |
| `STRUCT_HP` | `ref 6 / base 0.6 / span 0.4 / min 0.75 / max 2.6` | 血量归一曲线（见 §2-B1） |
| `STRUCT_ROOF` | `base 260 / perSqrtArea 70 / min 300 / max 1500` | 屋盖血条 = `260 + 70×√(投影面积)`（m²） |

## 2. 逐条落地

### A1 命中判据：组心平面距 → 最近成员碰撞盒的三维距离

**改法**（`js/05-world.js`）
- 新增 `boxDist3(p,b)`：点 → 碰撞盒的**三维**距离（盒内 = 0），共享结果槽（热路径不分配对象）。
- 新增 `structBounds(g)`：组成员盒并集包围盒（`dEnd` 时算一次）。仅用于**廉价早退**：到包围盒的距离 ≥ R
  就能断定组内任何盒都够不着（并集性质），否则再逐成员盒求最近。死盒被写成 99999 ⇒ 并集只会变大 ⇒
  判据永远保守（宁可多扫一组，不可漏一组）。
- `damageStructures` 的组循环：`d = min(成员盒的三维距离)`，且 `dy ≤ vGate` 才参与；
  `amt × (1 − d/R × falloff)`；命中件（最近那个盒）作为 `at` 透传给 `destroyStructure`。

**证据**（`dev/verify-destruct-20260927N.js` T1）
- 成员盒中心落点**空放率 = 0**（berlin 0/307、island 0/251；改前静态几何口径 9.3% / 10.2%）。
- 竖直门限不变量：12680 / 15294 次观测里，"竖直差 > 3.4m 的存活组掉血" = **0 次**。
- 爆点 ±60m（只改 y）→ **0 / 0**（改前 45 / 45，逐位相同 = 判据里根本没有 Y）。
- A/B 探针复核：柏林最大组"正中组内最远那块墙" **26.57 → 45**（远端不再被组心距罚掉 41%）。

### A2 撞塌按动量 + 爆炸参数单源 + B4 计分归属

**改法**（`js/15-vehicles.js`）
旧版 `if(b.dGroup && |vel|>1.9) destroyStructure(b.dGroup)` —— 任意接触、任意朝向、绕过 hp、不计分。
现在：把判定挪到算出碰撞法线之后，`facing ≥ 0.35`（正面 ±70° 内）且 `|vel| ≥ 1.9` 且过了 0.32s 冷却，
才走 `damageStructureBy(g, k·v², 车长/车组, 命中件)` —— **与炮弹同一套账**（hp0 → 扣血 → 受损档 → 销毁 → 记分）。
不满足条件时**落到原有的弹性推挤**（被墙挡住 + 掉速），不再"贴一下就把整栋拆了"。

**证据**（T2/T3，夹具用真 `Tank.update(0.05)` 驱动）
| 场景 | 旧版 | 本批实测 |
|---|---|---|
| 1.6 m/s（< 门槛） | 0（同样不触发） | **0** |
| 2.2 m/s（>  旧门槛） | **整组当场销毁**（含 202 盒楼段） | **扣 10.65**（=2.2×2.2²） |
| 8 m/s 正撞 | 整组销毁 | **140.8**（=2.2×8²），冷却窗口内 3 帧只结算一次 |
| 8 m/s 侧擦 | 整组销毁 | **0** |
| 撞毁归属 | 无（不计分） | **车组 +20**（轻档），玩家账 0 |

### A3 掩体可炸 + 油桶可引爆

**改法**（`js/05-world.js` + `js/05b-props.js`）
- `structSweepNear(p,R,amt,attacker)`：每次爆炸对近场盒做一次扫掠 —— `crush` 件（沙袋/石墙/木箱/树篱/倒木）
  在半径内**命中即摘**（复用 `crushCoverBox`：碎屑 + 树篱走 `vanishFlora`）；`b.roof` 件按 §B2 记账。
- 油桶：`barrel()` 的 CYLS 记录新增 `mesh` + `explosive`；`barrelBlast(c,attacker)` 先摘账
  （`killCyl` + 网格移出 world）再结算 —— 闪光/烟/火星 + `splashDamage(3.4, 95/60, 不认人)` +
  `igniteArea(2.2m)` + 以小半径（2.8/90）再走一遍 `damageStructures` ⇒ **连锁引爆**（深度上限 3 层防油桶阵互递归）。

**证据**：T4（normandy/island）掩体命中即摘且网格移出 world、半径外不受影响；
A/B 探针：坦克炮弹正中可碾掩体 —— 改前"掩体完好、10m 外的砖墙掉血"，改后**掩体死**；
T5：油桶引爆 + 2m 邻桶连锁 + 2m 处步兵 100 → −12.7。

### A4 坍塌碾压

**改法**：新增 `collapseCrush(bb,yTop,gy,attacker)`；`destroyStructure` 用**本组成员盒并集**做覆盖矩形，
`collapseRoof` 用**承重带 + 楼板并集**（在击杀碰撞**之前**取 AABB，此时还完好）。判据 =
水平落在矩形（外扩 0.6m）内、高度在 `[地面−4, 顶面+0.5]` 之间；步兵吃 `70 + 9×落体高度`（钳 200），
载具吃 ×0.55（`tanks`/`trucks` 的 `takeDmg`），attacker 透传（撞/炸/砸都算谁的战果）。
车内乘员按 `seatShielded` 跳过（由载具受伤承担，与 `splashDamage` 同口径）。

**证据**（T6）：覆盖内步兵 100 → 0.9（顶面 3.5m / 地面 0.3m）；屋盖坍塌覆盖内 100 → −57.4；
矩形外 12m 的步兵 100 不动。

### B1 血量按组规模归一

**改法**：`scaleStructHP()`（`24-main` 在 `capturePristineWorld()` 之前调用一次）
```
scale(n) = clamp(0.6 + 0.4×√(n/6), 0.75, 2.6)      // n=1→0.76×  6→1.0×  24→1.4×  60→1.86×  ≥202→2.6×
g.hp = round(g.hpNom × scale(g.n));  g.hpFull = g.hp;  g.hp0 = g.hpFull
```
- **为什么是 √**：全归一（每盒等价）会让 202 盒的楼段需要 ~150 发炮弹，完全改变巷战节奏；√ 是"大件更厚实、
  但不到数量级"的折中，同时把评分权重（`hp0`）从"首次受伤时机"改成**建图期定死**（重开一局前后档位一致）。
- **两个例外 `noScale`**：破袭补给库（720）与反舰炮位胸墙（`BATTERY_HP`）—— 它们的血量是**对局规则数值**，
  会被运行期复位链（`22-hud` / `15f.revive`）写回，缩放它会造成"开局值与复位值不一致"。
- `structResetHP(g)`：血量复位单源（HUD 复位不再写死 720）。

**证据**（T7）：全部组 `hp == round(hpNom×scale(n))` 且 `hp0 == hpFull`（违例 0）；曲线单调；
`noScale` 组原地不动（island 4 组）；每盒分摊极差 berlin **11.1×**（15.89~176）/ island **6.4×**（38.33~244），改前 88×。

### B2 屋盖承伤（打屋顶终于有效果）

**改法**：`roofRefFinalize(ref)` 在**每个屋顶构建处收口时**调用（`pitchedRoof` + 4 处手造 roofRef：
地铁亭平顶 / 防空塔×2 / 圆木堡）—— 给承重件（坡顶碰撞带 + 山墙；无 `bands` 时退回 `slabs[].b` 盖板盒）
打 `b.roof = ref` 标记，并按投影面积给 `ref.hp = 260 + 70×√(面积)`。爆炸扫掠时**每个 ref 只按最近那一片
记一次伤害**（与组的"一次结算"同规，避免一发炮弹盖住 6 条带记 6 次），累计 ≥ hp ⇒ `collapseRoof`。
世界还原把 `ref.dmg` 一起回快照。

**证据**（T8）：直接轰屋顶 → `ref.dmg` 300 起跳；承伤归零 → `ref.done` + 承重件全击杀；
血条按面积（area 134.2 m² → hp 1071）。

### B3 受损中间态

**改法**：`structSetDamageTier(g, hp/hp0)` —— 两档（>66% 完好 / <66% 档 1 / <33% 档 2），

**证据**（T9）：50% → 档 1（材质已换、带 `dmgTier` 标记）；75% → 档 2；世界还原 → 档 0 + 原材质复原 + 血量回满。

## 5. 用户实机验收清单

1. **打长墙**：对着长墙的**远端/墙脚**开炮 —— 现在"打到哪儿哪块掉血"（旧版远端会打不掉血）。
2. **楼层感**：在**楼下**轰墙，楼上的墙不应跟着掉血；把炮打在**三楼**，一楼不应跟着掉。
3. **打屋顶**：坡顶房 / 平顶房 / 防空塔顶板 —— 打屋顶**现在有反馈**，打光屋盖血条整片塌（注意：屋顶塌了墙可能还立着，这是本批有意保留的形态）。
4. **炸沙袋/木箱/石墙/树篱/倒木**：会被炸掉（与坦克碾压同一种碎屑表现）。
5. **炸油桶**：会爆（连锁、引燃、波及附近步兵/载具）——营地里的油桶现在是危险品。
6. **坦克撞墙**：轻蹭（≈7 km/h 以下）只被挡住、不再拆楼；**全速正面撞**才撞塌，且算车长/车组战果。
7. **站在要塌的楼里**：会被砸伤/砸死（以前不会）；被砸死的人也计入战果归属。
8. **耐久手感**：长墙/整栋主体比单块小垛更抗打（血量按规模归一）；受损时墙会**变暗两档**。
9. **永久件辨识**：灯塔/地铁亭/混凝土炮位/桥墩这类"打不烂的件"现在**材质略微提亮**（读作新浇混凝土）。
   若觉得碍眼/太亮，告诉我，一个数（`structMatPerm` 的 1.06）就能调或关掉。
10. **进图控制台**新增一行：`[破坏] 结构血量归一: N 组 (名→实 见 STRUCT_HP) · 永久件材质档: M 件`。
11. **破袭模式**：补给库血量仍是 720（未参与归一）；反舰炮位胸墙血量仍是 `BATTERY_HP`。

**可调旋钮（都在 00-config）**：`STRUCT_HIT.vGate`（楼层分层高度 3.4m）、`STRUCT_RAM.k`（撞塌强度 2.2）、
`STRUCT_RAM.minSpeed`（1.9 m/s）、`STRUCT_CRUSH.*`（坍塌伤害 70+9×高）、`STRUCT_HP.max`（大组血量上限 2.6×）、
`STRUCT_ROOF.*`（屋盖血条）、`structMatPerm` 的提亮系数。
