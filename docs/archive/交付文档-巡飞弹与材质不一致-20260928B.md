## 一、巡飞弹 TV 制导：从"弹体追本体角"改为"鼠标直控弹体"（修"生硬 + 随机失控"）

### 1.1 机制取证（dev/_diag-loiterplane.js 等临时探针，已删）

旧链路：`19-input` 把 movementX/Y **写进本体** `player.yaw/pitch`；`13-combat.updateLoiters` 里弹体以
`rateYaw=1.9` 的有限角速度 `angDiff(d.yaw, player.yaw)` 追本体角，另有 `-0.06·dt` 恒定低头。实测：

- 甩镜 1.1 rad，弹体要追 **34 帧（≈0.57 s）** 才到位 —— 手感"生硬"；
- 追角是**有上限的积分器**：鼠标多甩出去的角差**永远存留在本体角里**，松手后弹体继续朝那个角拐
  （180° 掉头最长 1.65 s 才收敛）—— 用户看到的"随机失控"；
- `-0.06·dt` 低头在稳态是 −0.001 rad 的平衡点（不是无界下沉），但它与追角叠加让瞄准点漂移。

### 1.2 修复（三个文件，一条链）

- `js/19-input.js` mousemove：`player.loiter`（正在 TV 制导）期间，movementX/Y **只记账**进
  `player.tvDX/tvDY`，本体 yaw/pitch **完全不动**；其余路径（步行/ADS/海战炮手镜灵敏度）原样。
- `js/18-game.js` player 字段：新增 `tvDX:0, tvDY:0`（累计器，注释写明单源）。
- `js/13-combat.js` updateLoiters：

  ```js
  const sens=0.0022*(SETTINGS.sens||1)*(85/74); // TV 视场 85 vs 步行 74 ⇒ 同倍率收窄
  const rateYaw=2.5, ratePitch=1.9;             // 逐帧角速度上限 (rad/s)
  d.yaw  += clamp(-(player.tvDX||0)*sens, -rateYaw*ldt, rateYaw*ldt);
  d.pitch+= clamp(-(player.tvDY||0)*sens, -ratePitch*ldt, ratePitch*ldt);
  player.tvDX=0; player.tvDY=0;                 // 当帧消费、当帧清账
  d.pitch=clamp(d.pitch,-1.2,1.2);
  player.yaw=d.yaw; player.pitch=clamp(d.pitch,-1.45,1.45);   // 本体角=弹体角
  ```

  口径三条：①鼠标增量**直接**变弹体姿态（0 帧延迟）；②超出角速度上限的增量**丢弃**而不是存起来
  （这是"失控"的根）；③本体角恒等于弹体角，退出 TV 视角（T 弃弹/引爆/F 第三人称）画面不跳。
  `loiterDetonate` / `loiterDespawn` 各加一行清账（否则下一枚出膛会先"拐一下"）。

### 1.3 判据（dev/verify-loiterfix-20260928.js L1，7 条）

增量→姿态逐位等于解析式（100px → −0.04167 rad）；一帧 5000px 只走 −rateYaw·dt（超出**丢弃**，
方向判据：movementX 为正 ⇒ yaw 负向）；零输入 120 帧姿态**逐位不变**（阴性：旧公式在同一状态
3 s 内还要再拐 **1.10 rad**）；零输入 20 s 俯仰漂移 0.0000 rad；`player.yaw===d.yaw`；
真 `mousemove` 事件经 19-input 派发 → tvDX/tvDY=37/−12、本体角未动（沙箱需 `pointerLocked=true`
—— 19-input 入口有 `!pointerLocked` 早退）；引爆后 tvDX/tvDY 归零。

## 二、击落视觉交接原子化（修"飞机挂在天上"）

### 2.2 机制取证

`Plane.die()` 旧顺序：`alive=false` → 记分/战报/布娃娃/兵力/特效 → **最后**才克隆残骸 + `visible=false`。
中间任何一环抛异常（记分 DOM、cannon、killfeed……），异常冒到主循环，而 `Plane.update()` 对
`!alive` **早退** —— 单位"死而不隐"，永远悬停。探针把 `showKillPop` 换成抛异常的桩**复现**了该机制
（dev/_diag-plane2/3.js，已删）。另：**时停中**击落的残骸随战场冻结（y 逐位不变）—— 这是
"时停冻的是战场"既有口径，不是本缺陷（见 §五）。

### 2.2 修复（js/16-aircraft.js Plane.die）

残骸克隆 + `planeWrecks.push` + `grp.visible=false` **整段提前**为 die() 的第一动作（视觉交接 = 原子的
一步），其后记分/战报/布娃娃/兵力/特效/音频整段包进 `try{…}catch(e){ console.warn('[击落] 记分/布娃娃
链异常 (单位已退场):',e) }`。口径：单位状态正确优先于记分完整 —— 打断的那一笔记分会丢，但不会再
产生"挂在天上的活尸体"。

### 2.3 判据（L2）

源码顺序（`planeWrecks.push` #956 与 `this.grp.visible=false` #1269 都早于 `registerKillScore` #1924 /
`cb.damage` #1635，副作用整段在 try #1293…catch #2264 内）；行为双路径：正常路径击毁即"本体已隐 +
残骸入表 + 残骸 4 s 坠落 70.3 m"；打断路径（showKillPop 抛异常）异常**不逃逸**、交接照常完成、残骸照落。

## 三、材质二次校准（修两张追报图的"材质不一致"）

### 3.1 取证：不是 UV 拉伸，是贴图内容问题

跑 `dev/_uvdensity-audit.js 0/3`（诺曼底/淞沪全量带贴图盒面）：

| 贴图 | 盒面数 | 密度中位 | 最小~最大 | 跨度 |
|---|---|---|---|---|
| brick | 69 / 23 | 1.80 m/贴 | 1.80~1.80 | **1.0×** |
| plaster | 23 | 1.80 | 1.80~1.80 | 1.0× |
| stone | 48 / 1 | 2.00 | 2.00~2.00 | 1.0× |
| wood/woodDark | 30/30 | 2.00 | 2.00~2.00 | 1.0× |

（PIL 裁块放大：`dev/_crop/B_*.png / A_*.png`，用后已删。）结论：`05-world.mesh→uvGeo→scaleBoxUV`
的密度归一在两张图上**工作正常**；"不一致"来自贴图内容本身 ↓。

### 3.2 砖（用户追报图：淞沪砖构大厂房）

三个病灶：①单砖 64×32px = **0.45×0.225 m**（@1.8 m/贴）—— 在大厂房立面读作"玩具积木"；
②列色表 `colFill` **整列同色** ⇒ 墙面出现竖向色带；③砖缝是米白宽底 + 亮高光条（#8a8172 底 +
rgba(255,236,214,.2) 条）—— 受光面看是"米白缝橙砖"、背光面是"深缝红砖"，**同一面墙两种材质感**
（= 用户说的"不一致"）。

修复（`02-scene` canvas + SVG 同口径重写）：单砖 **32×16px（8×16 块/贴 ⇒ 0.225×0.1125 m）**；
逐块只抖明度 `shade(BRICK_C, 0.88~1.12, ±3)`（行×列二维表，越界半块取对边同列色 ⇒ 平铺闭合、
缝上不换色）；行内奇偶错缝照旧；砖缝底色压暗 `#6e5849`，高光/阴影条收细收淡（0.10/0.22，1px）。

### 3.3 抹灰（用户追报图：诺曼底灰白楼）

28 首版（本会话上一批）把离散图形全删后，`svgMottle` 的 α = s·(R+G+B)+bias 按**三通道和**（均值 1.5）
取值 —— 首版参数实际合成明度调制只有 **~2%**，远处 minify 后整面墙平均成"没上材质的白模"。

修复：4 层 fBm 重配 —— 大修补斑 `pl1`(freq 0.012, −16% 暗云, op 0.45) + 晒褪斑 `pl2`(0.05, +9% 亮云,
op 0.30) + 细颗粒 `pl3`(0.6, op 0.12) + 微齿 `pl4`(1.2, op 0.08)，基色提为 `#b6ad97`；合成调制 ~5-8%。
红线不动：**仍无任何离散图形**（无 ellipse/path/渐变）、`stitchTiles="stitch"` 平铺无缝、单层 op≤0.5
（不会再长出"圆点/毛线"）。Canvas 兜底同步（颗粒对比度上调、基色对齐）。

### 3.4 判据（verify-matseam-20260927，44/0）

砖选择器随新尺寸更新（SVG rect h=14 / Canvas fillRect 30×14，排除 1px 高光条）；平铺闭合/接缝连续
对 144 块砖 + 高光/阴影线全查；抹灰新判据：无离散图形（元素全是 rect、无渐变）+ 层数/缝合 +
**存在感** Σ op·E[α] ∈ [30%, 95%] 且单层 op≤0.5（下限防"白模"复发，上限防"圆点"复发）。

## 六、验收清单（实机）

1. **巡飞弹**：观战 F 召幽灵坦克 → 发巡飞弹 → TV 视角快速甩镜/急停 —— 弹体应**零延迟**跟手；
   猛甩后松手弹体**立刻停**（不再继续拐）；引爆后立刻发射下一枚，出膛不"先拐一下"。
2. **击落**：巡飞弹击落飞机 —— 飞机应立刻消失并出现坠落残骸（拖着烟）；即便战报/记分出异常也不应
   再出现"死机悬停"。时停中击落：残骸与战场一起冻住、解除后落地（口径确认）。
3. **砖**：淞沪中央旗 E 侧厂房/村宅 —— 单砖明显变细密（约原来 1/2），无竖向色带；受光面/背光面
   砖缝观感一致（不再"一面米白一面深褐"）。
4. **抹灰**：诺曼底灰白楼/各类抹灰建筑 —— 远看有柔和的深浅云斑（不再是纯白模），近看无规则圆点、
   无"毛线"。
