# 交付文档 —— 击杀来源归因 + 受击方向弧 (2026-09-29)

> 用户实报三缺陷 → 问询定口径（弹体自带标签 / 方向弧只随玩家转向重算）→ 全链修复 → 沙箱回归全绿。
> 版本戳 `20260928k → 20260929a`（index.html 41 处，Node fs 改）。

## 一、用户实报

1. **击杀武器显示错误**：用巴祖卡击杀小兵，击杀播报显示的却是柯尔特 M1911。
2. **坦克被"打不动的武器"击毁**：车毁播报显示被 STG44 / M1911 击毁——这两把枪没有 `vehDmg`，本就打不动坦克（用户补充：反坦克兵副武器是 M1911；STG44 持有兵种没有能有效伤害坦克的武器）。
3. **伤害来源方向弧不随位置变化**：无论角色怎么转，受击时出现的屏缘红弧都不动。

## 二、根因（两个 BUG 同根）

- **来源标签挂在射手身上、击杀结算那一刻才读**（21-match `killSrcLabel` 优先读 `attacker._src`）。所有"开火→延迟杀伤"的弹体（火箭/手雷/迫击炮弹/炮弹）在飞行期间，射手可能又开了别的枪，`_src` 被覆盖 ⇒ 播报记错。即时命中链（子弹）没有这个问题。
- **缺陷①的直接病灶**：玩家火箭筒分支（20-player）在 `fireRocket(...)` 后直接 `return`，**永远走不到** `p._src=当前武器名` 那一行（20-player:808）——播报读到的是上次开火挂的旧标签。Bot 的火箭路径（14-bots 打坦克/打舰船两处）同样不写。
- **缺陷②的真凶**：延迟杀伤弹体的标签被覆盖。能伤坦克的爆炸只有走 `splashDamage` 的那几路（坦克炮/火箭/反坦克炮/迫击炮弹/反坦克炸药/航弹/巡飞弹/舰炮岸炮）；**普通手雷走 `explodeAt`，本就没有坦克伤害圈**（取证纠正了初判"手雷磨死坦克"——不成立）。
- **缺陷③**：`addDirHit`（21-match:621）在入帧那一刻算一次相对角写进 DOM transform，之后不再更新。

## 三、用户裁定（2026-09-29 问询定案）

- **归因修复**：**弹体自带标签**——每发弹体在创建时把来源名存到弹上（`src` 字段），命中/爆炸结算前把射手的 `_src` 重盖章成弹体标签。根治所有延迟杀伤（否决了"只补漏写 3 行"的轻量案：那只能修巴祖卡本例，"弹在飞时射手又开枪"仍会记错）。
- **方向弧**：**定格世界方位、每帧只随玩家朝向重算**——生成时记下攻击者的世界方位（`_wAng`），此后每帧按玩家当前 yaw 重算屏上角度（玩家转头弧反向滑动、始终指向真实世界方位）；攻击者后来的走位**不**追踪（否决了实时跟踪攻击者方案）。

**B. 命中/爆炸重盖章（4 处，都在伤害结算前一行）**

- 15-vehicles `updateShells` 命中块（覆盖火箭/坦克炮/反坦克炮弹的直击+溅射）；
- 15d-naval `shellHitNaval`（舰炮弹对艇）；
- 13-combat `nadeExplode`（迫击炮弹/反坦克炸药/手雷，烟雾/燃烧早退之后）；
- 13-combat 巡飞弹引爆块（含直击坦克/飞机/步兵三路）。

击杀链（`damage→die→addKillfeed`）与结算同步 ⇒ 重盖章后 `killSrcLabel` 读到的必然是本弹标签。

**C. 方向弧（21-match + 22-hud）**

- `addDirHit(worldAng)` 新增 `d._wAng=worldAng` 定格；同侧合并分支同步续传 `_wAng`。
- 新增 `updateDirHits()`：每帧按 `_wAng - player.yaw + π` 重写 transform（`rel` 随 yaw+1 而 −1，弧反向滑动、世界指向不变；攻击者走位不追踪）。
- 接线：22-hud `updateHUD` 逐帧段调用（typeof 守卫）。

## 六、实机验收清单（按 X 应看到 Y）

1. 用**巴祖卡/坦克杀手**击杀任意步兵 ⇒ 击杀播报显示 `[巴祖卡 M9]`（或 `[坦克杀手 RPzB54]`），**无论发射后是否切过枪**。
2. 让反坦克兵 Bot 击毁坦克（或自己射完火箭立刻切手枪打两枪）⇒ 车毁播报显示 `[巴祖卡 M9]`/`[坦克杀手 RPzB54]`，不再出现 `[柯尔特 M1911]`/`[STG 44]`。
3. 迫击炮弹炸死步兵/炸毁坦克 ⇒ 播报 `[迫击炮]`；舰炮/岸炮/坦克炮同理记载具/炮位名。
4. 站定不动被打一枪 ⇒ 屏缘红弧指向射手方向（与旧版一致）。
5. 吃一弹后**原地转身** ⇒ 红弧随转身**反向滑动**，始终指向射手当时所在的**世界方位**；1.5s 后照旧淡出。
6. 同一侧（±0.6rad）连续吃弹 ⇒ 弧不叠加、角度/计时刷新（旧口径保持）。
7. （口径提醒）射手**后续走位**弧不跟随——这是本批裁定口径，如实测想要"跟人走"再说一声即可改。
