### D3 不可破坏建筑墙体/谷仓房顶材质贴图严重不一致 ☑ 关闭（2026-09-28 阶段二批定案+修复，用户实机验收通过）

> 「全部不可破坏的建筑墙体和谷仓房顶存在严重的材质贴图不一致的问题！」

- **已做（第一轮，2026-09-28E 批）**：_matShade 池化克隆丢 uvRef ⇒ 补回写。修的是"密度漂移"这一层，
  实机仍复现 ⇒ 有第二层病根。
- **定案（2026-09-28 阶段二批，两层病根；用户口径"各个部位明暗区别很大"）**：
  - **层一 = B5 永久件逐盒提亮**：markPermPieces 给每块 box 单独 structMatPerm +6% 亮度 ⇒ 带门窗的
    墙体被拆成多块 box，提亮块与不提亮块同墙拼接 = 一墙两色的"拼块感"。09-28E 的 uvRef 回写让
    贴图密度正确后，**亮度差**成为唯一可见残差。**用户裁定：取消提亮** —— `structMatPerm` 改为
    直通（单源壳保留、perm 盒标记保留，T10/roofghost 口径不受影响）。
  - **层二 = 非盒几何不归一**：uvGeo 此前只有 BoxGeometry 分支，烟囱/草垛类 Cylinder 侧面 UV 是
    三内置 0..1 直通 ⇒ 贴图密度与整墙完全不同尺度（烟囱巨砖）。修复 = uvGeo 新增
    CylinderGeometry/ConeGeometry 分支：侧面 u 按 thetaLength·rMax/S、v 按斜长/S 归一，端盖按
    半径/S 归一，分类走 `g.groups`（heightSegments=1 时侧面顶点也在 ±h/2 平面，按 y 分类全误判），
    仅对带 uvRef 的材质生效，参数键缓存。
- **判据**：`verify-phase2-20260928` D3a（全库 0 件 permTier 材质 + perm 盒标记保留 + markPermPieces
  幂等）+ D3b（丝厂烟囱/谷仓草垛圆柱三向密度 vs 理论值 + uvGeo 直调 + 树皮阴性对照），诺曼底/淞沪双图。
- **验收（实机）**：带门窗的不可毁墙明暗一致无拼块；谷仓烟囱砖块与墙面同尺度；草垛贴图密度正常。
  —— **2026-09-28 用户实机验收通过，关闭**。
